## 🎯 페이지 목적

사용자의 **지갑 관리 및 자산 현황**을 제공하는 BlockPick의 **핵심 사용자 페이지**입니다.

이 화면은 다음과 같은 주요 목적을 가집니다:
- **자산 현황 파악**: 총 보유 캐시, 이벤트 캐시, 쇼핑 캐시 구분 표시
- **지갑 관리**: 충전, 환불, 거래 내역 조회
- **활동 추적**: 게임 참가 내역, 쇼핑 주문 내역 빠른 접근
- **시각적 분석**: 캐시 배분 차트 및 통계 정보 제공

## ⚙️ 기능 요구사항

### 기능 1: 사용자 잔액 조회 및 표시

**설명**: 로그인한 사용자의 총 캐시 잔액을 조회하여 표시합니다.

**기술 상세**:
- **Provider**: `authProvider`
- **데이터 소스**: `user.balance`
- **포맷팅**: `NumberFormat('#,###')`으로 천 단위 콤마

**데이터 흐름**:
1. MyScreen 빌드
2. `ref.watch(authProvider)` 호출
3. authState.valueOrNull?.user 확인
4. user.balance 가져오기
5. NumberFormat으로 포맷팅
6. UI에 표시

**로딩 처리**:
- user가 null이면 0원 표시 (또는 로딩 인디케이터)
- 비로그인 상태 시 로그인 유도 메시지

**완료 조건**:
- ✅ 사용자 잔액 정상 표시
- ✅ 천 단위 콤마 포맷팅
- ✅ 로그인/비로그인 상태 처리
