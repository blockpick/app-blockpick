## 🎯 페이지 목적

사용자가 **다양한 게임을 탐색하고 선택**하여 게임 플레이 화면으로 진입하는 BlockPick의 **주요 진입점 화면**입니다.

이 화면은 BlockPick의 핵심 경험을 제공합니다:
- 4가지 게임 타입 (DAILY, SELECT, VIBE, OPTIMAL)
- 카테고리별 필터링 (Digital, Fashion, Beauty, Gift, Food)
- 다양한 정렬 옵션 (인기순, 최신순, 마감임박순, 가격순)
- 직관적인 게임 카드 UI

## ⚙️ 기능 요구사항

### 기능 1: 탭 기반 게임 타입 필터링

**설명**: 사용자가 DAILY, SELECT, VIBE, OPTIMAL 탭을 선택하여 게임 타입별로 필터링합니다.

**기술 상세**:
- **TabController**: HomeScreen에서 4개 탭 관리
- **TabBarView**: 각 탭에 GameListScreen 또는 OptimalGameListScreen 표시
- **Riverpod Provider**: `gamesByTypeProvider(GameType)`로 타입별 게임 조회

**탭별 게임 타입**:
| 탭 | GameType | 설명 |
|----|----------|------|
| DAILY | GameType.daily | 일일 게임 (1개 선택) |
| SELECT | GameType.select | 선택 게임 (3~10개 선택) |
| VIBE | GameType.vibe | 바이브 게임 (이미지 배경) |
| OPTIMAL | (별도 화면) | 최적화 게임 |

**데이터 흐름**:
1. 사용자가 탭 선택
2. TabController가 탭 인덱스 변경
3. TabBarView가 해당 GameListScreen 표시
4. GameListScreen이 `gamesByTypeProvider` 호출
5. Provider가 `gamesProvider`에서 모든 게임 조회
6. gameType에 따라 필터링 (예: "DAILY", "SELECT", "VIBE")
7. GameRound 리스트 반환

**완료 조건**:
- ✅ 탭 전환 시 부드러운 애니메이션
- ✅ 각 탭에 해당하는 게임만 표시
- ✅ 탭 인디케이터 색상 변경

### 기능 2: 카테고리 필터링

**설명**: 사용자가 카테고리 칩을 선택하여 특정 카테고리의 게임만 표시합니다.

**카테고리 목록**:
- **ALL**: 모든 게임 (기본값)
- **Digital**: 디지털 기기 (iPhone, MacBook, AirPods 등)
- **Fashion**: 패션 아이템 (가방, 의류 등)
- **Gift**: 기프트카드, 상품권
- **Food**: 음식, 외식 쿠폰

**인터랙션**:
1. 사용자가 카테고리 칩 터치
2. `_selectedCategory` 상태 업데이트
3. 칩 스타일 변경 (선택됨 → 파란색, 미선택 → 흰색)
4. `_buildContent()`에서 필터링 로직 실행
5. 필터링된 게임만 그리드에 표시

**필터링 로직**:
```dart
if (_selectedCategory != 'ALL') {
  filteredGames = filteredGames
    .where((game) => game.category == _selectedCategory)
    .toList();
}
```

**완료 조건**:
- ✅ 카테고리 칩 선택 시 해당 카테고리 게임만 표시
- ✅ ALL 선택 시 모든 게임 표시
- ✅ 선택된 칩 강조 표시
- ✅ 가로 스크롤 가능

### 기능 3: 정렬 기능

**설명**: 사용자가 정렬 드롭다운을 사용하여 게임 목록을 다양한 기준으로 정렬합니다.

**정렬 옵션**:
1. **Most Popular** (인기순): 참여자 수 많은 순
2. **Newest** (최신순): 최근 생성된 순
3. **Ending Soon** (마감임박순): 남은 시간 짧은 순
4. **Price Low to High** (가격 낮은 순): 참가비 낮은 순

**기술 구현**:
- **PopupMenuButton**: 드롭다운 메뉴
- **sortedGamesProvider**: 정렬 로직 Provider
- **초기값**: 'popular'

**정렬 로직** (sortedGamesProvider):
```dart
switch (sortBy) {
  case 'popular':
    sorted.sort((a, b) => b.participants.compareTo(a.participants));
    break;
  case 'newest':
    sorted.sort((a, b) => b.id.compareTo(a.id));
    break;
  case 'ending_soon':
    sorted.sort((a, b) {
      if (a.timeLeft == 'Ended') return 1;
      if (b.timeLeft == 'Ended') return -1;
      return a.timeLeft.compareTo(b.timeLeft);
    });
    break;
  case 'price_low':
    sorted.sort((a, b) => a.currentPrice.compareTo(b.currentPrice));
    break;
}
```

**완료 조건**:
- ✅ 정렬 옵션 선택 시 게임 목록 재정렬
- ✅ 드롭다운 메뉴 정상 동작
- ✅ 선택된 정렬 옵션 표시

### 기능 5: GraphQL 데이터 조회

**설명**: GraphQL API를 통해 게임 목록을 조회하고, Riverpod으로 상태 관리합니다.

**GraphQL Query**:
```graphql
query GetGames {
  getGames {
    success
    code
    message
    games {
      id
      title
      description
      gameType
      status
      maxEntries
      entryFee
      startTime
      endTime
      gridRows
      gridCols
      gameProducts {
        id
        product {
          id
          name
          brand
          category
          defaultImage
          imageUrl
          price
          originalPrice
        }
      }
    }
  }
}
```

**Riverpod Provider 구조**:

1. **gamesProvider**: 모든 게임 조회
   - GraphQL Query 실행
   - Game 리스트 반환
   - 에러 시 빈 리스트 반환

2. **gamesByTypeProvider(GameType)**: 타입별 게임 필터링
   - gamesProvider에서 모든 게임 가져옴
   - gameType으로 필터링
   - GameRound로 변환하여 반환

3. **sortedGamesProvider(List, sortBy)**: 게임 정렬
   - 입력받은 게임 리스트를 sortBy 기준으로 정렬
   - 정렬된 리스트 반환

**데이터 흐름**:
```
[GraphQL API]
    ↓
[gamesProvider] ← Game 리스트
    ↓
[gamesByTypeProvider] ← GameType 필터링
    ↓
[GameListScreen] ← 카테고리 필터링
    ↓
[sortedGamesProvider] ← 정렬
    ↓
[GameGrid] ← 화면 표시
```

**에러 처리**:
- GraphQL 에러 시: 빈 리스트 반환 + 콘솔 로그
- 파싱 에러 시: 해당 게임 스킵, 나머지 게임 표시
- 네트워크 에러 시: 에러 상태 표시 + Retry 버튼

**완료 조건**:
- ✅ GraphQL 쿼리 정상 실행
- ✅ 게임 데이터 파싱 성공
- ✅ Riverpod Provider 연결
- ✅ 에러 처리 구현
