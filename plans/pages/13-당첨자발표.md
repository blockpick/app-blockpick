## 🎯 페이지 목적

당첨자 발표 화면은 BlockPick 게임의 **투명성과 신뢰성을 보여주는 핵심 화면**입니다.

주요 목적:
- **당첨자 공개**: 모든 게임의 당첨자를 투명하게 공개
- **나의 당첨 확인**: 사용자가 자신의 당첨 내역을 쉽게 확인
- **커뮤니티 신뢰 구축**: 실제 당첨 사례를 보여줌으로써 서비스 신뢰도 향상
- **참여 유도**: 다른 사용자의 당첨을 보고 게임 참여 동기 부여

## 📊 데이터 모델

### WinnerModel

```dart
class WinnerModel {
  final String id;
  final String prizeName;         // 상품명
  final String prizeImage;        // 상품 이미지 경로
  final PrizeType prizeType;      // PREMIUM or SHOP
  final String userName;          // 당첨자 이름
  final String userAvatar;        // 아바타 URL
  final DateTime winDate;         // 당첨 날짜
  final bool isMyWin;             // 내 당첨 여부

  String get prizeTypeBadge {
    switch (prizeType) {
      case PrizeType.premium:
        return '💎 프리미엄';
      case PrizeType.shop:
        return '🛒 쇼핑몰';
    }
  }
}

enum PrizeType { premium, shop }
```

### Mock Data

**파일**: `lib/data/mock_winner_data.dart`

```dart
class MockWinnerData {
  static List<WinnerModel> getAllWinners() { /* ... */ }

  static List<WinnerModel> filterByType(PrizeType? type) {
    if (type == null) return getAllWinners();
    return getAllWinners().where((w) => w.prizeType == type).toList();
  }

  static List<WinnerModel> filterMyWins(PrizeType? type) {
    final myWins = getAllWinners().where((w) => w.isMyWin).toList();
    if (type == null) return myWins;
    return myWins.where((w) => w.prizeType == type).toList();
  }
}
```
