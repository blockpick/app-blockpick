## 🎯 페이지 목적

사용자가 이메일 인증을 거쳐 BlockPick에 회원가입할 수 있는 화면입니다.

주요 목적:
- **안전한 회원가입**: 이메일 인증 코드 확인 후 계정 생성
- **3단계 프로세스**: 이메일 발송 → 코드 확인 → 비밀번호/닉네임 설정
- **자동 지갑 생성**: 회원가입 성공 시 블록체인 지갑 자동 생성 (사용자 모르게)
- **중복 방지**: 이메일/닉네임 중복 체크
- **약관 동의**: 이용약관 및 개인정보처리방침 동의

### 4. Step 3: 비밀번호 입력 필드

**비밀번호 규칙**:

**비밀번호 강도 표시**:
- **약함**: ●○○○○ (빨간색) - 8자 미만
- **보통**: ●●●○○ (주황색) - 8자 + 영문 + 숫자
- **강함**: ●●●●● (초록색) - 8자 + 영문 + 숫자 + 특수문자

**실시간 검증**:
```dart
String? _validatePassword(String? value) {
  if (value == null || value.isEmpty) {
    return '비밀번호를 입력해주세요';
  }

  final rules = [
    (value.length >= 8, '8자 이상'),
    (RegExp(r'[a-zA-Z]').hasMatch(value), '영문 포함'),
    (RegExp(r'[0-9]').hasMatch(value), '숫자 포함'),
    (RegExp(r'[!@#$%^&*(),.?":{}|<>]').hasMatch(value), '특수문자 포함'),
  ];

  // UI에 체크리스트 표시
  for (var rule in rules) {
    // rule.0: 조건 만족 여부
    // rule.1: 규칙 텍스트
  }

  if (!rules[0].$1 || !rules[1].$1 || !rules[2].$1) {
    return '비밀번호는 8자 이상, 영문, 숫자를 포함해야 합니다';
  }

  return null;
}
```

**비밀번호 확인 필드**:
- **검증**: 비밀번호와 일치 확인
- **에러**: "비밀번호가 일치하지 않습니다"

## ⚙️ 기능 요구사항

### 기능 1: Step 1 - 이메일 인증 코드 발송

**GraphQL Mutation**:
```graphql
mutation SendVerificationCode($email: String!, $verifyType: VerifyType!) {
  sendVerificationCode(email: $email, verifyType: $verifyType) {
    success
    code
    message
  }
}
```

**Input**:
- `email`: String! (이메일 주소)
- `verifyType`: "SIGN_UP" (고정)

**프로세스**:

1. **검증**:
   - 이메일 형식 체크
   - 빈 값 체크

2. **Mutation 전송**:
   ```dart
   final authProvider = ref.read(authProvider.notifier);
   await authProvider.sendSignUpVerificationCode(email);
   ```

3. **응답 처리**:
   - **성공**:
     - SnackBar: "인증 코드가 발송되었습니다"
     - Step 2로 전환
     - 타이머 시작 (3분)
   - **실패**:
     - 에러 메시지 표시
     - 버튼 활성화

**완료 조건**:
- ✅ 이메일 검증
- ✅ Mutation 전송
- ✅ 성공 시 Step 2로 전환
- ✅ 에러 처리

---

### 기능 2: Step 2 - 인증 코드 확인

**GraphQL Mutation**:
```graphql
mutation VerifyCode($input: VerifyCodeRequest!) {
  verifyCode(input: $input) {
    success
    code
    message
  }
}
```

**Input**:
- `email`: String!
- `code`: String! (6자리 숫자)
- `verifyType`: "SIGN_UP"

**프로세스**:

1. **자동 제출**:
   - 6자리 모두 입력 시 자동으로 검증 시작

2. **Mutation 전송**:
   ```dart
   final result = await authProvider.verifySignUpCode(
     email: email,
     code: code,
   );
   ```

3. **응답 처리**:
   - **성공**:
     - Step 3으로 전환
   - **실패**:
     - 코드 입력 필드 클리어
     - 에러 메시지: "인증 코드가 올바르지 않습니다"
     - 첫 번째 필드로 포커스 이동

4. **타이머 만료**:
   - "시간 만료! 코드를 재발송하세요"
   - 재발송 버튼 활성화

**완료 조건**:
- ✅ 6자리 코드 입력
- ✅ 자동 포커스 이동
- ✅ Mutation 전송
- ✅ 성공 시 Step 3로 전환
- ✅ 타이머 처리 (3분)
- ✅ 재발송 기능

### 기능 3: Step 2 - 코드 재발송

- ✅ 타이머 리셋

### 기능 5: 비밀번호 강도 표시

**구현**:
```dart
enum PasswordStrength { weak, medium, strong }

PasswordStrength _calculatePasswordStrength(String password) {
  if (password.length < 8) return PasswordStrength.weak;

  final hasLetter = RegExp(r'[a-zA-Z]').hasMatch(password);
  final hasNumber = RegExp(r'[0-9]').hasMatch(password);
  final hasSpecial = RegExp(r'[!@#$%^&*(),.?":{}|<>]').hasMatch(password);

  if (hasLetter && hasNumber && hasSpecial) {
    return PasswordStrength.strong;
  } else if (hasLetter && hasNumber) {
    return PasswordStrength.medium;
  } else {
    return PasswordStrength.weak;
  }
}

Widget _buildPasswordStrengthIndicator() {
  final strength = _calculatePasswordStrength(_passwordController.text);

  return Row(
    children: [
      Text('비밀번호 강도: '),
      _buildDot(strength, 0),
      _buildDot(strength, 1),
      _buildDot(strength, 2),
      _buildDot(strength, 3),
      _buildDot(strength, 4),
      SizedBox(width: 8),
      Text(
        strength == PasswordStrength.weak ? '약함' :
        strength == PasswordStrength.medium ? '보통' : '강함',
        style: TextStyle(
          color: strength == PasswordStrength.weak ? Colors.red :
                 strength == PasswordStrength.medium ? Colors.orange :
                 Colors.green,
        ),
      ),
    ],
  );
}
```

**완료 조건**:
- ✅ 실시간 강도 계산
- ✅ 색상별 도트 표시

## 📝 기술 노트

### 이메일 인증 플로우

**보안**:
- 인증 코드: 6자리 숫자 (000000-999999)
- 유효 시간: 3분
- 재발송 쿨다운: 30초
- 서버에서 이메일 중복 체크

**타이머 구현**:
```dart
Timer? _timer;
int _remainingSeconds = 180; // 3분

void _startTimer() {
  _timer = Timer.periodic(Duration(seconds: 1), (timer) {
    setState(() {
      if (_remainingSeconds > 0) {
        _remainingSeconds--;
      } else {
        _timer?.cancel();
        // 타이머 만료 처리
      }
    });
  });
}

@override
void dispose() {
  _timer?.cancel();
  super.dispose();
}
```

### 비밀번호 보안

**저장**:
- 클라이언트: 평문 전송 (HTTPS)
- 서버: bcrypt 해시 저장

**규칙**:
- 최소 8자
- 영문 + 숫자 필수
- 특수문자 권장

**강도 계산**:
- 약함: < 8자 또는 단일 타입
- 보통: 8자 + 영문 + 숫자
- 강함: 8자 + 영문 + 숫자 + 특수문자
