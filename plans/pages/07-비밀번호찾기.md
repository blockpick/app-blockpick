## 🎯 페이지 목적

사용자가 비밀번호를 잊어버렸을 때 이메일 인증을 통해 새 비밀번호를 설정할 수 있는 화면입니다.

주요 목적:
- **비밀번호 복구**: 이메일 인증 후 새 비밀번호 설정
- **3단계 프로세스**: 이메일 발송 → 코드 확인 → 새 비밀번호 설정
- **보안**: 이메일 소유 확인 후에만 비밀번호 변경 허용
- **자동 로그인**: 비밀번호 변경 성공 시 로그인 페이지로 리디렉션

## ⚙️ 기능 요구사항

### 기능 1: Step 1 - 이메일 인증 코드 발송

**GraphQL Mutation**:
```graphql
mutation SendVerificationCode($email: String!, $verifyType: VerifyType!) {
  sendVerificationCode(email: $email, verifyType: $verifyType) {
    success
    code
    message
  }
}
```

**Input**:
- `email`: String! (이메일 주소)
- `verifyType`: "CHANGE_PASSWORD" (고정)

**프로세스**:

1. **검증**:
   - 이메일 형식 체크
   - 빈 값 체크

2. **Mutation 전송**:
   ```dart
   final authProvider = ref.read(authProvider.notifier);
   await authProvider.sendPasswordResetCode(email);
   ```

3. **응답 처리**:
   - **성공**:
     - SnackBar: "인증 코드가 발송되었습니다"
     - Step 2로 전환
     - 타이머 시작 (3분)
   - **실패**:
     - 에러 메시지 표시
     - 가능한 에러:
       - "등록되지 않은 이메일입니다"
       - "이메일 발송에 실패했습니다"

**완료 조건**:
- ✅ 이메일 검증
- ✅ Mutation 전송
- ✅ 성공 시 Step 2로 전환
- ✅ 에러 처리 (미등록 이메일)

### 기능 2: Step 2 - 인증 코드 확인

**GraphQL Mutation**:
```graphql
mutation VerifyCode($input: VerifyCodeRequest!) {
  verifyCode(input: $input) {
    success
    code
    message
  }
}
```

**Input**:
- `email`: String!
- `code`: String! (6자리 숫자)
- `verifyType`: "CHANGE_PASSWORD"

**프로세스**:

1. **자동 제출**:
   - 6자리 모두 입력 시 자동으로 검증 시작

2. **Mutation 전송**:
   ```dart
   final result = await authProvider.verifyPasswordResetCode(
     email: email,
     code: code,
   );
   ```

3. **응답 처리**:
   - **성공**:
     - Step 3으로 전환
   - **실패**:
     - 코드 입력 필드 클리어
     - 에러 메시지: "인증 코드가 올바르지 않습니다"
     - 첫 번째 필드로 포커스 이동

4. **타이머 만료**:
   - "시간 만료! 코드를 재발송하세요"
   - 재발송 버튼 활성화

**완료 조건**:
- ✅ 6자리 코드 입력
- ✅ 자동 포커스 이동
- ✅ Mutation 전송
- ✅ 성공 시 Step 3로 전환
- ✅ 타이머 처리 (3분)
- ✅ 재발송 기능

### 기능 3: Step 3 - 새 비밀번호 설정

```graphql
mutation ResetPassword($input: ResetPasswordRequest!) {
  resetPassword(input: $input) {
    success
    code
    message
  }
}
```

**Input**:
- `email`: String! (Step 1에서 입력한 이메일)

**프로세스**:

1. **검증**:

2. **Mutation 전송**:

     - 에러 메시지 표시
     - 가능한 에러:
       - "인증 코드가 만료되었습니다"
       - "비밀번호 변경에 실패했습니다"

4. **성공 다이얼로그**:
   ```
   ┌────────────────────────────────┐
   ```

5. **자동 리디렉션**:

**완료 조건**:

## 📱 사용자 시나리오

### 시나리오 1: 정상 비밀번호 재설정 (성공)

**전제 조건**:
- 사용자가 이미 회원가입을 완료함
- 올바른 이메일을 알고 있음

**사용자 행동**:

**Step 1: 이메일 입력**
1. 로그인 페이지에서 "비밀번호를 잊으셨나요?" 클릭
2. `/forgot-password` 페이지 접속
3. 이메일 입력: `user@example.com`
4. [인증 코드 발송] 버튼 클릭

**화면 반응**:
1. 이메일 검증 ✅
2. Mutation 전송 (1초)
3. 성공 SnackBar: "인증 코드가 발송되었습니다"
4. Step 2로 전환 (페이드 애니메이션)
5. 타이머 시작: "03:00"

**Step 2: 코드 확인**
6. 이메일 확인 → 코드: `123456`
7. 코드 입력: `1` → `2` → `3` → `4` → `5` → `6`
   - 자동 포커스 이동
   - 6자리 입력 완료 시 자동 검증 시작

**화면 반응**:
1. Mutation 전송 (verifyCode)
2. 성공 시: Step 3으로 전환

**Step 3: 새 비밀번호 설정**
8. 새 비밀번호 입력: `NewPassword123!`
   - 강도 표시: ●●●●● 강함 (초록색)
   - 규칙 체크: 8자 ✅, 영문 ✅, 숫자 ✅, 특수문자 ✅
9. 비밀번호 확인: `NewPassword123!`
   - 일치 확인: ✅
10. [비밀번호 변경] 버튼 클릭

**화면 반응**:
1. 버튼 → CircularProgressIndicator
2. Mutation 전송 (resetPassword)
3. 성공 다이얼로그:
   ```
   ┌────────────────────────────────┐
   │  ✅ 비밀번호 변경 완료!         │
   │                                │
   │  새 비밀번호로 로그인해주세요    │
   │                                │
   │  2초 후 로그인 페이지로 이동...  │
   │                                │
   │     [로그인하러 가기 →]         │
   └────────────────────────────────┘
   ```
4. 2초 후 `/login` 페이지로 리디렉션

**예상 시간**: 2-3분

3. 코드 입력 필드 클리어
4. 빨간색 에러 메시지 표시
5. 첫 번째 필드로 포커스 이동

---

### 시나리오 4: 타이머 만료

**Step 2에서**:
1. 3분 경과 (타이머: 00:00)

**화면 반응**:
1. 타이머 빨간색 표시
2. 에러 메시지: "시간 만료! 코드를 재발송하세요"
3. 코드 입력 필드 비활성화
4. [재발송] 버튼 활성화

**재발송 클릭**:
1. Mutation 재전송
2. 타이머 리셋: 03:00
3. 코드 입력 필드 활성화 + 클리어

---

### 시나리오 5: 인증 코드 만료 (Step 3에서)

**전제 조건**:
- Step 2 코드 확인 후 오랜 시간 경과
- 서버에서 인증 코드 만료 처리 (예: 10분)

**Step 3에서**:
1. 비밀번호 입력 완료
2. [비밀번호 변경] 버튼 클릭

**화면 반응**:
1. Mutation 전송
2. 에러 응답:
   ```json
   {
     "success": false,
     "code": "VERIFICATION_CODE_EXPIRED",
     "message": "인증 코드가 만료되었습니다"
   }
   ```
3. 에러 다이얼로그:
   ```
   ┌────────────────────────────────┐
   │  ⚠️ 인증 코드 만료              │
   │                                │
   │  인증 코드가 만료되었습니다.     │
   │  처음부터 다시 시도해주세요.     │
   │                                │
   │     [처음으로]                 │
   └────────────────────────────────┘
   ```
4. [처음으로] 클릭 → Step 1로 리셋

**세션 관리**:
- 비밀번호 변경 후 모든 기존 세션 무효화 (서버)
- 사용자는 새 비밀번호로 다시 로그인 필요
