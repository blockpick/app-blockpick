## 🎯 페이지 목적

사용자의 **계정 관리, 앱 설정, 알림 설정**을 제공하는 **설정 페이지**입니다.

이 화면은 다음과 같은 주요 목적을 가집니다:
- **계정 관리**: 프로필 수정, 비밀번호 변경, 로그아웃, 회원 탈퇴
- **알림 설정**: 푸시 알림, 이메일 알림, 마케팅 수신 동의 관리
- **앱 정보**: 버전 정보, 이용약관, 개인정보처리방침, 고객센터
- **향후 확장**: 다크 모드, 언어 설정 등

## ⚙️ 기능 요구사항

### 기능 1: 사용자 정보 표시

**설명**: 로그인한 사용자의 정보를 표시합니다.

**기술 상세**:
- **Provider**: `authProvider`
- **데이터 소스**: `authState.valueOrNull?.user`
- **표시 정보**:
  - 아바타: 닉네임 또는 이메일의 첫 글자
  - 닉네임: user.nickname ?? "사용자"
  - 이메일: user.email

**표시 조건**:
- `user != null` 일 때만 표시
- 비로그인 시 사용자 정보 섹션 숨김

**완료 조건**:
- ✅ 사용자 정보 정상 표시
- ✅ 아바타 첫 글자 표시
- ✅ 로그인/비로그인 상태 처리

---

### 기능 2: 로그아웃

**설명**: 사용자가 로그아웃할 수 있는 기능을 제공합니다.

**기술 상세**:
- **액션**: "로그아웃" 아이템 터치
- **다이얼로그**: AlertDialog
- **버튼**: 취소 / 로그아웃

**로그아웃 로직**:
1. 사용자가 "로그아웃" 선택
2. `showDialog<bool>` 호출 → 확인 다이얼로그 표시
3. 사용자가 "로그아웃" 버튼 터치 → `true` 반환
4. `ref.read(authProvider.notifier).signOut()` 호출
5. AuthProvider에서:
   - SharedPreferences에서 토큰 삭제
   - 상태를 null로 변경
6. `context.go('/')` → 홈으로 네비게이션

**완료 조건**:
- ✅ 로그아웃 확인 다이얼로그 표시
- ✅ 로그아웃 정상 동작
- ✅ 토큰 삭제
- ✅ 홈으로 네비게이션

---

### 기능 3: 회원 탈퇴 (향후)

**설명**: 사용자가 회원 탈퇴할 수 있는 기능을 제공합니다.

**기술 상세**:
- **액션**: "회원 탈퇴" 아이템 터치
- **다이얼로그**: AlertDialog
- **버튼**: 취소 / 탈퇴 (빨간색)
- **GraphQL Mutation** (향후):
  ```graphql
  mutation DeleteAccount {
    deleteAccount {
      success
      message
    }
  }
  ```

**회원 탈퇴 로직** (향후):
1. 사용자가 "회원 탈퇴" 선택
2. `showDialog<bool>` 호출 → 확인 다이얼로그 표시
3. 사용자가 "탈퇴" 버튼 터치 → `true` 반환
4. GraphQL Mutation: deleteAccount 호출
5. 서버에서:
   - 사용자 계정 비활성화 또는 삭제
   - 관련 데이터 삭제 (참가 내역, 거래 내역 등)
6. 로그아웃 처리
7. `context.go('/')` → 홈으로 네비게이션

**주의 사항**:
- 회원 탈퇴는 되돌릴 수 없음을 명확히 안내
- 보유 캐시가 있을 경우 환불 안내
- 진행 중인 게임이 있을 경우 경고

**완료 조건** (향후):
- ⏳ 회원 탈퇴 확인 다이얼로그 표시
- ⏳ GraphQL deleteAccount 호출
- ⏳ 계정 삭제 처리
- ⏳ 로그아웃 및 네비게이션

### 기능 4: 프로필 수정 (향후)

**설명**: 사용자가 닉네임, 이메일 등을 수정할 수 있는 기능을 제공합니다.

**기술 상세**:
- **액션**: "프로필 수정" 아이템 터치
- **다이얼로그 또는 페이지**: 프로필 수정 폼
- **수정 가능 항목**:
  - 닉네임
  - 프로필 이미지 (향후)
  - 이메일 (인증 필요)

**GraphQL Mutation** (향후):
```graphql
mutation UpdateProfile($nickname: String, $email: String) {
  updateProfile(nickname: $nickname, email: $email) {
    success
    user {
      id
      nickname
      email
    }
  }
}
```

**프로필 수정 로직** (향후):
1. 사용자가 "프로필 수정" 선택
2. 프로필 수정 다이얼로그 또는 페이지 표시
3. 현재 닉네임, 이메일 표시 (수정 가능)
4. 사용자가 수정 후 "저장" 버튼 터치
5. 유효성 검사 (닉네임 길이, 이메일 형식 등)
6. GraphQL Mutation: updateProfile 호출
7. 서버에서 프로필 업데이트
8. AuthProvider 상태 업데이트
9. 다이얼로그 닫기 + SnackBar ("프로필이 업데이트되었습니다.")

**완료 조건** (향후):
- [ ] 프로필 수정 다이얼로그 UI
- [ ] 닉네임, 이메일 수정 폼
- [ ] 유효성 검사
- [ ] GraphQL updateProfile 호출
- [ ] AuthProvider 상태 업데이트

### 기능 5: 비밀번호 변경 (향후)

**설명**: 사용자가 비밀번호를 변경할 수 있는 기능을 제공합니다.

**기술 상세**:
- **액션**: "비밀번호 변경" 아이템 터치
- **다이얼로그 또는 페이지**: 비밀번호 변경 폼
- **입력 필드**:
  - 현재 비밀번호
  - 새 비밀번호
  - 새 비밀번호 확인

**GraphQL Mutation** (향후):
```graphql
mutation ChangePassword($currentPassword: String!, $newPassword: String!) {
  changePassword(currentPassword: $currentPassword, newPassword: $newPassword) {
    success
    message
  }
}
```

**비밀번호 변경 로직** (향후):
1. 사용자가 "비밀번호 변경" 선택
2. 비밀번호 변경 다이얼로그 표시
3. 사용자가 현재 비밀번호, 새 비밀번호 입력
4. 유효성 검사:
   - 현재 비밀번호 일치 확인
   - 새 비밀번호 강도 확인 (8자 이상, 영문+숫자+특수문자)
   - 새 비밀번호와 확인 일치 확인
5. GraphQL Mutation: changePassword 호출
6. 서버에서 비밀번호 업데이트
7. 다이얼로그 닫기 + SnackBar ("비밀번호가 변경되었습니다.")

**완료 조건** (향후):
