## 🎯 시스템 목적

디자인 시스템은 BlockPick 앱의 **일관된 시각적 경험과 개발 효율성을 제공하는 핵심 기반**입니다.

주요 목적:
- **일관성**: 모든 화면에서 통일된 색상, 타이포그래피, 간격 사용
- **재사용성**: 공통 컴포넌트로 개발 시간 단축 및 유지보수 용이
- **확장성**: 새로운 기능 추가 시 기존 디자인 언어 활용
- **브랜딩**: BlockPick만의 독특한 시각적 아이덴티티 확립

| 이름 | 값 | 용도 |
|------|-----|------|
| **radiusSm** | 4dp | 배지, 작은 버튼 |
| **radiusMd** | 8dp | 입력 필드, 칩 |

```dart
  vertical: AppConstants.paddingMd,   // 12dp

```

## 🎬 6. 애니메이션 시스템

### 6.1 Duration (지속 시간)

| 이름 | 값 | 용도 |
|------|-----|------|
| **Fast** | 150ms | 버튼 탭, 호버 |
| **Normal** | 300ms | 화면 전환, 모달 |
| **Slow** | 500ms | 복잡한 애니메이션 |

### 6.2 Curve (곡선)

| 이름 | 값 | 용도 |
|------|-----|------|
| **EaseIn** | `Curves.easeIn` | 진입 애니메이션 |
| **EaseOut** | `Curves.easeOut` | 퇴장 애니메이션 |
| **EaseInOut** | `Curves.easeInOut` | 양방향 애니메이션 |
| **Bounce** | `Curves.bounceOut` | 재미있는 효과 |

### 6.3 사용 예시

#### Fade In Animation
```dart
AnimatedOpacity(
  opacity: isVisible ? 1.0 : 0.0,
  duration: Duration(milliseconds: 300),
  curve: Curves.easeIn,
  child: Container(...),
)
```

#### Slide Animation
```dart
SlideTransition(
  position: Tween<Offset>(
    begin: Offset(0, 1),
    end: Offset.zero,
  ).animate(CurvedAnimation(
    parent: controller,
    curve: Curves.easeOut,
  )),
  child: Container(...),
)
```
