## 🎯 프로세스 목적

사용자가 선택한 좌표(블록)로 게임에 참가하는 **전체 End-to-End 프로세스**를 관리합니다.

이 프로세스는 BlockPick의 핵심 가치인:
- 블록체인 기반 투명성 (온체인 좌표 암호화)
- 사용자 프라이버시 보호 (클라이언트 측 암호화)
- 가스비 제로 (서버 가스비 대납)
- 완전 자동화된 참가 플로우

를 구현합니다.

## ⚙️ 기능 요구사항

### 기능 1: 블록체인 지갑 관리

**설명**: 사용자의 블록체인 지갑을 안전하게 생성하고 관리합니다.

**기술 상세**:
- **저장소**: Flutter Secure Storage
  - iOS: Keychain
  - Android: EncryptedSharedPreferences
- **키 생성**: `EthPrivateKey.createRandom()`
- **저장 정보**:
  - `blockchain_wallet_private_key`: 개인키 (Hex)
  - `blockchain_wallet_address`: 지갑 주소 (0x...)

**주요 메서드**:

1. **`getOrCreateWallet()`**:
   ```dart
   Future<Credentials> getOrCreateWallet() async {
     final wallet = await loadWallet();
     if (wallet != null) {
       return wallet; // 기존 지갑 로드
     }
     // 새 지갑 생성
     final (credentials, _) = await createWallet();
     return credentials;
   }
   ```

2. **`createWallet()`**:
   - EthPrivateKey 랜덤 생성
   - Secure Storage에 저장
   - 지갑 주소 반환

3. **`loadWallet()`**:
   - Secure Storage에서 개인키 로드
   - EthPrivateKey 복원
   - null 반환 (지갑 없음)

**보안**:
- ✅ 개인키는 디바이스에만 저장 (서버 전송 금지)
- ✅ Secure Storage 암호화
- ✅ 백업 권장 (향후 mnemonic 지원)

**완료 조건**:
- ✅ 지갑 자동 생성
- ✅ 지갑 로드/저장
- ✅ Secure Storage 암호화
- ✅ 에러 처리 (권한 거부 등)

### 기능 2: 하이브리드 암호화 키 획득

**설명**: 3단계 하이브리드 전략으로 암호화 키를 획득합니다.

**전략 상세**:

#### Step 3-1: 온체인 View 조회

**목적**: 기존 키 재사용 (가스비 절약)

**구현**:
```dart
// SmartContractService.getEncryptionKey()
final encryptionKey = await contractService.getEncryptionKey(
  contractAddress: contractAddress,
  userIndex: userIndex,
  userAddress: walletAddress,
);
```

**성공 조건**:
- 키가 이미 블록체인에 존재
- 사용자가 키 소유자 (owner check)
- RPC 연결 정상

**실패 시**:
- 예외 발생 → Step 3-2로

#### Step 3-2: 서버 가스비 대납 생성

**목적**: 사용자 가스비 부담 없이 키 생성

**구현**:
```graphql
mutation RequestEncryptionKey($input: RequestEncryptionKeyInput!) {
  requestEncryptionKey(input: $input) {
    success
    code
    message
    encryptionKey      # 응답에 키 포함 (옵션)
    contractAddress
    txHash
    userAddress
    index
    requestId          # 폴링용 ID (향후)
  }
}
```

**Input**:
- `gameId`: 게임 ID
- `userAddress`: 지갑 주소
- `index`: userIndex (SHA256 해시)

**서버 동작**:
1. 서버 지갑으로 `requestEncryptionKey()` 트랜잭션 실행
2. 가스비 서버 부담
3. 블록체인 이벤트: `EncryptionKeyGenerated(index, sender, key)`
4. 응답 반환:
   - 성공: `encryptionKey` 포함 (즉시 사용)
   - 또는: `txHash` 반환 (Step 3-3으로)

**에러 코드**:
- `KEY_REQUEST_PROCESSING_FAILED`: Outbox 처리 실패
- `KEY_ALREADY_EXISTS`: 이미 키 존재
- `GAME_NOT_FOUND`: 게임 없음

#### Step 3-3: 온체인 폴링

**목적**: 서버 응답에 키가 없을 경우 블록체인에서 폴링

**구현**:
```dart
const maxAttempts = 30;
const pollInterval = Duration(seconds: 2);

for (int i = 0; i < maxAttempts; i++) {
  try {
    final key = await contractService.getEncryptionKey(...);
    return key; // 성공
  } catch (e) {
    if (i < maxAttempts - 1) {
      await Future.delayed(pollInterval);
    } else {
      throw Exception('타임아웃: 60초');
    }
  }
}
```

**폴링 정책**:
- 최대 시도: 30회
- 간격: 2초
- 총 대기 시간: 60초
- 타임아웃: 예외 발생

**userIndex 생성 규칙**:
```dart
// 게임별로 고정 인덱스 사용 (중복 방지)
final rawIndex = '${walletAddress.toLowerCase()}-$gameId';
final bytes = utf8.encode(rawIndex);
final digest = sha256.convert(bytes);
final userIndex = digest.toString(); // 64자 hex
```

**완료 조건**:
- ✅ 3단계 하이브리드 전략 구현
- ✅ 기존 키 재사용 (Step 3-1)
- ✅ 서버 가스비 대납 (Step 3-2)

### 기능 3: 좌표 암호화

**설명**: 선택한 좌표를 AES-256-CBC로 암호화합니다.

**암호화 알고리즘**:
- **방식**: AES-256-CBC
- **키 길이**: 32바이트 (256비트)
- **IV**: 키의 앞 16바이트 (결정론적)
- **패딩**: PKCS7

**구현**:
```dart
String encryptCoordinate({
  required int row,
  required int col,
  required String encryptionKeyHex,
}) {
  // 1. 키 준비 (Hex → Bytes)
  var keyBytes = Uint8List.fromList(hex.decode(encryptionKeyHex));

  // 2. 16바이트 키인 경우 32바이트로 확장
  if (keyBytes.length == 16) {
    keyBytes = Uint8List.fromList([...keyBytes, ...keyBytes]);
  }

  final key = Key(keyBytes);
  final iv = IV(Uint8List.fromList(keyBytes.sublist(0, 16)));

  // 3. 암호화 객체 생성
  final encrypter = Encrypter(AES(key, mode: AESMode.cbc));

  // 4. 좌표 데이터 준비 (JSON)
  final coordinateData = {
    'row': row,
    'col': col,
    'timestamp': DateTime.now().toIso8601String(),
  };
  final plaintext = jsonEncode(coordinateData);

  // 5. 암호화
  final encrypted = encrypter.encrypt(plaintext, iv: iv);
  return encrypted.base64;
}
```

**입력**:
- `row`: 행 좌표 (0-999)
- `col`: 열 좌표 (0-999)
- `encryptionKeyHex`: 64자 hex 키

**출력**:
- Base64 암호문 (예: "a8f3d9c2...==")

**보안**:

### 기능 4: 지갑 주소 해시화

**설명**: 지갑 주소를 SHA-256으로 해시하여 익명성을 보장합니다.

**목적**:
- 서버는 원본 지갑 주소를 알 수 없음
- 백엔드 DB에는 해시만 저장
- 동일 사용자 식별 가능 (해시 일치)

**구현**:
```dart
import 'package:crypto/crypto.dart';
import 'dart:convert';

// 지갑 주소 해시화
final walletBytes = utf8.encode(walletAddress.toLowerCase());
final walletHash = sha256.convert(walletBytes).toString();

// idempotencyKey 생성 (128자 제한)
final timestamp = DateTime.now().millisecondsSinceEpoch;
final shortWalletHash = walletHash.substring(0, 16); // 64비트
final idempotencyKey = '$gameId-$shortWalletHash-$timestamp';
// 총 길이: 36 + 16 + 13 + 2 = 67자
```

**완료 조건**:
- ✅ SHA-256 해시
- ✅ 소문자 변환 (대소문자 통일)
- ✅ idempotencyKey 생성 (128자 이내)
- ✅ 서버에 원본 주소 미전송

### 기능 6: 엔트리 상태 폴링

**설명**: 블록체인 트랜잭션 확정을 추적합니다.

**폴링 서비스**:
```dart
// EntryStatusPollingService
Stream<EntryStatus> pollEntryStatus(String entryId) async* {
  const maxAttempts = 60;
  const pollInterval = Duration(seconds: 2);

  for (int i = 0; i < maxAttempts; i++) {
    final status = await _queryEntryStatus(entryId);
    yield status;

    if (status.isConfirmed) {
      break; // 확정 완료
    }

    await Future.delayed(pollInterval);
  }
}
```

**EntryStatus 모델**:
```dart
class EntryStatus {
  final String entryId;
  final String status;        // PENDING, CONFIRMED, FAILED
  final List<TxIntent> txIntents;
  final String? errorMessage;

  bool get isConfirmed => status == 'CONFIRMED';
}

class TxIntent {
  final String txHash;
  final String status;        // PENDING, CONFIRMED
  final DateTime? confirmedAt;
}
```

  @override
  GameJoinProgress? build() => null;

    required GameJoinStep step,
    String? message,
    String? txHash,

      step: step,
      message: message,
      txHash: txHash,
    );
  }

    required GameJoinStep step,
    required String errorMessage,

## 🔐 보안 정책

### 1. 개인키 보안
- ✅ **저장소**: Flutter Secure Storage (AES-256 암호화)
  - iOS: Keychain
  - Android: EncryptedSharedPreferences
- ✅ **전송 금지**: 개인키는 절대 서버에 전송하지 않음
- ✅ **백업 권장**: 향후 mnemonic 지원 예정

### 2. 좌표 프라이버시
- ✅ **클라이언트 측 암호화**: AES-256-CBC
- ✅ **서버는 평문 접근 불가**: 암호문만 저장
- ✅ **복호화 권한**: 게임 종료 후 공개 조건 충족 시만 가능

### 3. 지갑 주소 익명성
- ✅ **SHA-256 해시**: 원본 주소를 서버에 전송하지 않음
- ✅ **백엔드는 해시만 저장**: 역추적 불가
- ✅ **동일 사용자 식별**: 해시 일치로 가능

### 4. 데이터 보관
- ✅ **백엔드 저장**: coordCiphertext, signerWalletHash, entryId, gameId
- ✅ **노출 금지**: 원본 좌표, 개인키, 평문 지갑 주소
- ✅ **감사 로그**: 모든 요청 기록 (idempotencyKey 포함)
