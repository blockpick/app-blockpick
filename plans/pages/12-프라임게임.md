## 🎯 페이지 목적

사용자가 **상품의 최적가를 예측하여 입찰**하는 BlockPick의 새로운 게임 방식입니다.

기존 그리드 기반 게임과 달리, 프라임 게임은:
- **가격 휠 인터페이스**를 통한 직관적인 가격 선택
- **스크롤 기반 UX**로 부드러운 가격 탐색
- **상품 이미지를 배경**으로 한 몰입도 높은 디자인
- **간단한 입찰 프로세스**로 빠른 게임 참여

를 제공합니다.

**게임 메커니즘**:
1. 사용자는 상품의 최종 가격(실제 판매가)을 예측
2. 휠을 스크롤하여 예상 가격 선택
3. 입찰 버튼을 눌러 참여
4. 실제 가격과 가장 가까운 입찰이 승리

## ⚙️ 기능 요구사항

### 기능 1: 가격 휠 스크롤

**설명**: 사용자가 휠을 스크롤하여 원하는 가격을 선택합니다.

**기술 상세**:
- **위젯**: `ListWheelScrollView.useDelegate`
- **컨트롤러**: `FixedExtentScrollController`
- **델리게이트**: `ListWheelChildBuilderDelegate`

**가격 생성 로직**:
```dart
// OptimalGame 모델의 availablePrices getter
List<int> get availablePrices {
  final prices = <int>[];
  for (int price = maxPrice; price >= minPrice; price -= priceStep) {
    prices.add(price);
  }
  return prices;
}
```

**예시**:
- maxPrice: 1,590,000원
- minPrice: 1,000,000원
- priceStep: 1,000원
- 결과: 1,590,000원부터 1,000,000원까지 1,000원 단위로 591개 가격

**스크롤 동작**:
1. 사용자가 휠을 상하로 스크롤
2. `onSelectedItemChanged` 콜백 호출
3. 현재 인덱스 업데이트: `_currentIndex`
4. 선택된 가격 콜백: `onPriceSelected(prices[index])`
5. 햅틱 피드백 (선택 사항)

**물리 효과**:
- **Physics**: `FixedExtentScrollPhysics`
- **스냅**: 각 아이템 위치에 자동 정렬
- **관성**: 스크롤 시 부드러운 감속
- **바운스**: iOS/Android 기본 동작

**3D 효과**:
- **diameterRatio**: 1.5 (값이 작을수록 곡률이 큼)
- **perspective**: 0.003 (원근감 강도)
- **Transform.scale**: 중앙은 1.0, 주변은 0.85
- **Opacity**: 중앙은 1.0, 주변은 0.5

**완료 조건**:
- ✅ 부드러운 60fps 스크롤
- ✅ 정확한 스냅 위치 정렬
- ✅ 3D 효과 정상 표시
- ✅ 햅틱 피드백 동작

### 기능 5: 배경 상품 이미지

**설명**: 선택한 상품의 이미지를 배경에 표시하여 몰입도를 높입니다.

**구현 상세**:

1. **배경 레이어**:
   ```dart
   Positioned.fill(
     child: Stack(
       fit: StackFit.expand,
       children: [
         // 상품 이미지
         Image.asset(
           widget.backgroundImageUrl!,
           fit: BoxFit.contain,
           errorBuilder: (context, error, stackTrace) {
             return const SizedBox.shrink();
           },
         ),
         // 블러 효과 + 오버레이
         BackdropFilter(
           filter: ImageFilter.blur(sigmaX: 0, sigmaY: 0),
           child: Container(
             color: AppColors.deepWhite.withOpacity(0.2),
           ),
         ),
       ],
     ),
   )
   ```

2. **블러 강도**:
   - 현재: sigmaX 0, sigmaY 0 (블러 없음)
   - 조정 가능: 값을 높이면 블러 효과 증가
   - 권장: sigmaX 5, sigmaY 5 (약간의 블러)

3. **오버레이**:
   - 색상: 딥 화이트 (#FAFAFA)
   - Opacity: 0.2 (20%)
   - 용도: 텍스트 가독성 확보

4. **이미지 Fit**:
   - `BoxFit.contain`: 비율 유지, 전체 이미지 표시
   - 대안: `BoxFit.cover` (화면 꽉 채움, 잘림 가능)

**에러 처리**:
- 이미지 로드 실패 시: `SizedBox.shrink()` (빈 공간)
- null 이미지: 배경 레이어 자체를 렌더링하지 않음

**완료 조건**:
- ✅ 배경 이미지 정상 표시
- ✅ 블러 효과 적용
- ✅ 오버레이로 가독성 확보

   - 현재: StatefulWidget (로컬 상태)
   - 향후: Riverpod Provider (전역 상태)
   - 이유: 단순한 화면이므로 로컬 상태로 충분
