## 🎯 페이지 목적

사용자가 **대형 그리드(최대 1,000×1,000)에서 원하는 블록을 선택**하여 게임에 참여하는 BlockPick의 **가장 핵심적인 화면**입니다.

이 화면은 BlockPick의 차별화 포인트인:
- 세계 최초 모바일 대형 그리드 60fps 렌더링
- 직관적인 블록 선택 UX
- 전략적 재미 (어느 위치를 선택할까?)

를 구현합니다.

### UI 컴포넌트

#### 1. Pick HUD (좌상단)
- **위치**: 화면 좌상단, `SafeArea` 내
- **크기**: 120×40 dp
- **배경**: 반투명 흰색 (Opacity 0.9), 둥근 모서리 (radius 20)
- **내용**:
  - 텍스트: "3/5 picks" (현재 선택/최대 선택)
  - 폰트: Body Medium (16px, SemiBold)
  - 색상: Primary Blue (#5C72F5)
- **애니메이션**: 블록 선택 시 스케일 펄스 (1.0 → 1.1 → 1.0, 200ms)

#### 2. 미니맵 (우상단)
- **위치**: 화면 우상단, `SafeArea` 내
- **크기**: 120×120 dp (정사각형)
- **배경**: 흰색, 테두리 1px (#E0E0E0)
- **내용**:
  - 전체 그리드 축소판 (회색 배경)
  - 현재 뷰포트 영역 (흰색 테두리 박스)
  - 선택된 블록 폴리곤 (파란색)
- **인터랙션**: 터치하면 해당 위치로 그리드 이동 (애니메이션)

#### 3. 게임 그리드 (중앙)
- **위치**: 전체화면
- **렌더링**: `CustomPaint` 기반
- **배경**: 상품 이미지 또는 흰색
- **그리드 라인**: 회색 (#E0E0E0), LOD에 따라 두께 조절
- **선택된 블록**: 파란색 테두리 (두께 2px, #5C72F5)
- **선택된 블록 폴리곤**: 반투명 파란색 Fill (Opacity 0.2)

#### 4. 줌 컨트롤 (우하단)
- **위치**: 화면 우하단, 미니맵 아래
- **크기**: 각 버튼 48×48 dp
- **디자인**:
  - 원형 버튼
  - 흰색 배경, 그림자 (elevation 4)
  - 아이콘: + / - (회색 #757575)
- **간격**: 버튼 간 8dp
- **인터랙션**: 터치 시 햅틱 피드백

#### 5. 선택된 블록 바텀시트 (하단)
- **위치**: 화면 하단
- **표시 조건**: 1개 이상 블록 선택 시
- **애니메이션**: 슬라이드 업 (300ms, Ease-in-out)
- **높이**:
  - 최소: 80dp (1개 선택)
  - 중간: 40% 화면 (2-4개 선택)
  - 최대: 70% 화면 (5개 이상 선택)
- **내용**:
  - 헤더: "Selected Blocks (3/5)"
  - 블록 리스트 (스크롤 가능)
  - 푸터: "CLEAR" 버튼 + "Select blocks" 버튼

#### 6. 섹션 오버레이 (옵션)
- **위치**: 그리드 위 오버레이
- **표시 조건**: 줌 레벨이 낮을 때 (축소 상태)
- **내용**:
  - 3×3 구역 라벨 (A1, A2, ..., C3)
  - 각 구역의 테두리
  - 각 구역의 선택 블록 개수
- **폰트**: Display (32px, Bold), 흰색 + 검은색 Stroke
- **투명도**: 반투명 (Opacity 0.7)

## ⚙️ 기능 요구사항

### 기능 1: 대형 그리드 렌더링

**설명**: 10×10부터 1,000×1,000 크기의 거대한 그리드를 60fps로 부드럽게 렌더링합니다.

**기술 상세**:
- **렌더링 방식**: `CustomPaint` + `Canvas`
- **최적화**:
  - **Sparse Grid**: 빈 셀은 렌더링하지 않음
  - **Viewport Culling**: 화면에 보이지 않는 영역 제외
  - **LOD (Level of Detail)**: 9단계 줌 레벨별 세밀도 조절
  - **최대 렌더링**: 25,000개 셀/프레임

**LOD 시스템** (9단계):

| Zoom Level | 범위 | 렌더링 내용 |
|------------|------|-------------|
| **Ultra Zoomed Out** | < 0.05x | 섹션 라벨만 |
| **Very Zoomed Out** | 0.05x ~ 0.1x | 섹션 + 클러스터 마커 |
| **Zoomed Out** | 0.1x ~ 0.25x | 클러스터 마커 |
| **Far** | 0.25x ~ 0.5x | 그리드 라인 (굵음) |
| **Medium** | 0.5x ~ 1.0x | 그리드 라인 (중간) |
| **Base** | 1.0x ~ 2.0x | 그리드 라인 (얇음) |
| **Near** | 2.0x ~ 4.0x | 그리드 라인 + 셀 번호 |
| **Very Close** | 4.0x ~ 8.0x | 셀 번호 (큰 폰트) |
| **Ultra Close** | > 8.0x | 셀 번호 (초대 폰트) |

**완료 조건**:
- ✅ 1,000×1,000 그리드를 60fps로 렌더링
- ✅ 줌 레벨 변경 시 LOD 자동 조절
- ✅ 메모리 사용량 100MB 이하

### 기능 2: 블록 선택

**설명**: 사용자가 그리드의 특정 블록을 터치하여 선택/해제할 수 있습니다.

**인터랙션**:
1. 사용자가 그리드의 빈 블록을 터치
2. 터치 좌표를 그리드 좌표로 변환
3. 해당 블록을 `selectedBlocks` 리스트에 추가
4. 블록에 파란색 테두리 표시
5. Pick HUD 업데이트 ("3/5 picks")
6. 바텀시트 슬라이드 업

**제약 조건**:
- 최대 선택 가능 개수: 게임 설정에 따름 (예: 5개)
- 초과 선택 시: 스낵바 표시 "최대 5개까지 선택 가능합니다"
- 이미 선택한 블록 재터치: 선택 해제

**시각적 피드백**:
- 선택 시: 파란색 테두리 (2px), 햅틱 피드백
- 선택 해제 시: 테두리 제거, 햅틱 피드백
- Pick HUD 펄스 애니메이션

**완료 조건**:
- ✅ 터치로 블록 선택/해제 가능
- ✅ 최대 개수 제한 동작
- ✅ 시각적 피드백 정상 동작
- ✅ 햅틱 피드백 동작

---

### 기능 3: 줌 & 팬 (확대/축소 및 이동)

**설명**: 사용자가 그리드를 확대/축소하고 이동할 수 있습니다.

**모바일 제스처**:
- **핀치 투 줌**: 두 손가락으로 확대/축소
- **드래그**: 한 손가락으로 그리드 이동

**데스크톱 제스처**:
- **마우스 휠**: 줌 in/out
- **마우스 드래그**: 그리드 이동
- **클릭**: 블록 선택

**줌 레벨**:
- **최소**: 0.01x (전체 그리드를 화면에 맞춤)
- **초기**: 0.5x ~ 1.0x (선택하기 좋은 레벨)
- **최대**: 16.0x+ (개별 셀을 크게 확대)

**줌 컨트롤 버튼**:
- **[+] 버튼**: 현재 줌 레벨의 1.5배로 확대
- **[-] 버튼**: 현재 줌 레벨의 0.67배로 축소
- 최소/최대 도달 시: 스낵바 표시

**팬 경계**:
- 그리드 밖으로 벗어나지 않도록 제한
- 그리드 전체를 볼 수 있도록 경계 설정

**완료 조건**:
- ✅ 핀치 투 줌 동작
- ✅ 드래그 팬 동작
- ✅ 줌 컨트롤 버튼 동작
- ✅ LOD 자동 조절
- ✅ 경계 제한 동작

### 기능 4: 미니맵

**설명**: 전체 그리드의 축소판을 표시하고, 현재 보고 있는 위치를 시각화합니다.

**표시 내용**:
1. **전체 그리드**: 회색 배경 (#F0F0F0)
2. **현재 뷰포트**: 흰색 테두리 박스 (두께 2px)
3. **선택된 블록 폴리곤**: 파란색 (#5C72F5)

**인터랙션**:
- 미니맵의 특정 위치를 터치
- 터치한 위치로 그리드 뷰포트가 부드럽게 이동 (애니메이션 500ms)
- 뷰포트 박스가 터치한 위치로 이동

**동기화**:
- 그리드 줌/팬 시 미니맵 실시간 업데이트
- 블록 선택 시 미니맵 폴리곤 업데이트

**완료 조건**:
- ✅ 미니맵 렌더링
- ✅ 뷰포트 박스 표시
- ✅ 선택 블록 폴리곤 표시
- ✅ 터치로 빠른 이동
- ✅ 실시간 동기화

---

### 기능 5: 선택된 블록 바텀시트

**설명**: 선택한 블록의 목록을 표시하고, 관리할 수 있습니다.

**구성 요소**:

1. **헤더**:
   - 제목: "Selected Blocks (3/5)"
   - 드래그 핸들 (바텀시트 높이 조절용)

2. **블록 리스트** (스크롤 가능):
   - 각 블록 카드:
     - 파란색 블록 아이콘
     - 좌표 텍스트: "Row 123, Col 456"
     - [X] 삭제 버튼
   - 카드 간 간격: 8dp

3. **푸터** (고정):
   - **[CLEAR] 버튼**:
     - 회색 아웃라인 버튼
     - 텍스트: "CLEAR"
     - 동작: 모든 블록 선택 해제
   - **[Select blocks] 버튼**:
     - 파란색 그라데이션 버튼
     - 텍스트: "Select blocks (3/5 picks)"
     - 동작: 게임 참가 프로세스 시작
     - 활성화 조건: 1개 이상 블록 선택

**애니메이션**:
- 슬라이드 업/다운: 300ms, Ease-in-out
- 높이 변경: 200ms, Ease-out

**드래그 제스처**:
- 위로 드래그: 바텀시트 확장
- 아래로 드래그: 바텀시트 축소/닫기
- 스냅 포인트: 최소(80dp), 중간(40%), 최대(70%)

**블록 카드 인터랙션**:
- **카드 터치**: 해당 블록 위치로 그리드 이동 + 줌
- **[X] 버튼 터치**: 해당 블록 선택 해제

**완료 조건**:
- ✅ 바텀시트 슬라이드 애니메이션
- ✅ 블록 리스트 표시
- ✅ CLEAR 버튼 동작
- ✅ Select blocks 버튼 동작
- ✅ 카드 터치로 블록 위치 이동
- ✅ [X] 버튼으로 블록 삭제

### 기능 6: 섹션 오버레이 시스템

**설명**: 그리드를 3×3 구역으로 나누어 현재 위치를 직관적으로 표시합니다.

**구역 분할**:
```
┌───────┬───────┬───────┐
│  A1   │  A2   │  A3   │  상단
├───────┼───────┼───────┤
│  B1   │  B2   │  B3   │  중단
├───────┼───────┼───────┤
│  C1   │  C2   │  C3   │  하단
└───────┴───────┴───────┘
 좌측    중앙    우측
```

**표시 조건**:
- 줌 레벨 < 0.5x (축소 상태)

**표시 내용**:
1. **구역 라벨**: "A1", "B2" 등 (중앙에 큰 텍스트)
2. **구역 테두리**: 회색 점선 (두께 1px)
3. **선택 블록 개수**: 각 구역의 선택된 블록 수 (예: "5개")

**폰트 & 색상**:
- 라벨: Display (32px, Bold), 흰색 (#FFFFFF)
- Stroke: 검은색 (#000000), 두께 2px
- 개수: Body Large (16px, SemiBold), 파란색 (#5C72F5)

**완료 조건**:
- ✅ 구역 분할 및 라벨 표시
- ✅ 줌 레벨에 따른 표시/숨김
- ✅ 선택 블록 개수 표시

### 시나리오 2: 블록 선택

**사용자 행동**: 그리드의 특정 위치 터치

**화면 반응**:

1. **터치 좌표 변환**
   - 터치 좌표 (x, y) → 그리드 좌표 (row, col)
   - 예: (250, 180) → (Row 123, Col 456)

2. **블록 선택 검증**
   - 이미 선택한 블록인가? → 선택 해제
   - 최대 개수 초과인가? → 스낵바 표시 "최대 5개까지 선택 가능"
   - 선택 가능 → 계속

3. **블록 추가**
   - `selectedBlocks` 리스트에 추가
   - 블록에 파란색 테두리 표시
   - 햅틱 피드백 (Light Impact)

4. **UI 업데이트**
   - Pick HUD: "1/5 picks" (펄스 애니메이션)
