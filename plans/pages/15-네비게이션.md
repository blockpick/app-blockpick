## 🎯 시스템 목적

네비게이션 시스템은 BlockPick 앱의 **전역 탐색 경험을 제공하는 핵심 인프라**입니다.

주요 목적:
- **일관된 탐색**: 모든 화면에서 일관된 네비게이션 경험 제공
- **빠른 접근**: 주요 기능에 한 번의 탭으로 접근
- **플랫폼 전환**: OFFICIAL, BlockPick, MALL 플랫폼 간 원활한 전환
- **컨텍스트 유지**: 탭 간 이동 시 상태 유지 (IndexedStack)

PreferredSizeWidget _buildAppBar(PlatformMode platformMode) {
  // 메인 페이지 체크

  // 서브 페이지

  );
}

Widget? _buildBottomNav(PlatformMode platformMode) {
  // BlockPick 모드에서만 하단 네비게이션 표시

### IndexedStack으로 상태 유지

**구현**:
```dart
Widget _buildBody(PlatformMode platformMode) {
  switch (platformMode) {
    case PlatformMode.official:
      return const OfficialScreen();
    case PlatformMode.blockpick:
      return IndexedStack(
        index: _currentIndex,
        children: _blockpickScreens, // 모든 화면 미리 로드
      );
    case PlatformMode.mall:
      return const MallScreen();
  }
}
```

**장점**:
- 탭 간 이동 시 상태 유지 (스크롤 위치, 입력 값 등)
- 빠른 전환 (화면 재빌드 없음)
- 메모리 효율적 (한 번만 빌드)

**단점**:
- 모든 화면이 동시에 메모리에 존재
- 초기 빌드 시간 증가 (6개 화면)

## 🎯 주요 이슈 및 해결 방안

### Issue 1: 플랫폼 전환 UX

**문제**:
- 플랫폼 선택 드롭다운이 주석 처리됨
- 사용자가 플랫폼 전환 방법을 모를 수 있음

**해결 방안**:
- [ ] 플랫폼 선택 Bottom Sheet 구현
- [ ] 각 플랫폼 설명 및 미리보기 추가
- [ ] 첫 사용 시 온보딩 튜토리얼
- [ ] Drawer에서도 플랫폼 전환 가능

**Story Points**: 5pt

---

### Issue 2: 메모리 최적화

**문제**:
- IndexedStack이 6개 화면 모두 메모리에 유지
- 복잡한 화면일수록 메모리 사용량 증가

**해결 방안**:
- [ ] Lazy loading 적용 (필요한 화면만 로드)
- [ ] AutomaticKeepAliveClientMixin 선택적 사용
- [ ] 메모리 프로파일링 (DevTools)
- [ ] 불필요한 위젯 dispose

**Story Points**: 5pt

---

### Issue 3: 딥링크 지원

**문제**:
- 외부 링크에서 특정 화면으로 바로 진입 불가

- [ ] GoRouter의 ShellRoute 사용

## 📝 개발 노트

### 플랫폼 모드 (PlatformMode)

**3가지 플랫폼**:
1. **OFFICIAL**: 공식 게임 플랫폼
   - 하단 네비게이션 없음
   - OfficialScreen 표시

2. **BlockPick**: 블록픽 게임 플랫폼
   - 하단 네비게이션 표시 (6개 탭)
   - IndexedStack으로 화면 전환

3. **MALL**: 쇼핑몰 플랫폼
   - 하단 네비게이션 없음
   - MallScreen 표시

**전환 방식**:
- App Drawer 메뉴 선택
- 플랫폼 선택 드롭다운 (향후 활성화)
- `platformModeProvider` 상태 변경

---

### 탭 인덱스 매핑

**Bottom Nav (5개)**:
| 인덱스 | 화면 | 표시 |
|--------|------|------|
| 0 | NewHomeScreen | HOME |
| 1 | MyPickScreen | My Pick |
| 2 | HomeScreen | PICK (중앙 버튼) |
| 3 | WinnersScreen | Winners |
| 4 | MallScreen | MALL |

**숨겨진 탭 (1개)**:
| 인덱스 | 화면 | 접근 방법 |
|--------|------|-----------|
| 5 | MyScreen | 유저 아이콘 탭 |

**설계 이유**:
- 하단 네비게이션에 5개 이상 표시 시 복잡함
- MY 페이지는 유저 아이콘으로 접근하는 것이 직관적
- 인덱스 5는 내부적으로만 사용

---

### App Bar 표시 규칙

**Main App Bar 표시 조건**:
- OFFICIAL 플랫폼
- MALL 플랫폼
- BlockPick의 HOME 탭 (인덱스 0)
- BlockPick의 PICK 탭 (인덱스 2)

**Sub App Bar 표시 조건**:
- BlockPick의 My Pick 탭 (인덱스 1)
- BlockPick의 Winners 탭 (인덱스 3)
- BlockPick의 MY 탭 (인덱스 5)

**이유**:
- 메인 화면은 플랫폼 전환이 필요하므로 Main App Bar
- 서브 화면은 간단한 제목만 표시하면 되므로 Sub App Bar
