## 1. 문서 개요

### 1.1 목적

본 문서는 BlockPick 서비스의 운영 정책과 절차를 정의합니다. 공정하고 투명한 서비스 운영을 통해 사용자 신뢰를 확보하고, 일관된 고객 경험을 제공합니다.

### 1.2 적용 범위

본 정책은 다음에 적용됩니다:
- BlockPick 모바일 애플리케이션
- BlockPick 웹사이트
- 모든 게임 타입 (DAILY, SELECT, VIBE, PRIME)
- Event Cash 및 Shopping Cash 시스템
- 고객 지원 서비스

### 1.3 운영 원칙

**투명성**:
- 모든 게임 규칙을 사전 공개
- 당첨자 선정 과정의 완전한 투명성
- 블록체인 기록을 통한 검증 가능성

**공정성**:
- 모든 사용자에게 동일한 기회 제공
- Chainlink VRF를 통한 조작 불가능한 난수 생성
- 내부자 우대 및 차별 금지

**신속성**:
- 고객 문의 24시간 내 응답
- 당첨자 발표 후 즉시 알림
- 상품 배송 7일 이내 완료

**안정성**:
- 시스템 가동률 99.9% 이상
- 정기 점검 사전 공지
- 긴급 상황 대응 체계 구축

## 2. 게임 운영 정책

### 2.1 게임 생성 및 등록

**게임 생성 주체**: BlockPick 운영팀

**게임 등록 절차**:
1. 상품 선정 및 구매/제휴
2. 게임 정보 입력 (제목, 설명, 이미지, 참가비 등)
3. 내부 검토 및 승인
4. 블록체인 컨트랙트에 게임 등록
5. 앱에 게임 노출

**게임 정보 필수 항목**:
- 게임 타입 (DAILY, SELECT, VIBE, PRIME)
- 상품명 및 상세 설명
- 상품 이미지 (최소 1장, 최대 5장)
- 정가
- 참가비
- 최대 참여자 수
- 게임 시작 시간
- 게임 종료 시간
- 환급 비율

**게임 검토 기준**:
- [ ] 상품이 실제로 존재하고 배송 가능한가?
- [ ] 상품 가치가 정확하게 표기되었는가?
- [ ] 이미지가 고품질이며 상품을 정확히 보여주는가?
- [ ] 참가비가 합리적인가? (상품 가치의 0.1% ~ 1%)
- [ ] 게임 기간이 적절한가? (최소 6시간, 최대 7일)
- [ ] 법적 문제가 없는가? (사행성, 저작권 등)

### 2.2 게임 타입별 운영 정책

#### 2.2.1 DAILY 게임

**운영 방침**:
- 매일 오전 10시 새로운 게임 시작
- 게임 기간: 24시간
- 참가비: 1,000원 ~ 3,000원
- 상품 가치: 50만 원 ~ 100만 원
- 최대 참여자: 500명
- 환급 비율: 10%

**상품 카테고리** (주별 로테이션):
- 월요일: 디지털 (스마트폰, 태블릿 등)
- 화요일: 패션 (가방, 시계 등)
- 수요일: 뷰티 (화장품 세트 등)
- 목요일: 식품 (고급 한우, 과일 등)
- 금요일: 기프트 (상품권 등)
- 토요일: 홈/리빙 (가전제품 등)
- 일요일: 스페셜 (고가 상품)

**참여자 수 미달 시**:
- 최소 참여자: 50명
- 50명 미만인 경우: 게임 취소 및 전액 환불
- 취소 통보: 종료 1시간 전

#### 2.2.2 SELECT 게임

**운영 방침**:
- 주 2~3회 진행 (화, 목, 토)
- 게임 기간: 3~7일
- 참가비: 3,000원 ~ 5,000원
- 상품 가치: 200만 원 ~ 500만 원
- 최대 참여자: 300명
- 환급 비율: 20%

**프리미엄 상품**:
- 명품 가방, 시계
- 최신 노트북, 카메라
- 고급 가전제품
- 해외여행 패키지

#### 2.2.3 VIBE 게임

**운영 방침**:
- 월 1~2회 진행
- 게임 기간: 7~14일
- 참가비: 5,000원 ~ 10,000원
- 상품 가치: 500만 원 이상
- 최대 참여자: 200명
- 환급 비율: 30%

**특별 이벤트**:
- 그룹 참여 기능 (친구와 함께)
- 그룹 할인 (3명 이상 10% 할인)
- 소셜 공유 보너스

#### 2.2.4 PRIME 게임

**운영 방침**:
- 주 1회 진행 (일요일)
- 게임 기간: 24시간
- 참가비: 1,000원
- 상품 가치: 100만 원
- 방식: 가격 맞추기
- 환급: 없음 (낮은 참가비)

**게임 규칙**:
- 상품의 정확한 가격을 예측
- 정답 또는 가장 근접한 가격을 맞춘 사람이 당첨
- 동점자가 여러 명인 경우 랜덤 추첨

### 2.3 게임 상태 관리

**게임 상태 변경**:

```
UPCOMING (시작 전)
  ↓ (게임 시작 시간 도래)
ONGOING (진행 중)
  ↓ (게임 종료 시간 도래)
ENDED (종료됨)
  ↓ (당첨자 선정 완료)
COMPLETED (완료)

또는

CANCELLED (취소됨) ← 긴급 상황 시
```

**자동 상태 전환**:
- `UPCOMING → ONGOING`: 시작 시간 1분 후
- `ONGOING → ENDED`: 종료 시간 정각
- `ENDED → COMPLETED`: 당첨자 발표 후

**수동 개입 필요 상황**:
- 시스템 오류로 인한 게임 취소
- 상품 품절로 인한 게임 취소
- 법적 문제 발생 시 게임 취소

### 2.4 게임 노출 정책

**메인 홈 노출 우선순위**:
1. 진행 중인 게임 (마감 임박순)
2. 곧 시작하는 게임 (시작 임박순)
3. 인기 게임 (참여자 수 기준)

**게임 카드 필수 정보**:
- 상품 이미지
- 상품명
- 게임 타입 뱃지
- 참가비
- 현재 참여자 수 / 최대 참여자 수
- 남은 시간 (실시간 카운트다운)
- "참여하기" 버튼

**검색 및 필터**:
- 게임 타입별 필터
- 카테고리별 필터
- 가격대별 필터
- 정렬: 인기순, 최신순, 마감임박순, 가격낮은순

## 3. 당첨자 선정 및 발표

### 3.1 당첨자 선정 프로세스

**선정 시점**: 게임 종료 시간 정각

**선정 절차**:
1. 게임 상태를 `ENDED`로 변경
2. Chainlink VRF에 랜덤 숫자 요청 (블록체인)
3. VRF 응답 대기 (평균 2~5초)
4. 난수를 사용하여 당첨 블록 계산: `randomSeed % 1,000,000`
5. 백엔드에서 모든 참여자의 암호화된 좌표 복호화
6. 당첨 블록을 포함하는 3×3 섹션을 선택한 참여자 찾기
7. 당첨자 주소를 블록체인 컨트랙트에 기록
8. 데이터베이스에 당첨 정보 저장
9. 당첨자 및 모든 참여자에게 알림 발송

**당첨 블록 계산 예시**:
```javascript
// Chainlink VRF가 반환한 난수
const randomSeed = 0x1a2b3c4d5e6f7890...;

// 0 ~ 999,999 범위의 블록 번호 계산
const winningBlockNumber = BigInt(randomSeed) % 1000000n;

// 블록 번호를 (x, y) 좌표로 변환
const x = Math.floor(winningBlockNumber / 1000);
const y = winningBlockNumber % 1000;

console.log(`당첨 블록: (${x}, ${y})`);
// 예: 당첨 블록: (523, 847)
```

**당첨자 찾기 로직**:
```javascript
// 모든 참여자의 블록 검사
for (const participation of participations) {
  const blocks = decryptCoordinates(participation.encryptedCoordinates);

  // 당첨 블록이 선택한 9개 블록에 포함되는지 확인
  const isWinner = blocks.some(block =>
    block.x === winningX && block.y === winningY
  );

  if (isWinner) {
    return participation.userId;
  }
}

// 아무도 당첨 블록을 선택하지 않은 경우
// → 가장 가까운 블록을 선택한 사람 찾기
return findClosestParticipant(winningX, winningY);
```

### 3.2 당첨자 발표

**발표 시점**: 당첨자 선정 완료 즉시

**발표 채널**:
1. **푸시 알림**
   - 당첨자: "축하합니다! [게임명]에 당첨되셨습니다!"
   - 낙첨자: "[게임명]의 당첨자가 발표되었습니다. Event Cash [금액]원이 환급되었습니다."

2. **이메일**
   - 당첨자: 상품 수령 방법 안내
   - 낙첨자: 환급 내역 안내

3. **SMS** (당첨자에게만)
   - "[BlockPick] 축하합니다! [상품명]에 당첨되셨습니다. 앱에서 상품 수령 절차를 진행해주세요."

4. **앱 내 알림**
   - 당첨자 발표 화면
   - My Pick에 당첨 배지 표시

**공개 정보**:
- 당첨 블록 좌표 (x, y)
- 난수 시드 (Chainlink VRF)
- 당첨자 닉네임 (일부 마스킹: 홍*동)
- 블록체인 트랜잭션 해시

**비공개 정보**:
- 당첨자 개인정보 (이메일, 전화번호, 주소)
- 다른 참여자의 블록 선택 정보

### 3.3 당첨 검증

**사용자가 직접 검증 가능**:

1. **블록체인 탐색기에서 확인**:
   - Polygonscan에서 트랜잭션 조회
   - `WinnerSelected` 이벤트 확인
   - 난수 시드 및 당첨 블록 확인

2. **앱 내 검증 화면**:
   - 게임 상세 → "당첨 검증" 탭
   - 당첨 블록 위치 표시 (그리드 위에)
   - 본인이 선택한 블록 위치 표시
   - Chainlink VRF 링크 제공

3. **고객 센터 문의**:
   - 의심스러운 경우 문의 가능
   - 운영팀이 상세 내역 제공

### 3.4 당첨 무효 사유

다음의 경우 당첨이 무효 처리됩니다:

1. **부정 행위 발견**:
   - 다중 계정 사용
   - 시스템 해킹 시도
   - 블록체인 조작 시도

2. **허위 정보 제공**:
   - 가짜 신분증 제출
   - 타인 명의 도용

3. **상품 수령 불가**:
   - 연락 두절 (7일 이상)
   - 배송지 정보 미제공
   - 수령 거부

**무효 처리 절차**:
1. 운영팀 검토 및 판단
2. 당첨자에게 이메일 통보
3. 차순위 당첨자 선정 또는 재추첨
4. 부정 행위 시 계정 정지 및 법적 조치

## 4. 상품 배송 정책

### 4.1 상품 수령 방법 선택

**당첨자는 다음 중 선택**:

1. **실물 배송** (실물 상품):
   - 배송지 주소 입력
   - 7영업일 이내 배송 시작
   - 택배 추적 가능

2. **디지털 상품 수령**:
   - 쿠폰 코드 즉시 제공
   - 또는 다운로드 링크 제공

3. **현금 수령** (현금성 상품):
   - Shopping Cash로 자동 적립
   - 또는 계좌 이체 (7영업일)

### 4.2 배송 프로세스

**실물 상품 배송**:

```
1. 당첨자 발표
   ↓
2. 배송지 정보 입력 (48시간 내)
   ↓
3. 배송지 확인 및 검증
   ↓
4. 상품 발주 및 포장 (2~3일)
   ↓
5. 택배 발송 (CJ대한통운)
   ↓
6. 배송 중 (3~5일)
   ↓
7. 배송 완료
   ↓
8. 수령 확인 (당첨자 확인 버튼 클릭)
```

**배송 정보 제공**:
- 택배사: CJ대한통운
- 송장번호 제공
- 실시간 배송 추적 링크
- 배송 상태 푸시 알림

### 4.3 배송 지연 및 문제 해결

**배송 지연 사유**:
- 상품 품절 (대체 상품 제안)
- 천재지변 (태풍, 폭설 등)
- 배송지 정보 오류
- 부재중으로 인한 반송

**지연 시 조치**:
1. 당첨자에게 즉시 연락 (이메일, SMS)
2. 지연 사유 및 예상 배송일 안내
3. 보상 제공 (Event Cash 추가 지급)
4. 대체 상품 제안 (동의 시)

**배송 실패 시**:
- 3회 배송 시도 후 실패 → 고객센터 연락
- 연락 두절 시 7일 후 당첨 무효 처리
- 상품은 다음 게임 상품으로 재활용 또는 기부

### 4.4 교환 및 반품

**상품 하자 시**:
- 수령 후 7일 이내 교환 가능
- 사진 첨부하여 고객센터 문의
- 운영팀 확인 후 새 상품 발송
- 왕복 배송비 BlockPick 부담

**단순 변심**:
- 교환/반품 불가 (경품의 특성상)
- 예외: 상품이 설명과 다른 경우

## 5. Event Cash 운영 정책

### 5.1 충전 정책

**충전 방법**:
- 신용카드/체크카드
- 계좌이체
- 토스페이, 카카오페이, 네이버페이

**충전 한도**:
- 1회 최소: 1,000원
- 1회 최대: 500,000원
- 1일 최대: 1,000,000원
- 1달 최대: 5,000,000원

**충전 보너스**:
| 충전 금액 | 보너스 | 총 금액 |
|-----------|--------|---------|
| 10,000원 | 0원 | 10,000원 |
| 30,000원 | 3,000원 (10%) | 33,000원 |
| 50,000원 | 7,500원 (15%) | 57,500원 |
| 100,000원 | 20,000원 (20%) | 120,000원 |

**충전 실패 시**:
- 결제 실패: 재시도 안내
- PG사 오류: 다른 결제 수단 안내
- 한도 초과: 한도 안내 및 분할 충전 제안

### 5.2 사용 정책

**사용 용도**:
- 게임 참가비 결제 (주 용도)
- Shopping Cash로 전환 (1:1 비율)

**사용 제한**:
- 타인에게 양도 불가
- 현금 출금 불가 (환불만 가능)
- 불법 용도 사용 금지

**사용 우선순위**:
1. 보너스 Event Cash (유효기간 짧은 것부터)
2. 충전 Event Cash (충전일 오래된 것부터)

### 5.3 환급 정책

**낙첨 시 환급**:
- DAILY: 참가비의 10% 환급
- SELECT: 참가비의 20% 환급
- VIBE: 참가비의 30% 환급
- PRIME: 환급 없음

**환급 시점**: 당첨자 발표 즉시

**환급 방식**: Event Cash 자동 적립

### 5.4 소멸 정책

**소멸 조건**:
- 최종 적립일로부터 5년간 미사용 시 소멸

**소멸 예정 안내**:
- 소멸 3개월 전: 이메일 안내

- 소멸 1주일 전: 푸시 알림 + 이메일 + SMS

**소멸 유예**:

## 6. 환불 및 취소 정책

### 6.1 게임 참가 취소

**취소 가능 기간**:
- 게임 종료 1시간 전까지 취소 가능
- 종료 1시간 이내: 취소 불가

**취소 수수료**:
- 참가비의 10% 차감
- 90% 환불

**취소 절차**:
1. My Pick → 참여 내역 → "참가 취소" 버튼
2. 취소 확인 팝업
3. Event Cash 즉시 환불
4. 블록체인에 취소 기록 (선택 블록 해제)

**취소 제한 사유**:
- 게임 종료 1시간 이내
- 이미 당첨자가 선정된 경우
- 시스템 오류로 인한 일시적 제한

### 6.2 Event Cash 환불

**환불 가능 조건**:
- 충전 후 미사용 금액
- 보너스 Event Cash는 환불 불가
- 게임 참가 등으로 사용한 금액 제외

**환불 수수료**:
- 환불 금액의 10%
- 최소 수수료: 1,000원

**환불 한도**:
- 1회 최대: 500,000원
- 1달 최대: 1,000,000원

**환불 절차**:
1. My 페이지 → Event Cash → "환불 신청"
2. 환불 금액 입력
3. 계좌 정보 입력 (예금주, 은행, 계좌번호)
4. 본인 확인 (비밀번호 입력)
5. 신청 완료
6. 운영팀 검토 (1~2영업일)
7. 승인 후 계좌 이체 (3~5영업일)
8. 완료 알림

**환불 거부 사유**:
- 부정 획득한 Event Cash
- 환불 한도 초과
- 계좌 정보 불일치
- 법적 분쟁 중인 계정

### 6.3 게임 취소 시 보상

**운영팀의 게임 취소 사유**:
- 상품 품절 또는 공급 불가
- 시스템 오류로 공정성 훼손
- 법적 문제 발생

**보상 정책**:
1. 참가비 100% 환불 (Event Cash)
2. 추가 보상 Event Cash 지급 (참가비의 20%)
3. 사과 공지 및 안내

**예시**:
- 참가비 3,000원 게임 취소
- 환불: 3,000원
- 추가 보상: 600원
- 총 수령: 3,600원
