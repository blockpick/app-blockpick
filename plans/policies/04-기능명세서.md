# BlockPick 기능 명세서

**문서 버전**: 1.0
**작성일**: 2025-11-20
**문서 유형**: 기능 상세 명세서

---

## 1. 문서 개요

본 기능 명세서는 BlockPick 시스템의 모든 기능을 상세히 정의합니다. 각 기능은 고유 ID, 설명, 입력/출력, 전제조건, 후행조건, 예외 처리를 포함하며, 개발자가 구현할 수 있을 정도로 구체적으로 작성되었습니다.

---

## 2. 인증 기능

### FUNC-AUTH-001: 이메일 회원가입

**기능 설명**
사용자가 이메일 주소를 사용하여 새로운 계정을 생성하는 기능입니다.

**입력**
- email: 문자열, 이메일 형식(예: user@example.com), 필수
- password: 문자열, 최소 8자, 영문/숫자/특수문자 중 3가지 이상 포함, 필수
- name: 문자열, 2-20자, 필수
- phoneNumber: 문자열, 010-XXXX-XXXX 형식, 선택
- birthDate: 날짜, YYYY-MM-DD 형식, 선택

**출력**
- success: 불리언, 가입 성공 여부
- userId: 문자열, 생성된 사용자 ID
- message: 문자열, 결과 메시지

**전제조건**
- 이메일이 유효한 형식이어야 함
- 이메일이 데이터베이스에 존재하지 않아야 함
- 비밀번호가 정책을 만족해야 함

**후행조건**
- users 테이블에 새로운 레코드 생성
- 비밀번호는 bcrypt로 해싱되어 저장
- Event Cash 1,000원 자동 적립
- 환영 이메일 발송

**예외 처리**
- 중복 이메일: "이미 사용 중인 이메일입니다"
- 잘못된 비밀번호: "비밀번호는 최소 8자 이상, 영문/숫자/특수문자 중 3가지 이상 포함해야 합니다"
- 데이터베이스 오류: "일시적인 오류가 발생했습니다. 다시 시도해주세요"

---

### FUNC-AUTH-002: 이메일 로그인

**기능 설명**
등록된 이메일과 비밀번호로 인증하여 시스템에 접근하는 기능입니다.

**입력**
- email: 문자열, 필수
- password: 문자열, 필수

**출력**
- success: 불리언
- accessToken: 문자열, JWT 액세스 토큰, 유효기간 30분
- refreshToken: 문자열, JWT 리프레시 토큰, 유효기간 7일
- user: 객체, 사용자 기본 정보(id, email, name)

**전제조건**
- 이메일이 데이터베이스에 존재해야 함
- 계정이 잠기지 않았어야 함

**후행조건**
- 로그인 성공 시 last_login_at 업데이트
- 실패 시 failed_login_count 증가
- 5회 실패 시 계정 15분간 잠금

**예외 처리**
- 존재하지 않는 이메일 또는 잘못된 비밀번호: "이메일 또는 비밀번호가 일치하지 않습니다"
- 계정 잠금: "계정이 일시적으로 잠겼습니다. 15분 후 다시 시도하거나 비밀번호를 재설정하세요"

## 3. 게임 참여 기능

### FUNC-GAME-001: 게임 목록 조회

**기능 설명**
진행 중인 게임 목록을 필터링, 정렬, 페이지네이션하여 조회하는 기능입니다.

**입력**
- filter: 객체, 선택
  - gameType: 문자열, DAILY/SELECT/VIBE/PRIME 중 하나
  - category: 문자열, Digital/Fashion/Beauty/Gift/Food 등
  - status: 문자열, UPCOMING/ONGOING/ENDED
- sort: 객체, 선택
  - field: 문자열, mostPopular/newest/endingSoon/priceLowToHigh
  - order: 문자열, ASC/DESC
- pagination: 객체, 선택
  - first: 정수, 페이지당 항목 수, 기본값 20
  - after: 문자열, 커서

**출력**
- edges: 배열, 게임 목록
  - node: 게임 객체
    - id, title, gameType, productImage, entryFee, participantCount, maxParticipants, endDate 등
- pageInfo: 객체
  - hasNextPage: 불리언
  - endCursor: 문자열

**전제조건**
- 없음 (로그인 필요 없음, 공개 API)

**후행조건**
- 없음 (읽기 전용)

**예외 처리**
- 잘못된 필터: "유효하지 않은 게임 타입입니다"
- 데이터베이스 오류: 빈 배열 반환 및 에러 로그

---

### FUNC-GAME-002: 게임 참가

**기능 설명**
사용자가 선택한 블록으로 게임에 참가하는 기능입니다. 블록체인에 참여 기록을 남기고 참가비를 결제합니다.

**입력**
- gameId: 문자열, 필수
- selectedBlocks: 배열, 9개의 좌표 객체 [{x, y}, ...], 필수

**출력**
- success: 불리언
- participationId: 문자열, 생성된 참여 ID
- transactionHash: 문자열, 블록체인 트랜잭션 해시
- remainingCash: 정수, 참가 후 남은 Event Cash

**전제조건**
- 사용자가 로그인되어 있어야 함
- 게임이 ONGOING 상태여야 함
- 참여자 수가 최대에 도달하지 않았어야 함
- 선택한 블록이 정확히 9개이고 3×3 형태여야 함
- 선택한 블록이 이미 선택되지 않았어야 함
- Event Cash 잔액이 참가비 이상이어야 함
- 블록체인 지갑이 있어야 함 (없으면 자동 생성)

**후행조건**
- participations 테이블에 새로운 레코드 생성
- 블록체인에 암호화된 좌표 기록
- Event Cash 차감
- transactions 테이블에 사용 기록 추가
- 게임의 currentParticipants 증가
- 선택된 블록 occupied 상태로 표시

**예외 처리**
- 게임 종료됨: "이 게임은 이미 종료되었습니다"
- 참여자 수 초과: "참여 가능 인원이 모두 찼습니다"
- 중복 블록 선택: "이미 선택된 블록입니다. 다른 블록을 선택해주세요"
- 잔액 부족: "Event Cash가 부족합니다. 현재 잔액: [금액]"
- 블록체인 오류: "일시적인 오류로 참가에 실패했습니다. 참가비는 환불됩니다"

---

### FUNC-GAME-003: 블록 선택 가능 여부 확인

**기능 설명**
사용자가 선택하려는 3×3 블록 영역이 선택 가능한지 확인하는 기능입니다.

**입력**
- gameId: 문자열, 필수
- centerBlock: 객체, {x, y}, 필수

**출력**
- available: 불리언, 선택 가능 여부
- occupiedBlocks: 배열, 이미 선택된 블록 목록 (available이 false인 경우)

**전제조건**
- 게임이 존재해야 함
- centerBlock이 그리드 범위 내에 있어야 함 (1 <= x, y <= 998)

**후행조건**
- 없음 (읽기 전용)

**예외 처리**
- 범위 벗어남: "그리드 경계를 벗어난 블록입니다"

---

## 4. Event Cash 관리 기능

### FUNC-CASH-001: Event Cash 충전

**기능 설명**
신용카드, 계좌이체 등으로 Event Cash를 충전하는 기능입니다.

**입력**
- amount: 정수, 충전 금액 (1,000 ~ 500,000), 필수
- paymentMethod: 문자열, CARD/ACCOUNT_TRANSFER, 필수
- paymentInfo: 객체, 결제 수단별 추가 정보, 필수

**출력**
- success: 불리언
- paymentId: 문자열, PG사 결제 ID
- chargedAmount: 정수, 충전된 금액
- currentCash: 정수, 충전 후 총 Event Cash

**전제조건**
- 사용자가 로그인되어 있어야 함
- 충전 금액이 범위 내에 있어야 함
- 결제 수단 정보가 유효해야 함

**후행조건**
- PG사를 통해 실제 결제 처리
- 결제 성공 시 Event Cash 증가
- transactions 테이블에 충전 기록 추가
- 충전 완료 푸시 알림 발송

**예외 처리**
- 결제 실패: "결제에 실패했습니다. [PG사 에러 메시지]"
- 금액 범위 오류: "충전 금액은 1,000원 이상 500,000원 이하여야 합니다"

---

### FUNC-CASH-002: Event Cash 사용

**기능 설명**
게임 참가비로 Event Cash를 사용하는 기능입니다.

**입력**
- userId: 문자열, 필수
- amount: 정수, 사용 금액, 필수
- purpose: 문자열, 사용 목적 (GAME_ENTRY 등), 필수
- relatedId: 문자열, 관련 ID (게임 ID 등), 선택

**출력**
- success: 불리언
- transactionId: 문자열, 거래 ID
- remainingCash: 정수, 남은 Event Cash

**전제조건**
- Event Cash 잔액이 사용 금액 이상이어야 함

**후행조건**
- Event Cash 차감
- transactions 테이블에 사용 기록 추가

**예외 처리**
- 잔액 부족: "Event Cash가 부족합니다. 현재 잔액: [금액]"

---

### FUNC-CASH-003: Event Cash ↔ Shopping Cash 전환

**기능 설명**
Event Cash를 Shopping Cash로 전환하거나 그 반대로 전환하는 기능입니다.

**입력**
- userId: 문자열, 필수
- amount: 정수, 전환 금액, 필수
- direction: 문자열, EVENT_TO_SHOPPING 또는 SHOPPING_TO_EVENT, 필수

**출력**
- success: 불리언
- eventCash: 정수, 전환 후 Event Cash
- shoppingCash: 정수, 전환 후 Shopping Cash

**전제조건**
- 전환할 Cash 잔액이 충분해야 함

**후행조건**
- 해당 Cash 차감, 다른 Cash 증가
- 전환 비율 1:1, 수수료 없음
- transactions 테이블에 전환 기록 추가

**예외 처리**
- 잔액 부족: "[Cash 타입] 잔액이 부족합니다"
- 잘못된 방향: "유효하지 않은 전환 방향입니다"

## 5. 당첨 및 보상 기능

### FUNC-REWARD-001: 당첨자 선정

**기능 설명**
게임 종료 시 Chainlink VRF를 사용하여 공정하게 당첨자를 선정하는 기능입니다.

**입력**
- gameId: 문자열, 필수

**출력**
- success: 불리언
- winnerId: 문자열, 당첨자 사용자 ID
- winningBlocks: 배열, 당첨 블록 좌표
- randomSeed: 문자열, 사용된 난수 (검증용)

**전제조건**
- 게임이 ENDED 상태여야 함
- 참여자가 1명 이상이어야 함

**후행조건**
- 스마트 컨트랙트에서 VRF로 난수 생성
- 난수로 당첨 블록 결정
- 해당 블록을 선택한 참여자 찾기
- participations 테이블의 isWinner 업데이트
- games 테이블의 winnerId 업데이트
- 당첨 알림 발송

**예외 처리**
- 참여자 없음: "참여자가 없어 당첨자를 선정할 수 없습니다"
- VRF 오류: "난수 생성에 실패했습니다. 재시도합니다"

---

### FUNC-REWARD-002: Event Cash 환급

**기능 설명**
낙첨자에게 참가비의 일부를 Event Cash로 환급하는 기능입니다.

**입력**
- participationId: 문자열, 필수

**출력**
- success: 불리언
- refundAmount: 정수, 환급 금액
- currentCash: 정수, 환급 후 Event Cash

**전제조건**
- 해당 참여가 낙첨 상태여야 함 (isWinner = false)
- 아직 환급받지 않았어야 함

**후행조건**
- 참가비 × 환급 비율 계산 (게임 타입별 상이)
- Event Cash 증가
- participations 테이블의 refundAmount 업데이트
- transactions 테이블에 환급 기록 추가

**예외 처리**
- 이미 환급됨: "이미 환급 처리되었습니다"
- 당첨자: "당첨자는 환급 대상이 아닙니다"

## 6. 블록체인 지갑 기능

### FUNC-WALLET-001: 지갑 자동 생성

**기능 설명**
사용자가 처음 게임에 참여할 때 자동으로 블록체인 지갑을 생성하는 기능입니다.

**입력**
- userId: 문자열, 필수

**출력**
- success: 불리언
- walletAddress: 문자열, 생성된 지갑 주소 (0x...)
- mnemonic: 문자열, 12단어 복구 문구 (일회성, 사용자가 저장해야 함)

**전제조건**
- 사용자가 아직 지갑을 가지고 있지 않아야 함

**후행조건**
- BIP39로 니모닉 생성
- 니모닉에서 개인키 유도
- 개인키를 Flutter Secure Storage에 암호화 저장
- 공개키에서 지갑 주소 계산
- users 테이블의 walletAddress 업데이트

**예외 처리**
- 이미 지갑 있음: 기존 지갑 사용
- 저장 실패: "지갑 생성에 실패했습니다. 다시 시도해주세요"

---

### FUNC-WALLET-002: 지갑 복구

**기능 설명**
니모닉 문구를 사용하여 지갑을 복구하는 기능입니다.

**입력**
- userId: 문자열, 필수
- mnemonic: 문자열, 12단어 공백 구분, 필수

**출력**
- success: 불리언
- walletAddress: 문자열, 복구된 지갑 주소

**전제조건**
- 니모닉이 유효한 BIP39 형식이어야 함

**후행조건**
- 니모닉에서 개인키 재유도
- 개인키 저장
- 지갑 주소 계산 및 확인
- users 테이블 업데이트

**예외 처리**
- 잘못된 니모닉: "유효하지 않은 복구 문구입니다"
- 주소 불일치: "복구된 주소가 기존 주소와 일치하지 않습니다"

## 7. 알림 기능

### FUNC-NOTIF-001: 푸시 알림 발송

**기능 설명**
사용자에게 푸시 알림을 발송하는 기능입니다.

**입력**
- userId: 문자열 또는 배열, 필수
- title: 문자열, 알림 제목, 필수
- body: 문자열, 알림 본문, 필수
- data: 객체, 추가 데이터 (딥링크 등), 선택
- category: 문자열, 알림 카테고리, 필수

**출력**
- success: 불리언
- sentCount: 정수, 발송 성공 개수

**전제조건**
- 사용자가 푸시 알림을 허용했어야 함
- 해당 카테고리 알림을 켰어야 함

**후행조건**
- FCM을 통해 알림 전송
- 알림 발송 이력 저장

**예외 처리**
- FCM 오류: 재시도 (최대 3회)
- 디바이스 토큰 없음: 조용히 실패
