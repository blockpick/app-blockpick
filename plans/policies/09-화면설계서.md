## 1. 문서 개요

### 1.1 목적

본 문서는 BlockPick 모바일 애플리케이션의 모든 화면을 문장 형태로 상세히 설명합니다. 각 화면의 구성 요소, 레이아웃, 상호작용, 상태 변화를 명확히 기술하여 디자이너와 개발자가 일관된 사용자 경험을 구현할 수 있도록 합니다.

### 1.2 범위

본 문서는 BlockPick 앱의 모든 주요 화면과 다이얼로그, 바텀시트 등을 포함합니다. UI 목업이나 이미지는 포함하지 않으며, 순수하게 문장으로 화면의 모든 요소를 설명합니다.

### 1.3 화면 네이밍 규칙

각 화면은 다음과 같은 규칙으로 이름이 지정됩니다.
- 온보딩 화면: ONBOARD-001, ONBOARD-002 등
- 인증 화면: AUTH-001, AUTH-002 등
- 메인 화면: HOME-001
- 게임 화면: GAME-001, GAME-002 등
- Event Cash 화면: CASH-001, CASH-002 등
- 설정 화면: SETTING-001, SETTING-002 등

## 2. 디자인 시스템

### 2.1 색상 팔레트

BlockPick 앱은 다음의 주요 색상을 사용합니다.

**Primary 색상**: 주황색 계열 (#FF5722). 이는 BlockPick의 브랜드 색상으로, 주요 버튼, 강조 요소, 선택된 상태 등에 사용됩니다. 예를 들어, "참가하기" 버튼은 주황색 배경에 흰색 텍스트로 표시됩니다.

**Secondary 색상**: 진한 회색 (#212121). 텍스트, 아이콘, 구분선 등에 사용됩니다.

**Background 색상**: 밝은 회색 (#FAFAFA). 화면의 기본 배경색입니다.

**Surface 색상**: 흰색 (#FFFFFF). 카드, 다이얼로그, 바텀시트 등 표면 요소의 배경색입니다.

**Success 색상**: 초록색 (#4CAF50). 성공 메시지, 당첨 알림 등에 사용됩니다.

**Error 색상**: 빨간색 (#F44336). 에러 메시지, 경고 등에 사용됩니다.

**Warning 색상**: 노란색 (#FFC107). 주의 메시지에 사용됩니다.

### 2.2 타이포그래피

**제목 1 (Headline 1)**: 크기 32sp, 굵기 Bold. 화면의 주요 제목에 사용됩니다.

**제목 2 (Headline 2)**: 크기 24sp, 굵기 Bold. 섹션 제목에 사용됩니다.

**본문 1 (Body 1)**: 크기 16sp, 굵기 Regular. 일반 텍스트에 사용됩니다.

**본문 2 (Body 2)**: 크기 14sp, 굵기 Regular. 보조 텍스트에 사용됩니다.

**캡션 (Caption)**: 크기 12sp, 굵기 Regular. 작은 설명 텍스트에 사용됩니다.

**버튼 텍스트 (Button)**: 크기 16sp, 굵기 Bold. 버튼 라벨에 사용됩니다.

### 2.3 간격 및 여백

**Small Padding**: 8dp. 작은 요소 간 간격에 사용됩니다.

**Medium Padding**: 16dp. 일반적인 요소 간 간격에 사용됩니다.

**Large Padding**: 24dp. 섹션 간 간격에 사용됩니다.

**Screen Margin**: 좌우 16dp. 화면 가장자리와 콘텐츠 사이의 여백입니다.

### 2.4 버튼 스타일

**Primary Button**: 주황색 배경, 흰색 텍스트, 모서리 반경 8dp, 높이 48dp. 주요 액션 버튼에 사용됩니다. 예: "참가하기", "충전하기".

**Secondary Button**: 흰색 배경, 주황색 테두리, 주황색 텍스트, 모서리 반경 8dp, 높이 48dp. 보조 액션 버튼에 사용됩니다. 예: "취소", "나중에".

**Text Button**: 배경 없음, 주황색 텍스트. 덜 중요한 액션에 사용됩니다. 예: "건너뛰기", "더 보기".

**Disabled Button**: 회색 배경, 연한 회색 텍스트. 비활성화 상태의 버튼입니다.

### 2.5 카드 스타일

**Elevation**: 카드는 2dp의 그림자를 가져 배경에서 약간 떠 있는 느낌을 줍니다.

**모서리 반경**: 12dp. 부드러운 모서리를 가집니다.

**배경색**: 흰색.

**패딩**: 내부 콘텐츠와 카드 가장자리 사이에 16dp 패딩이 있습니다.

## 3. 온보딩 화면

### ONBOARD-001: 스플래시 화면

사용자가 앱을 실행하면 가장 먼저 표시되는 화면입니다.

**배경**: 주황색 그라데이션 배경입니다. 상단은 밝은 주황색에서 하단은 진한 주황색으로 부드럽게 변합니다.

**로고**: 화면 중앙에 BlockPick 로고가 크게 표시됩니다. 로고는 흰색이며, 애니메이션 효과로 페이드 인됩니다. 로고 크기는 화면 너비의 60% 정도입니다.

**로딩 인디케이터**: 로고 하단에 작은 원형 로딩 인디케이터가 표시됩니다. 흰색이며, 회전 애니메이션이 적용됩니다.

**동작**: 이 화면은 2초간 표시된 후 자동으로 다음 화면으로 전환됩니다. 만약 사용자가 이미 로그인되어 있다면 메인 홈 화면으로 이동하고, 로그인되지 않았다면 온보딩 슬라이드 화면으로 이동합니다.

### ONBOARD-002: 온보딩 슬라이드 화면

신규 사용자를 위한 앱 소개 화면입니다. 총 3개의 슬라이드로 구성됩니다.

**레이아웃**: 화면 전체를 차지하는 ViewPager 형태입니다. 사용자는 좌우로 스와이프하여 슬라이드를 넘길 수 있습니다.

**슬라이드 1**:
- 상단에 일러스트 이미지가 표시됩니다. 그리드와 블록을 선택하는 모습을 표현한 이미지입니다. 이미지는 화면 너비 전체를 차지하고, 높이는 화면 높이의 50%입니다.
- 이미지 하단에 제목이 표시됩니다. "블록을 선택하고\n상금을 받으세요". 제목은 Headline 1 스타일, 중앙 정렬, 진한 회색입니다.
- 제목 아래에 설명 텍스트가 표시됩니다. "1,000×1,000 그리드에서\n9개의 블록을 선택하세요.\n당첨되면 상금을 받습니다!". Body 1 스타일, 중앙 정렬, 회색입니다.

**슬라이드 2**:
- 상단에 4개의 게임 타입 아이콘이 표시된 이미지가 있습니다.
- 제목: "4가지 게임 타입,\n다양한 재미"
- 설명: "DAILY, SELECT, VIBE, PRIME\n매일 다른 게임에 참여하고\n큰 상금을 노려보세요!"

**슬라이드 3**:
- 상단에 블록체인과 투명성을 상징하는 이미지가 있습니다.
- 제목: "안전한 블록체인 기반\n투명한 추첨"
- 설명: "모든 참여와 당첨 결과는\n블록체인에 기록되어\n누구나 검증할 수 있습니다."

**페이지 인디케이터**: 슬라이드 하단에 작은 점 3개가 표시됩니다. 현재 슬라이드는 주황색, 나머지는 회색으로 표시됩니다. 사용자가 슬라이드를 넘기면 인디케이터도 함께 움직입니다.

**버튼**:
- 슬라이드 1, 2에서는 우측 하단에 "다음" 텍스트 버튼이 있습니다. 터치하면 다음 슬라이드로 이동합니다.
- 슬라이드 3에서는 중앙 하단에 "시작하기" Primary 버튼이 있습니다. 터치하면 회원가입 화면으로 이동합니다.
- 모든 슬라이드의 좌측 하단에 "건너뛰기" 텍스트 버튼이 있습니다. 터치하면 온보딩을 건너뛰고 회원가입 화면으로 즉시 이동합니다.

## 4. 인증 화면

### AUTH-001: 회원가입 - 이메일 입력 화면

**상단 바**:
- 좌측에 뒤로 가기 아이콘 버튼이 있습니다. 터치하면 이전 화면으로 돌아갑니다.
- 중앙에 "회원가입" 텍스트가 표시됩니다. Headline 2 스타일입니다.

**진행 상태 바**:
- 상단 바 아래에 가로로 진행 상태를 나타내는 바가 있습니다. 총 4단계 중 1단계를 표시합니다. 25%가 주황색으로 채워져 있고, 나머지는 연한 회색입니다.

**본문**:
- 화면 중앙 상단에 "이메일 주소를 입력해 주세요" 제목이 표시됩니다. Headline 2 스타일입니다.
- 제목 아래에 "이메일로 인증 코드를 보내드립니다" 설명 텍스트가 있습니다. Body 2 스타일, 회색입니다.
- 설명 아래에 이메일 입력 필드가 있습니다. 테두리가 있는 직사각형 필드이며, 플레이스홀더로 "example@email.com"이 표시됩니다. 사용자가 입력을 시작하면 플레이스홀더가 사라집니다.
- 입력 필드 우측에 "X" 아이콘 버튼이 있습니다. 터치하면 입력한 텍스트가 모두 지워집니다. 입력된 텍스트가 없으면 이 버튼은 표시되지 않습니다.
- 입력 필드 아래에 에러 메시지 영역이 있습니다. 기본적으로는 비어 있지만, 유효하지 않은 이메일을 입력하면 "올바른 이메일 주소를 입력해 주세요"라는 빨간색 텍스트가 표시됩니다.

**하단 버튼**:
- 화면 하단에 "다음" Primary 버튼이 있습니다. 기본적으로는 비활성화 상태(회색)이며, 유효한 이메일을 입력하면 활성화(주황색)됩니다. 터치하면 이메일 인증 화면으로 이동하며, 서버로 인증 코드 발송 요청이 전송됩니다.

### AUTH-002: 회원가입 - 이메일 인증 화면

**진행 상태 바**: 50% 채워져 있습니다 (2/4 단계).

**본문**:
- 제목: "인증 코드를 입력해 주세요"
- 설명: "입력하신 이메일로 6자리 인증 코드를 발송했습니다.\n[사용자가 입력한 이메일 주소]"
- 인증 코드 입력 필드: 6개의 네모난 칸이 가로로 나열되어 있습니다. 각 칸은 한 자리 숫자를 입력받습니다. 사용자가 숫자를 입력하면 자동으로 다음 칸으로 포커스가 이동합니다. 모든 칸이 채워지면 자동으로 인증 확인 요청이 서버로 전송됩니다.
- 인증 코드 입력 칸 아래에 "코드를 받지 못하셨나요?" 텍스트와 "재발송" 텍스트 버튼이 있습니다. 재발송 버튼을 터치하면 새로운 인증 코드가 발송되고, "새 코드를 발송했습니다" 스낵바 메시지가 하단에 표시됩니다.
- 재발송 버튼 우측에 카운트다운 타이머가 표시됩니다. "10:00"부터 시작하여 1초씩 감소합니다. 0이 되면 "코드가 만료되었습니다. 재발송해 주세요"라는 메시지가 표시됩니다.

**로딩 상태**:
- 인증 코드 6자리를 모두 입력하면 자동으로 검증이 시작되며, 화면 중앙에 로딩 인디케이터가 표시됩니다.
- 인증 성공 시 자동으로 다음 화면(비밀번호 설정)으로 이동합니다.
- 인증 실패 시 "인증 코드가 올바르지 않습니다" 에러 메시지가 표시되고, 입력 칸이 모두 지워집니다.

### AUTH-003: 회원가입 - 비밀번호 설정 화면

**진행 상태 바**: 75% 채워져 있습니다 (3/4 단계).

**본문**:
- 제목: "비밀번호를 설정해 주세요"
- 설명: "안전한 비밀번호를 사용하세요"
- 비밀번호 입력 필드: 테두리가 있는 텍스트 필드입니다. 플레이스홀더는 "비밀번호 (8자 이상)"입니다. 입력한 문자는 점(•)으로 마스킹됩니다. 필드 우측에 눈 모양 아이콘 버튼이 있으며, 터치하면 비밀번호가 평문으로 보이거나 다시 마스킹됩니다.
- 비밀번호 입력 필드 아래에 비밀번호 강도 바가 표시됩니다. 약함(빨간색), 보통(노란색), 강함(초록색) 중 하나로 표시되며, 사용자가 입력하는 동안 실시간으로 업데이트됩니다.
- 비밀번호 조건 체크리스트가 표시됩니다:
  - "8자 이상" - 충족 시 초록색 체크 아이콘, 미충족 시 회색 체크 아이콘
  - "영문 포함" - 충족 시 초록색 체크, 미충족 시 회색 체크
  - "숫자 포함" - 충족 시 초록색 체크, 미충족 시 회색 체크
- 비밀번호 확인 입력 필드: 위와 동일한 스타일입니다. 플레이스홀더는 "비밀번호 확인"입니다.
- 비밀번호 확인 필드 아래에 일치 여부 메시지가 표시됩니다. 일치하면 "비밀번호가 일치합니다" 초록색 텍스트, 불일치하면 "비밀번호가 일치하지 않습니다" 빨간색 텍스트가 표시됩니다.

**하단 버튼**:
- "다음" Primary 버튼. 모든 조건이 충족되고 비밀번호가 일치할 때만 활성화됩니다.

### AUTH-004: 회원가입 - 닉네임 설정 화면

**진행 상태 바**: 100% 채워져 있습니다 (4/4 단계).

**본문**:
- 제목: "닉네임을 설정해 주세요"
- 설명: "다른 사용자에게 표시되는 이름입니다"
- 닉네임 입력 필드: 플레이스홀더는 "닉네임 (2-10자)"입니다.
- 입력 필드 우측에 "중복 확인" 텍스트 버튼이 있습니다. 닉네임을 입력한 후 이 버튼을 터치하면 서버에 중복 확인 요청이 전송됩니다. 사용 가능한 닉네임이면 "사용 가능한 닉네임입니다" 초록색 메시지, 이미 사용 중이면 "이미 사용 중인 닉네임입니다" 빨간색 메시지가 표시됩니다.
- 약관 동의 섹션:
  - "이용약관 동의 (필수)" 체크박스와 텍스트. 텍스트를 터치하면 이용약관 전문을 보여주는 바텀시트가 올라옵니다.
  - "개인정보 처리방침 동의 (필수)" 체크박스와 텍스트. 동일하게 바텀시트로 전문을 볼 수 있습니다.
  - "마케팅 정보 수신 동의 (선택)" 체크박스. 이메일과 푸시 알림 수신 여부를 선택합니다.
  - 상단에 "전체 동의" 체크박스가 있어, 한 번에 모든 항목을 체크할 수 있습니다.

**하단 버튼**:
- "가입 완료" Primary 버튼. 닉네임 중복 확인이 완료되고 필수 약관에 모두 동의했을 때 활성화됩니다. 터치하면 회원가입이 완료되고 지갑 생성 화면으로 이동합니다.

### AUTH-005: 지갑 생성 화면

회원가입 완료 후 자동으로 표시되는 화면입니다.

**본문**:

- 아이콘 아래에 "안전한 지갑을 생성하고 있습니다..." 텍스트와 로딩 인디케이터가 표시됩니다.

### AUTH-006: 니모닉 백업 화면

**상단 바**:
- 중앙에 "지갑 백업" 제목이 표시됩니다.
- 뒤로 가기 버튼은 없습니다. 사용자가 반드시 이 단계를 완료하도록 합니다.

**본문**:
- 경고 아이콘과 함께 "중요: 다음 12개의 단어를 안전한 곳에 보관하세요" 메시지가 표시됩니다. 배경은 연한 노란색, 텍스트는 진한 노란색입니다.
- 설명 텍스트: "이 단어들은 지갑을 복구할 때 필요합니다. 분실 시 지갑을 복구할 수 없으니 반드시 저장하세요."
- 12개의 단어가 3×4 그리드로 표시됩니다. 각 단어는 흰색 배경의 카드 안에 있으며, 번호와 함께 표시됩니다. 예: "1. apple", "2. banana", ..., "12. zebra".
- 단어 그리드 아래에 "복사하기" Secondary 버튼이 있습니다. 터치하면 12개 단어가 클립보드에 복사되고, "클립보드에 복사되었습니다" 스낵바가 표시됩니다.
- 체크박스와 "니모닉을 안전하게 보관했습니다" 텍스트가 있습니다. 이 체크박스를 선택해야 다음 버튼이 활성화됩니다.

**하단 버튼**:
- "다음" Primary 버튼. 체크박스 선택 시 활성화되며, 터치하면 니모닉 확인 화면으로 이동합니다.

### AUTH-007: 니모닉 확인 화면

사용자가 니모닉을 제대로 저장했는지 확인하는 화면입니다.

**본문**:
- 제목: "니모닉을 확인해 주세요"
- 설명: "다음 위치의 단어를 입력해 주세요"
- 무작위로 선택된 3개의 위치에 대한 입력 필드가 표시됩니다. 예:
  - "3번째 단어" - 빈 입력 필드
  - "7번째 단어" - 빈 입력 필드
  - "11번째 단어" - 빈 입력 필드
- 각 입력 필드에 올바른 단어를 입력해야 합니다. 입력한 단어가 틀리면 필드가 빨간색으로 흔들리는 애니메이션이 표시됩니다.

**하단 버튼**:
- "확인" Primary 버튼. 모든 단어를 올바르게 입력했을 때 활성화됩니다. 터치하면 메인 홈 화면으로 이동하며, "환영합니다!" 축하 메시지가 표시됩니다.

### AUTH-008: 로그인 화면

이미 계정이 있는 사용자가 로그인하는 화면입니다.

**본문**:
- 상단에 BlockPick 로고가 표시됩니다.
- 로고 아래에 "환영합니다!" 제목이 있습니다.
- 이메일 입력 필드: 플레이스홀더 "이메일"
- 비밀번호 입력 필드: 플레이스홀더 "비밀번호", 마스킹됨, 우측에 눈 아이콘 버튼.
- "로그인 상태 유지" 체크박스. 선택하면 다음 실행 시 자동 로그인됩니다.
- "비밀번호를 잊으셨나요?" 텍스트 버튼. 터치하면 비밀번호 찾기 화면으로 이동합니다.

**하단 버튼**:
- "로그인" Primary 버튼. 이메일과 비밀번호를 모두 입력했을 때 활성화됩니다.
- "아직 계정이 없으신가요? 회원가입" 텍스트 버튼. 터치하면 회원가입 화면으로 이동합니다.

**소셜 로그인**:
- 구분선과 함께 "또는" 텍스트가 표시됩니다.
- 카카오, 구글, 애플 로그인 버튼이 가로로 나열됩니다. 각 버튼은 해당 서비스의 로고와 색상을 사용합니다.

## 5. 메인 홈 화면

### HOME-001: 메인 홈 화면

**상단 바**:

**본문 - 사용자 정보 섹션**:
- 화면 상단에 사용자 정보 카드가 있습니다. 흰색 배경, 모서리가 둥근 카드입니다.

- 프로필 이미지 우측에 닉네임이 표시됩니다. "홍길동님" 형식, Headline 2 스타일입니다.
- 닉네임 아래에 "오늘도 행운을 빕니다!" 인사 메시지가 Body 2 스타일로 표시됩니다.
- 카드 우측에 Event Cash 잔액이 크게 표시됩니다. "12,500 캐시", Primary 색상, Headline 1 스타일입니다.
- 잔액 아래에 "충전하기" 작은 버튼이 있습니다.

**본문 - 빠른 액션 섹션**:
- 사용자 정보 카드 아래에 4개의 아이콘 버튼이 가로로 나열됩니다.
- "게임 참여", "내 참가", "충전", "출금" 버튼입니다.
- 각 버튼은 아이콘과 라벨로 구성됩니다. 터치하면 해당 기능의 화면으로 이동합니다.

**본문 - 진행 중인 게임 섹션**:
- "지금 참여 가능한 게임" 제목이 표시됩니다. Headline 2 스타일입니다.
- 제목 우측에 "전체 보기" 텍스트 버튼이 있습니다. 터치하면 게임 목록 화면으로 이동합니다.
- 게임 카드들이 세로로 스크롤 가능한 리스트로 표시됩니다. 각 카드는 다음 정보를 포함합니다:
  - 상단에 게임 타입 배지. "DAILY", "SELECT", "VIBE", "PRIME" 중 하나. 각 타입마다 다른 색상의 배지입니다.
  - 게임 제목. 예: "DAILY #1234"
  - 총 상금. 큰 글씨로 "500,000 캐시" 형식. Primary 색상입니다.
  - 참가비. "참가비: 1,000 캐시" 형식. Body 2 스타일, 회색입니다.
  - 현재 참여자 수 / 최대 참여자 수. "234 / 무제한" 형식. 진행 바와 함께 표시됩니다.
  - 남은 시간. "12시간 34분 남음" 형식. 시계 아이콘과 함께 표시됩니다.
  - 카드 우측에 "참가하기" 버튼이 있습니다. Primary 버튼, 작은 크기입니다.
- 게임 카드를 터치(버튼 외 영역)하면 게임 상세 화면으로 이동합니다.

**본문 - 배너 섹션**:
- 진행 중인 게임 섹션 위나 아래에 프로모션 배너가 표시됩니다.
- 배너는 슬라이더 형태로 여러 개가 자동으로 슬라이드됩니다.
- 각 배너는 이미지와 짧은 텍스트로 구성됩니다. 예: "첫 충전 시 보너스 3,000 캐시!"
- 배너를 터치하면 해당 프로모션 상세 화면이나 충전 화면으로 이동합니다.

**하단 탭 바**:
- 화면 최하단에 5개의 탭이 있습니다.
- "홈", "게임", "내 참가", "출금", "내 정보" 탭입니다.
- 각 탭은 아이콘과 라벨로 구성됩니다.
- 현재 선택된 탭(홈)은 Primary 색상, 나머지는 회색입니다.
- 탭을 터치하면 해당 화면으로 전환됩니다.

## 6. 게임 관련 화면

### GAME-001: 게임 목록 화면

하단 탭의 "게임" 탭을 선택하면 표시되는 화면입니다.

**상단 바**:

**필터 및 정렬**:
- 상단 바 아래에 칩 형태의 필터 버튼들이 가로로 스크롤 가능하게 나열됩니다.

- 선택된 칩은 Primary 색상 배경, 선택되지 않은 칩은 회색 테두리만 있습니다.
- 칩을 터치하면 해당 타입의 게임만 필터링됩니다.

- 각 게임 카드는 HOME-001에서 설명한 것과 동일한 구조입니다.
- 리스트는 무한 스크롤을 지원합니다. 하단에 도달하면 자동으로 다음 페이지의 게임들을 로드합니다.

**빈 상태**:
- 필터 조건에 맞는 게임이 없으면 중앙에 "진행 중인 게임이 없습니다" 메시지와 슬픈 얼굴 아이콘이 표시됩니다.

### GAME-002: 게임 상세 화면

**상단 바**:

- 중앙에 게임 제목 "DAILY #1234"가 표시됩니다.

**본문 - 게임 정보 섹션**:
- 화면 상단에 게임 타입 배지가 크게 표시됩니다. "DAILY" 텍스트, 주황색 배경.

  - 참가비: "1,000 캐시", 큰 글씨
  - 현재 참여자: "234명", 작은 진행 바와 함께

**본문 - 참여자 리스트 섹션** (접을 수 있음):

### GAME-003: 블록 선택 화면 (그리드 화면)

"참가하기" 버튼을 터치하면 전체 화면으로 전환되는 그리드 화면입니다.

**상단 바**:
- 좌측에 "X" 닫기 버튼이 있습니다. 터치하면 확인 다이얼로그가 나타납니다. "블록 선택을 취소하시겠습니까? 지금까지 선택한 블록이 사라집니다." "취소", "확인" 버튼이 있습니다.
- 중앙에 "블록 선택 (0/9)" 텍스트가 표시됩니다. 사용자가 블록을 선택할 때마다 숫자가 업데이트됩니다.
- 우측에 현재 잔액이 작게 표시됩니다.

**그리드 영역**:
- 화면 대부분을 차지하는 그리드가 표시됩니다. 1,000×1,000 블록이 렌더링됩니다.
- 초기 상태에서는 전체 그리드가 축소되어 보입니다.
- 사용자는 핀치 제스처로 그리드를 확대/축소할 수 있습니다. 최소 줌 레벨은 전체 그리드가 보이는 수준, 최대 줌 레벨은 개별 블록이 명확히 보이는 수준입니다.
- 사용자는 한 손가락 드래그로 그리드를 이동할 수 있습니다.
- 블록을 터치하면 해당 블록이 선택되며, 파란색으로 하이라이트됩니다.
- 이미 선택한 블록을 다시 터치하면 선택이 취소되며, 원래 색상으로 돌아갑니다.
- 9개를 모두 선택한 상태에서 새로운 블록을 터치하면 "최대 9개까지 선택할 수 있습니다" 스낵바 메시지가 표시됩니다.

**미니맵**:
- 화면 우측 하단에 작은 미니맵이 표시됩니다. 전체 그리드를 축소한 모습입니다.
- 현재 보고 있는 영역이 반투명 사각형으로 표시됩니다.
- 미니맵을 터치하면 해당 위치로 그리드 뷰가 이동합니다.
- 미니맵은 드래그하여 위치를 변경할 수 있습니다.

**선택된 블록 리스트**:
- 화면 좌측 하단에 선택된 블록들의 좌표가 작은 칩 형태로 표시됩니다.
- 예: "(123, 456)", "(234, 567)", ...
- 각 칩에는 "X" 아이콘이 있어 터치하면 해당 블록 선택이 취소됩니다.

**하단 고정 영역**:
- "참가 완료" 큰 Primary 버튼이 있습니다.
- 9개를 모두 선택하기 전에는 비활성화(회색) 상태입니다.
- 9개를 모두 선택하면 활성화(주황색)됩니다.
- 터치하면 참가 확인 다이얼로그가 나타납니다.

**참가 확인 다이얼로그**:
- 중앙에 다이얼로그가 오버레이됩니다.
- 제목: "게임에 참가하시겠습니까?"
- 본문: "참가비 1,000 캐시가 차감됩니다.\n현재 잔액: 12,500 캐시\n참가 후 잔액: 11,500 캐시\n\n선택한 블록:\n(123, 456), (234, 567), ... (9개 모두 나열)\n\n참가 후에는 취소할 수 없습니다."
- "취소" Secondary 버튼과 "참가" Primary 버튼이 있습니다.
- "참가" 버튼을 터치하면 다이얼로그가 닫히고, 로딩 인디케이터가 표시되며, 블록체인 트랜잭션이 전송됩니다.
- 트랜잭션 성공 시 성공 화면으로 전환됩니다.

### GAME-004: 참가 성공 화면

- 아이콘 아래에 "참가가 완료되었습니다!" 큰 제목이 표시됩니다. Headline 1 스타일.
- 제목 아래에 "행운을 빕니다!" 부제목이 있습니다. Body 1 스타일.
- 참가 정보 카드가 표시됩니다:
  - 게임 이름: "DAILY #1234"
  - 참가비: "1,000 캐시"
  - 선택한 블록: "(123, 456), (234, 567), ..." (9개 나열)
  - 트랜잭션 해시: "0x1234...abcd" (축약됨, 터치하면 전체 복사)
  - 게임 종료 시간: "오늘 오후 6시"
- 카드 아래에 "게임이 종료되면 알림을 보내드립니다" 안내 텍스트가 있습니다.

**하단 버튼**:

### GAME-005: 내 참가 목록 화면

하단 탭의 "내 참가" 탭을 선택하면 표시되는 화면입니다.

**상단 바**:
- 중앙에 "내 참가" 제목이 표시됩니다.

**탭 바**:
- 상단 바 아래에 3개의 탭이 있습니다.
- "진행 중", "종료됨", "당첨" 탭입니다.
- 선택된 탭은 밑줄과 Primary 색상으로 표시됩니다.

**진행 중 탭**:
- 현재 진행 중인 게임들의 참가 내역이 리스트로 표시됩니다.
- 각 카드에는 다음 정보가 포함됩니다:
  - 게임 타입 배지와 게임 이름
  - 참가 시간: "2시간 전 참가"
  - 선택한 블록 수: "9개 블록 선택"
  - 게임 종료까지 남은 시간: "10시간 30분 남음", 진행 바와 함께
  - "상세 보기" 버튼

**종료됨 탭**:

- 각 카드에는:
  - 게임 정보
  - 참가 시간
  - 종료 시간: "1일 전 종료"
  - 당첨 결과: "당첨 안 됨" (빨간색) 또는 "결과 대기 중" (회색)
  - 당첨 블록 정보 (결과가 나온 경우): "당첨 블록: (345, 678)"
  - 내 선택과의 거리: "가장 가까운 블록: 123칸 차이"

**당첨 탭**:
- 당첨된 게임들만 표시됩니다.
- 각 카드에는:
  - 게임 정보
  - 당첨 시간
  - 상금: "200,000 캐시 획득!" (큰 글씨, 초록색)
  - 당첨 블록: "(345, 678)"
  - 당첨자 수: "5명과 상금 공유"
  - "상세 보기" 버튼
- 카드 배경에 미묘한 금색 그라데이션이나 별 패턴이 있어 축하 분위기를 냅니다.

**빈 상태**:
- 각 탭에 해당하는 내역이 없으면 "참가 내역이 없습니다" 메시지와 "게임 참여하러 가기" 버튼이 표시됩니다.

## 7. Event Cash 화면

### CASH-001: Event Cash 메인 화면

하단 탭의 "출금" 탭을 선택하거나, 홈 화면의 잔액을 터치하면 표시됩니다.

**상단 바**:
- 중앙에 "Event Cash" 제목

**본문 - 잔액 카드**:
- 화면 상단에 큰 카드가 있습니다. 그라데이션 배경 (주황색 계열).
- 카드 상단에 "현재 잔액" 작은 라벨, 흰색.
- 잔액이 매우 크게 표시됩니다. "12,500 캐시", 흰색, Headline 1보다 큰 크기.
- 잔액 아래에 "1 캐시 = 1원" 작은 설명, 반투명 흰색.
- 카드 하단에 "충전하기"와 "출금하기" 두 개의 버튼이 가로로 배치됩니다. 흰색 배경, Primary 색상 텍스트.

**본문 - 빠른 액션**:
- 잔액 카드 아래에 4개의 아이콘 버튼이 2×2 그리드로 배치됩니다.
- "충전 내역", "출금 내역", "게임 사용 내역", "전체 내역" 버튼입니다.
- 각 버튼은 아이콘, 라벨, 우측 화살표로 구성됩니다.
- 터치하면 해당 내역 화면으로 이동합니다.

**본문 - 최근 거래**:
- "최근 거래" 제목, Headline 2 스타일.
- 제목 우측에 "전체 보기" 텍스트 버튼.
- 최근 5개의 거래 내역이 리스트로 표시됩니다.
- 각 항목은:
  - 좌측에 거래 유형 아이콘 (충전, 사용, 상금, 출금)
  - 거래 설명: "10,000 캐시 충전", "DAILY #1234 참가", "PRIME #999 당첨" 등
  - 거래 일시: "2시간 전", "1일 전" 등 상대 시간
  - 우측에 금액: "+10,000 캐시" (충전/상금은 초록색, 사용/출금은 빨간색)
  - 맨 우측에 거래 후 잔액: "12,500 캐시" (작은 글씨, 회색)

**빈 상태**:
- 거래 내역이 없으면 "아직 거래 내역이 없습니다" 메시지와 "충전하러 가기" 버튼이 표시됩니다.

### CASH-002: 충전 화면

"충전하기" 버튼을 터치하면 표시되는 화면입니다.

**상단 바**:
- 좌측에 뒤로 가기 버튼
- 중앙에 "Event Cash 충전" 제목

**본문 - 충전 금액 선택**:
- "충전 금액을 선택하세요" 제목, Headline 2 스타일.
- 사전 정의된 금액 옵션들이 2×3 그리드로 배치됩니다:
  - "5,000원" 카드: "5,000 캐시"
  - "10,000원" 카드: "10,000 캐시" + "인기" 배지
  - "30,000원" 카드: "30,000 캐시"
  - "50,000원" 카드: "52,500 캐시" + "+2,500 보너스" 작은 텍스트 (초록색)
  - "100,000원" 카드: "110,000 캐시" + "+10,000 보너스"
  - "직접 입력" 카드: 연필 아이콘
- 각 카드는 흰색 배경, 테두리. 선택하면 Primary 색상 테두리로 변경됩니다.
- "직접 입력" 카드를 선택하면 숫자 입력 필드가 나타납니다. 플레이스홀더 "금액 입력 (최소 3,000원)".

**본문 - 첫 충전 보너스 안내** (첫 충전 사용자만):
- 노란색 배경의 안내 카드가 표시됩니다.
- "🎁 첫 충전 보너스!" 제목
- "첫 충전 시 금액과 관계없이 3,000 캐시 추가 지급!" 설명

**본문 - 결제 수단 선택**:
- "결제 수단" 제목
- 라디오 버튼 형태로 여러 옵션이 나열됩니다:
  - 신용/체크카드 (카드 아이콘)
  - 계좌이체 (은행 아이콘)
  - 카카오페이 (카카오 로고)
  - 네이버페이 (네이버 로고)
  - 토스페이 (토스 로고)
- 선택된 옵션은 체크 표시와 Primary 색상 테두리로 강조됩니다.

**본문 - 결제 정보 요약**:
- 화면 하단 고정 영역 위에 요약 카드가 있습니다.
- "충전 금액: 10,000원"
- "보너스: +1,000 캐시" (있는 경우)
- "받을 캐시: 11,000 캐시" (굵은 글씨)

**하단 고정 영역**:
- "결제하기" 큰 Primary 버튼.
- 금액과 결제 수단을 모두 선택했을 때 활성화됩니다.
- 터치하면 결제 확인 다이얼로그가 나타납니다.

**결제 확인 다이얼로그**:
- "결제를 진행하시겠습니까?" 제목
- "결제 금액: 10,000원\n받을 캐시: 11,000 캐시\n결제 수단: 카카오페이" 본문
- "취소", "확인" 버튼
- "확인" 버튼 터치 시 PG사 결제 화면으로 전환되거나, 간편결제 앱이 실행됩니다.

**결제 처리 화면**:
- 결제가 처리되는 동안 로딩 화면이 표시됩니다.
- "결제 처리 중입니다..." 메시지와 로딩 인디케이터.
- 처리 완료 시 성공 화면으로 전환됩니다.

## 10. 공통 컴포넌트

### COMP-001: 로딩 인디케이터

**설명**: 데이터 로딩 중이거나 처리 중일 때 표시되는 컴포넌트입니다.

**스타일**:
- 원형 로딩 인디케이터. Primary 색상.
- 회전 애니메이션.
- 중앙에 위치하거나, 버튼 내부에 작게 표시될 수 있습니다.

**전체 화면 로딩**:
- 화면 전체를 반투명 회색으로 오버레이합니다.
- 중앙에 로딩 인디케이터와 "처리 중입니다..." 텍스트가 표시됩니다.

### COMP-002: 에러 스낵바

**설명**: 에러 메시지를 사용자에게 알리는 컴포넌트입니다.

**스타일**:
- 화면 하단에서 슬라이드되어 올라옵니다.
- 빨간색 배경, 흰색 텍스트.
- 좌측에 경고 아이콘.
- 3-5초간 표시된 후 자동으로 사라집니다.
- 우측에 "X" 아이콘. 터치하면 즉시 닫힙니다.

**내용**:
- 짧고 명확한 에러 메시지. 예: "네트워크 연결을 확인해 주세요", "잘못된 입력입니다"

### COMP-003: 성공 스낵바

**에러 스낵바와 동일하지만 초록색 배경, 체크 아이콘 사용**

### COMP-004: 확인 다이얼로그

**설명**: 사용자에게 중요한 결정을 확인받는 다이얼로그입니다.

**스타일**:
- 화면 중앙에 오버레이로 표시됩니다.
- 흰색 배경, 모서리가 둥근 직사각형.
- 그림자 효과.

**구조**:
- 상단에 제목. Headline 2 스타일. 예: "정말 삭제하시겠습니까?"
- 본문 텍스트. Body 1 스타일. 자세한 설명이나 경고.
- 하단에 두 개의 버튼이 가로로 배치됩니다.
  - 좌측: "취소" Secondary 버튼
  - 우측: "확인" Primary 버튼 (또는 위험한 작업의 경우 빨간색 버튼)

### COMP-005: 바텀시트

**설명**: 화면 하단에서 슬라이드되어 올라오는 시트입니다. 추가 옵션이나 정보를 표시합니다.

**스타일**:
- 화면 하단에서 위로 슬라이드 애니메이션.
- 흰색 배경, 상단 모서리가 둥글게 처리됨.
- 최상단 중앙에 작은 가로 막대 (핸들). 사용자가 드래그하여 시트를 닫을 수 있습니다.

**구조**:
- 핸들 아래에 제목 영역. 중앙에 제목, 우측에 "X" 닫기 버튼.
- 본문 영역. 리스트, 폼, 텍스트 등 다양한 콘텐츠가 표시됩니다.
- 하단에 버튼 (선택 사항).

**동작**:
- 바텀시트 외부를 터치하면 닫힙니다.
- 핸들을 아래로 드래그하면 닫힙니다.
- "X" 버튼을 터치하면 닫힙니다.

### COMP-006: 빈 상태 컴포넌트

**설명**: 리스트나 데이터가 없을 때 표시되는 컴포넌트입니다.

**스타일**:
- 화면 중앙에 위치합니다.
- 회색 계열의 일러스트 또는 아이콘.
- 아이콘 아래에 메시지 텍스트. "아직 참가 내역이 없습니다", "친구가 없습니다" 등.
- 메시지 아래에 액션 버튼 (선택 사항). 예: "게임 참여하러 가기", "친구 초대하기".

### COMP-007: 풀 화면 에러

**설명**: 전체 화면을 차지하는 에러 화면입니다. 네트워크 오류, 서버 오류 등 치명적인 에러 시 사용됩니다.

**스타일**:
- 화면 전체를 차지합니다.
- 중앙에 에러 아이콘 (빨간색 경고 삼각형 또는 슬픈 얼굴).
- 아이콘 아래에 에러 메시지. "네트워크 연결을 확인해 주세요", "서버에 일시적인 문제가 발생했습니다" 등.
- 메시지 아래에 "다시 시도" Primary 버튼.
- 하단에 "고객센터 문의" 텍스트 버튼.
