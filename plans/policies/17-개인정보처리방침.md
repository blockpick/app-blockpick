## BlockPick 개인정보 처리방침

**주식회사 블록픽**(이하 "회사"라 함)은 「개인정보 보호법」 제30조에 따라 정보주체의 개인정보를 보호하고 이와 관련한 고충을 신속하고 원활하게 처리할 수 있도록 하기 위하여 다음과 같이 개인정보 처리방침을 수립·공개합니다.

**최근 개정일**: 2025년 1월 20일

## 1. 개인정보의 처리 목적

회사는 다음의 목적을 위하여 개인정보를 처리합니다. 처리하고 있는 개인정보는 다음의 목적 이외의 용도로는 이용되지 않으며, 이용 목적이 변경되는 경우에는 「개인정보 보호법」 제18조에 따라 별도의 동의를 받는 등 필요한 조치를 이행할 예정입니다.

### 1.1 회원 가입 및 관리

- 회원 가입의사 확인
- 회원제 서비스 제공에 따른 본인 식별·인증
- 회원자격 유지·관리
- 서비스 부정이용 방지
- 각종 고지·통지
- 고충처리
- 분쟁 조정을 위한 기록 보존

### 1.2 재화 또는 서비스 제공

- 서비스 제공
- 콘텐츠 제공
- 맞춤 서비스 제공
- 본인인증
- 요금결제·정산
- 채권추심

### 1.3 게임 서비스 제공

- 블록 땅따먹기 게임 참여 및 진행
- 당첨자 선정 및 발표
- 상품 배송
- 게임 결과 기록 및 통계
- 블록체인 트랜잭션 처리

### 1.4 마케팅 및 광고 활용

- 신규 서비스(제품) 개발 및 맞춤 서비스 제공
- 이벤트 및 광고성 정보 제공 및 참여기회 제공
- 인구통계학적 특성에 따른 서비스 제공 및 광고 게재
- 서비스의 유효성 확인
- 접속빈도 파악
- 회원의 서비스 이용에 대한 통계

## 2. 개인정보의 처리 및 보유기간

### 2.1 처리 및 보유기간

회사는 법령에 따른 개인정보 보유·이용기간 또는 정보주체로부터 개인정보를 수집시에 동의받은 개인정보 보유·이용기간 내에서 개인정보를 처리·보유합니다.

각각의 개인정보 처리 및 보유 기간은 다음과 같습니다.

#### 2.1.1 회원 정보

| 구분 | 보유기간 | 근거 |
|------|----------|------|
| 일반 회원정보 | 회원 탈퇴 시까지 | 서비스 제공 |
| 소셜 로그인 정보 | 회원 탈퇴 시까지 | 서비스 제공 |
| 지갑 주소 | 회원 탈퇴 시까지 | 블록체인 거래 |

**보유기간 상세:**
- 회원 가입일로부터 회원 탈퇴 시까지 보유·이용
- 다만, 다음의 사유에 해당하는 경우에는 해당 사유 종료 시까지
  - 관계 법령 위반에 따른 수사·조사 등이 진행중인 경우: 해당 수사·조사 종료 시까지
  - 서비스 이용에 따른 채권·채무관계 잔존 시: 해당 채권·채무관계 정산 시까지

#### 2.1.2 게임 참여 기록

| 구분 | 보유기간 | 근거 |
|------|----------|------|
| 게임 참여 이력 | 5년 | 전자상거래법 |
| 당첨 기록 | 5년 | 전자상거래법 |
| 블록체인 거래 내역 | 영구 | 블록체인 특성 |

#### 2.1.3 결제 정보

| 구분 | 보유기간 | 근거 |
|------|----------|------|
| 대금결제 및 재화 공급 기록 | 5년 | 전자상거래법 제6조 |
| 계약 또는 청약철회 등에 관한 기록 | 5년 | 전자상거래법 제6조 |
| 소비자 불만 또는 분쟁처리 기록 | 3년 | 전자상거래법 제6조 |

#### 2.1.4 로그 기록

### 2.2 휴면 계정 처리

회사는 「개인정보 보호법」 제39조의6에 따라 1년간 서비스를 이용하지 않은 회원의 개인정보를 보호하기 위해 다음과 같이 조치합니다.

**처리 절차:**

1. **사전 안내** (휴면 전환 30일 전)
   - 이메일 및 SMS를 통한 사전 안내
   - 휴면 전환 예정일 고지
   - 계속 이용 의사 확인

2. **휴면 전환** (마지막 로그인 후 1년)
   - 개인정보를 별도 분리 보관
   - 서비스 이용 제한

3. **휴면 해제**
   - 본인 인증 후 즉시 해제
   - 정상 서비스 이용 가능

4. **파기** (휴면 전환 후 3년)
   - 별도 보관된 개인정보 완전 파기
   - 파기 30일 전 이메일 통지

**휴면 계정 보관 정보:**
```
- 이메일 (암호화)
- 가입일
- 마지막 로그인 일시
- 휴면 전환일
```

**분리 보관 방법:**
- 별도 데이터베이스 테이블에 암호화하여 보관
- 접근 권한 최소화
- 정기적 파기 프로세스 운영

## 3. 개인정보의 제3자 제공

### 3.1 개인정보 제3자 제공 원칙

회사는 정보주체의 개인정보를 제1조(개인정보의 처리 목적)에서 명시한 범위 내에서만 처리하며, 정보주체의 동의, 법률의 특별한 규정 등 「개인정보 보호법」 제17조 및 제18조에 해당하는 경우에만 개인정보를 제3자에게 제공합니다.

### 3.2 제3자 제공 현황

회사는 다음과 같이 개인정보를 제3자에게 제공하고 있습니다.

#### 3.2.1 상품 배송 업체

| 항목 | 내용 |
|------|------|
| **제공받는 자** | 택배 업체 (CJ대한통운, 우체국택배 등) |
| **제공 목적** | 상품 배송 |
| **제공 항목** | 수령인 성명, 전화번호, 주소 |
| **보유 및 이용기간** | 배송 완료 후 3개월 |
| **제공 근거** | 정보주체의 동의 |

#### 3.2.2 본인 인증 기관

| 항목 | 내용 |
|------|------|
| **제공받는 자** | 본인확인기관 (NICE평가정보, 코리아크레딧뷰로) |
| **제공 목적** | 본인 확인 및 인증 |
| **제공 항목** | 이름, 생년월일, 휴대폰번호, 통신사정보, 내/외국인 여부, 성별 |
| **보유 및 이용기간** | 본인 확인 후 즉시 파기 |
| **제공 근거** | 정보주체의 동의 |

#### 3.2.3 국세청 (당첨금 과세)

| 항목 | 내용 |
|------|------|
| **제공받는 자** | 국세청 |
| **제공 목적** | 제세공과금 신고 및 납부 |
| **제공 항목** | 성명, 주민등록번호, 당첨금액 |
| **보유 및 이용기간** | 법정 보존기간 |
| **제공 근거** | 소득세법 제145조 (5만원 초과 경품 시) |

**과세 기준:**
- 5만원 이하: 과세 대상 아님
- 5만원 초과 ~ 200만원 이하: 기타소득세 22% (지방세 포함)
- 200만원 초과: 기타소득세 + 초과분에 대한 누진세

### 3.3 제공 정보의 관리

**제공 시 보호조치:**
1. 최소한의 정보만 제공
2. 제공 목적 명시 및 제한
3. 암호화 전송
4. 제공 내역 기록 및 보관
5. 제공받는 자의 정보보호 수준 확인

**정보주체 권리:**
- 제3자 제공 내역 확인 요청 가능
- 제공 동의 철회 가능 (단, 법령상 의무인 경우 제외)
- 제공받는 자에게 직접 개인정보 삭제 요청 가능

## 4. 개인정보처리의 위탁

### 4.1 개인정보 처리위탁 원칙

회사는 원활한 개인정보 업무처리를 위하여 다음과 같이 개인정보 처리업무를 위탁하고 있습니다.

**위탁 관리 원칙:**
1. 위탁계약 체결 시 개인정보 보호법 제26조에 따라 위탁업무 수행목적 외 개인정보 처리금지, 기술적·관리적 보호조치, 재위탁 제한, 수탁자에 대한 관리·감독, 손해배상 등 책임에 관한 사항을 계약서 등 문서에 명시
2. 수탁자가 변경될 경우 지체없이 본 개인정보 처리방침을 통하여 공개

## 7. 개인정보의 파기

### 7.1 파기 원칙

회사는 개인정보 보유기간의 경과, 처리목적 달성 등 개인정보가 불필요하게 되었을 때에는 지체없이 해당 개인정보를 파기합니다.

### 7.2 파기 절차

**1단계: 파기 대상 선정**
- 보유기간 만료 개인정보 자동 선정
- 처리목적 달성 여부 확인
- 법령 보존 의무 확인

**2단계: 파기 심의**
- 개인정보 보호책임자 검토
- 파기 대상 최종 확인
- 파기 일정 수립

**3단계: 파기 실행**
- 전자적 파일: 복구 불가능한 방법으로 영구 삭제
- 종이 문서: 분쇄기로 분쇄 또는 소각

**4단계: 파기 기록**
- 파기 일시, 담당자, 파기 방법 등 기록
- 파기 대장 작성 및 보관 (3년)

### 7.3 파기 방법

#### 7.3.1 전자적 파일

**파기 방법:**
```sql
-- 소프트 삭제 (보존 기간 있는 경우)
UPDATE users SET
  status = 'DELETED',
  deleted_at = NOW(),
  email = CONCAT('deleted_', id, '@deleted.local'),
  phone = NULL,
  name = NULL
WHERE id = [USER_ID];

-- 하드 삭제 (보존 기간 없는 경우)
DELETE FROM users WHERE id = [USER_ID];

-- 연관 데이터 삭제
DELETE FROM sessions WHERE user_id = [USER_ID];
DELETE FROM refresh_tokens WHERE user_id = [USER_ID];
DELETE FROM delivery_addresses WHERE user_id = [USER_ID];
```

**기술적 조치:**
- Low Level Format
- 덮어쓰기 (최소 3회)
- 물리적 파괴 (저장매체 교체 시)

#### 7.3.2 종이 문서

**파기 방법:**
- 종이 문서: 분쇄기로 분쇄
- 필름, CD 등: 파쇄 또는 소각

**파기 장소:**
- 사내 파기: 개인정보 보호책임자 입회 하 실행

**접근 로그 기록:**
```sql
-- 접근 로그 테이블
CREATE TABLE access_logs (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES users(id),
  action VARCHAR(100),          -- 행위 (조회, 수정, 삭제)
  resource_type VARCHAR(100),   -- 리소스 타입
  resource_id VARCHAR(255),     -- 리소스 ID
  ip_address INET,              -- 접속 IP
  user_agent TEXT,              -- User Agent
  result VARCHAR(20),           -- 성공/실패
  created_at TIMESTAMP DEFAULT NOW()
);

-- 인덱스
CREATE INDEX idx_access_logs_user ON access_logs(user_id, created_at);
CREATE INDEX idx_access_logs_action ON access_logs(action, created_at);
```

- 보존기간: 3년

- 이상 징후 자동 알림

## 11. 추가적인 이용·제공 판단기준

회사는 「개인정보 보호법」 제15조제3항 및 제17조제4항에 따라 「개인정보 보호법 시행령」 제14조의2에 따른 사항을 고려하여 정보주체의 동의 없이 개인정보를 추가적으로 이용·제공할 수 있습니다.

이에 따라 회사는 정보주체의 동의 없이 추가적인 이용·제공을 하기 위해서 다음과 같은 사항을 고려합니다.

### 11.1 판단 기준

1. **당초 수집 목적과 관련성**
   - 당초 수집 목적과 추가 이용·제공 목적 간의 관련성 검토
   - 수집 시 예측 가능성 여부

2. **수집 정황 또는 처리 관행**
   - 개인정보 수집 당시의 정황
   - 해당 업종의 개인정보 처리 관행

3. **정보주체의 이익 침해 여부**
   - 추가 이용·제공으로 인한 정보주체 이익 침해 가능성
   - 침해 정도와 범위

4. **가명처리 또는 암호화 등 안전성 확보 조치**
   - 가명처리, 암호화 등 안전성 확보 조치 여부
   - 조치의 적정성

### 11.2 추가 이용·제공 사례

**예시 1: 부정 이용 방지**
- 당초 목적: 서비스 제공
- 추가 목적: 부정 이용 방지, 사기 탐지
- 판단: 서비스 안정적 제공을 위해 필요, 정보주체에게 이익
- 조치: 가명처리 후 분석

**예시 2: 서비스 개선**
- 당초 목적: 게임 서비스 제공
- 추가 목적: 서비스 품질 개선, 통계 분석
- 판단: 서비스 개선으로 정보주체에게 이익
- 조치: 통계 목적으로 가명처리

### 14.2 열람 청구 방법

**온라인 열람:**
```
앱 메뉴: 마이페이지 > 개인정보 관리 > 내 정보 보기
```

**서면 청구:**
1. 개인정보 열람 청구서 작성
   - 회사 웹사이트에서 양식 다운로드
2. 본인 확인 서류 첨부
   - 신분증 사본, 본인 서명

**대리인 청구:**
- 법정대리인 또는 정보주체의 위임을 받은 자

  - 위임장
  - 정보주체 신분증 사본
  - 대리인 신분증 사본
  - 법정대리인의 경우: 가족관계증명서 등

### 14.3 열람 제공 방법

**제공 방법:**
1. 앱 내 열람
2. 이메일 전송 (PDF)
3. 서면 교부 (방문 또는 우편)
4. CD, USB 등 저장매체

**처리 기간:**
- 청구일로부터 10일 이내

**수수료:**
- 무료 (과도한 반복 청구 시 실비 부과 가능)

### 14.4 권리 행사 제한

다음의 경우 열람을 제한하거나 거절할 수 있으며, 이 경우 10일 이내에 그 사유를 서면 등으로 통지합니다.

1. 법률에 따라 열람이 금지되거나 제한되는 경우
2. 다른 사람의 생명·신체를 해할 우려가 있거나 다른 사람의 재산과 그 밖의 이익을 부당하게 침해할 우려가 있는 경우
3. 공공기관이 다음 업무를 수행할 때 중대한 지장을 초래하는 경우
   - 조세의 부과·징수 또는 환급
   - 각급 학교의 성적 평가 또는 입학자 선발
   - 학력·기능 및 채용 시험, 자격 심사
   - 보상금·급부금 산정 등에 대한 평가 또는 판단
   - 다른 법률에 따라 진행 중인 감사 및 조사
