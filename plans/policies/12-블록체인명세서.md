## 1. 문서 개요

### 1.1 목적

본 문서는 BlockPick의 블록체인 레이어를 정의합니다. 스마트 컨트랙트의 구조, 함수, 이벤트, 보안 정책을 명시하여 투명하고 검증 가능한 럭키드로우 시스템을 구현합니다.

### 1.2 블록체인 사용 목적

**투명성 보장**:
- 모든 참여 기록을 블록체인에 영구 저장
- 누구나 참여 내역을 검증 가능
- 당첨자 선정 과정의 완전한 투명성

**공정성 보장**:
- Chainlink VRF를 통한 검증 가능한 랜덤성
- 조작 불가능한 당첨자 선정
- 타임스탬프 기반 자동 실행

**신뢰성 향상**:
- 중앙 서버 의존도 최소화
- 불변성(Immutability) 보장
- 분산 네트워크를 통한 가용성

### 1.3 Polygon 네트워크 선택 이유

| 항목 | Ethereum Mainnet | Polygon | 선택 이유 |
|------|------------------|---------|-----------|
| Gas Fee | 매우 높음 ($5-50) | 매우 낮음 ($0.001-0.01) | ✅ 비용 효율적 |
| 트랜잭션 속도 | 느림 (15초) | 빠름 (2초) | ✅ 사용자 경험 개선 |
| 처리량 | ~15 TPS | ~7,000 TPS | ✅ 확장성 |
| EVM 호환성 | 완전 | 완전 | ✅ Solidity 사용 가능 |
| Chainlink VRF | 지원 | 지원 | ✅ VRF 사용 가능 |

### 2.2 하이브리드 아키텍처

BlockPick은 **하이브리드 아키텍처**를 사용합니다:

**온체인 (Blockchain)**:
- 게임 참여 기록 (암호화된 블록 좌표)
- 당첨자 선정 (Chainlink VRF)
- 참여 증명 (Participation Proof)

**오프체인 (Backend Server)**:
- 사용자 정보
- 게임 상세 정보 (상품명, 이미지 등)
- Event Cash 관리
- 결제 처리

**장점**:
- 블록체인의 투명성 + 서버의 유연성
- Gas Fee 최소화 (필수 정보만 온체인)
- 빠른 쿼리 (GraphQL API 사용)

## 4. BlockPickGame 컨트랙트

### 4.1 컨트랙트 전체 코드

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.20;

import "@openzeppelin/contracts/access/AccessControl.sol";
import "@openzeppelin/contracts/security/ReentrancyGuard.sol";
import "@openzeppelin/contracts/security/Pausable.sol";
import "@openzeppelin/contracts/utils/Counters.sol";
import "@chainlink/contracts/src/v0.8/VRFConsumerBaseV2.sol";
import "@chainlink/contracts/src/v0.8/interfaces/VRFCoordinatorV2Interface.sol";

/**
 * @title BlockPickGame
 * @dev 메인 게임 컨트랙트 - 투명하고 공정한 럭키드로우
 * @notice 이 컨트랙트는 게임 참여, 당첨자 선정, 상품 수령을 관리합니다
 */
contract BlockPickGame is
    AccessControl,
    ReentrancyGuard,
    Pausable,
    VRFConsumerBaseV2
{
    using Counters for Counters.Counter;

    // ============ 역할 정의 ============
    bytes32 public constant ADMIN_ROLE = keccak256("ADMIN_ROLE");
    bytes32 public constant OPERATOR_ROLE = keccak256("OPERATOR_ROLE");

    // ============ 상수 ============
    uint256 public constant GRID_SIZE = 1000;
    uint256 public constant BLOCKS_PER_PARTICIPATION = 9;
    uint256 public constant MAX_PARTICIPANTS = 10000;

    // ============ 상태 변수 ============
    Counters.Counter private _gameIdCounter;
    Counters.Counter private _participationIdCounter;

    // Chainlink VRF
    VRFCoordinatorV2Interface private immutable i_vrfCoordinator;
    uint64 private immutable i_subscriptionId;
    bytes32 private immutable i_gasLane;
    uint32 private immutable i_callbackGasLimit;
    uint16 private constant REQUEST_CONFIRMATIONS = 3;
    uint32 private constant NUM_WORDS = 1;

    // ============ 구조체 ============

    struct Game {
        uint256 gameId;
        string gameType;        // "DAILY", "SELECT", "VIBE", "PRIME"
        uint256 entryFee;       // Wei 단위
        uint256 maxParticipants;
        uint256 currentParticipants;
        uint256 startTime;
        uint256 endTime;
        GameStatus status;
        address winner;
        uint256 winningBlock;   // 0 ~ 999,999
        uint256 randomSeed;     // Chainlink VRF seed
        uint256 vrfRequestId;   // Chainlink VRF request ID
    }

    struct Participation {
        uint256 participationId;
        uint256 gameId;
        address participant;
        bytes32 encryptedCoordinates;  // AES-256 암호화된 좌표
        uint256 timestamp;
        bool claimed;
    }

    enum GameStatus {
        UPCOMING,   // 0: 시작 전
        ONGOING,    // 1: 진행 중
        ENDED,      // 2: 종료됨
        CANCELLED   // 3: 취소됨
    }

    // ============ 매핑 ============
    mapping(uint256 => Game) public games;
    mapping(uint256 => Participation) public participations;
    mapping(uint256 => uint256[]) public gameParticipations;  // gameId => participationIds
    mapping(address => uint256[]) public userParticipations;  // user => participationIds
    mapping(uint256 => address) public vrfRequestToGame;      // VRF requestId => gameId

    // ============ 이벤트 ============
    event GameCreated(
        uint256 indexed gameId,
        string gameType,
        uint256 entryFee,
        uint256 maxParticipants,
        uint256 startTime,
        uint256 endTime
    );

    event GameJoined(
        uint256 indexed gameId,
        uint256 indexed participationId,
        address indexed participant,
        bytes32 encryptedCoordinates,
        uint256 timestamp
    );

    event WinnerSelected(
        uint256 indexed gameId,
        address indexed winner,
        uint256 winningBlock,
        uint256 randomSeed
    );

    event PrizeClaimed(
        uint256 indexed gameId,
        uint256 indexed participationId,
        address indexed winner
    );

    event GameCancelled(uint256 indexed gameId);

    event RandomnessRequested(
        uint256 indexed gameId,
        uint256 indexed requestId
    );

    event RandomnessFulfilled(
        uint256 indexed requestId,
        uint256 randomSeed
    );

    // ============ 생성자 ============

    /**
     * @dev 컨트랙트 생성자
     * @param vrfCoordinator Chainlink VRF Coordinator 주소
     * @param subscriptionId Chainlink VRF Subscription ID
     * @param gasLane Chainlink VRF Gas Lane (Key Hash)
     * @param callbackGasLimit Chainlink VRF Callback Gas Limit
     */
    constructor(
        address vrfCoordinator,
        uint64 subscriptionId,
        bytes32 gasLane,
        uint32 callbackGasLimit
    ) VRFConsumerBaseV2(vrfCoordinator) {
        i_vrfCoordinator = VRFCoordinatorV2Interface(vrfCoordinator);
        i_subscriptionId = subscriptionId;
        i_gasLane = gasLane;
        i_callbackGasLimit = callbackGasLimit;

        _grantRole(DEFAULT_ADMIN_ROLE, msg.sender);
        _grantRole(ADMIN_ROLE, msg.sender);
        _grantRole(OPERATOR_ROLE, msg.sender);
    }

    // ============ 게임 관리 함수 ============

    /**
     * @notice 새로운 게임 생성 (ADMIN만 가능)
     * @param gameType 게임 타입 ("DAILY", "SELECT", "VIBE", "PRIME")
     * @param entryFee 참가비 (Wei 단위)
     * @param maxParticipants 최대 참여자 수
     * @param startTime 게임 시작 시간 (Unix timestamp)
     * @param endTime 게임 종료 시간 (Unix timestamp)
     */
    function createGame(
        string memory gameType,
        uint256 entryFee,
        uint256 maxParticipants,
        uint256 startTime,
        uint256 endTime
    ) external onlyRole(ADMIN_ROLE) returns (uint256) {
        require(endTime > startTime, "Invalid time range");
        require(maxParticipants > 0 && maxParticipants <= MAX_PARTICIPANTS, "Invalid max participants");

        _gameIdCounter.increment();
        uint256 gameId = _gameIdCounter.current();

        games[gameId] = Game({
            gameId: gameId,
            gameType: gameType,
            entryFee: entryFee,
            maxParticipants: maxParticipants,
            currentParticipants: 0,
            startTime: startTime,
            endTime: endTime,
            status: GameStatus.UPCOMING,
            winner: address(0),
            winningBlock: 0,
            randomSeed: 0,
            vrfRequestId: 0
        });

        emit GameCreated(gameId, gameType, entryFee, maxParticipants, startTime, endTime);

        return gameId;
    }

    /**
     * @notice 게임 참가
     * @param gameId 게임 ID
     * @param encryptedCoordinates 암호화된 블록 좌표 (AES-256)
     * @dev 사용자는 백엔드에서 서명을 받아 참가합니다
     */
    function joinGame(
        uint256 gameId,
        bytes32 encryptedCoordinates
    ) external payable nonReentrant whenNotPaused {
        Game storage game = games[gameId];

        // 검증
        require(game.gameId != 0, "Game does not exist");
        require(game.status == GameStatus.ONGOING, "Game not ongoing");
        require(block.timestamp >= game.startTime, "Game not started");
        require(block.timestamp < game.endTime, "Game ended");
        require(game.currentParticipants < game.maxParticipants, "Game full");
        require(msg.value == game.entryFee, "Incorrect entry fee");

        // 참여 기록 생성
        _participationIdCounter.increment();
        uint256 participationId = _participationIdCounter.current();

        participations[participationId] = Participation({
            participationId: participationId,
            gameId: gameId,
            participant: msg.sender,
            encryptedCoordinates: encryptedCoordinates,
            timestamp: block.timestamp,
            claimed: false
        });

        // 매핑 업데이트
        gameParticipations[gameId].push(participationId);
        userParticipations[msg.sender].push(participationId);
        game.currentParticipants++;

        emit GameJoined(gameId, participationId, msg.sender, encryptedCoordinates, block.timestamp);
    }

    /**
     * @notice 게임 상태 업데이트 (OPERATOR만 가능)
     * @param gameId 게임 ID
     * @param newStatus 새로운 상태
     */
    function updateGameStatus(
        uint256 gameId,
        GameStatus newStatus
    ) external onlyRole(OPERATOR_ROLE) {
        Game storage game = games[gameId];
        require(game.gameId != 0, "Game does not exist");

        game.status = newStatus;
    }

    // ============ 당첨자 선정 함수 ============

    /**
     * @notice Chainlink VRF를 사용하여 당첨자 선정 시작
     * @param gameId 게임 ID
     * @dev 게임 종료 후 OPERATOR만 호출 가능
     */
    function requestWinnerSelection(uint256 gameId)
        external
        onlyRole(OPERATOR_ROLE)
        returns (uint256 requestId)
    {
        Game storage game = games[gameId];

        require(game.gameId != 0, "Game does not exist");
        require(game.status == GameStatus.ENDED, "Game not ended");
        require(game.currentParticipants > 0, "No participants");
        require(game.winner == address(0), "Winner already selected");

        // Chainlink VRF 요청
        requestId = i_vrfCoordinator.requestRandomWords(
            i_gasLane,
            i_subscriptionId,
            REQUEST_CONFIRMATIONS,
            i_callbackGasLimit,
            NUM_WORDS
        );

        game.vrfRequestId = requestId;
        vrfRequestToGame[requestId] = game.gameId;

        emit RandomnessRequested(gameId, requestId);

        return requestId;
    }

    /**
     * @notice Chainlink VRF 콜백 함수
     * @param requestId VRF 요청 ID
     * @param randomWords 난수 배열
     * @dev Chainlink VRF Coordinator만 호출 가능
     */
    function fulfillRandomWords(
        uint256 requestId,
        uint256[] memory randomWords
    ) internal override {
        uint256 gameId = vrfRequestToGame[requestId];
        Game storage game = games[gameId];

        require(game.gameId != 0, "Invalid game");
        require(game.winner == address(0), "Winner already selected");

        uint256 randomSeed = randomWords[0];
        game.randomSeed = randomSeed;

        // 0 ~ 999,999 범위의 랜덤 블록 선택
        uint256 winningBlock = randomSeed % (GRID_SIZE * GRID_SIZE);
        game.winningBlock = winningBlock;

        // 당첨 블록을 선택한 참여자 찾기
        // 실제로는 백엔드에서 암호화된 좌표를 복호화하여 확인
        // 온체인에서는 암호화된 좌표만 저장되므로 백엔드가 당첨자를 설정

        emit RandomnessFulfilled(requestId, randomSeed);
    }

    /**
     * @notice 당첨자 설정 (OPERATOR만 가능)
     * @param gameId 게임 ID
     * @param winner 당첨자 주소
     * @dev 백엔드에서 암호화된 좌표를 복호화한 후 호출
     */
    function setWinner(
        uint256 gameId,
        address winner
    ) external onlyRole(OPERATOR_ROLE) {
        Game storage game = games[gameId];

        require(game.gameId != 0, "Game does not exist");
        require(game.randomSeed != 0, "Random seed not generated");
        require(game.winner == address(0), "Winner already set");
        require(winner != address(0), "Invalid winner");

        game.winner = winner;

        emit WinnerSelected(gameId, winner, game.winningBlock, game.randomSeed);
    }

    /**
     * @notice 상품 수령 (당첨자만 가능)
     * @param participationId 참여 ID
     */
    function claimPrize(uint256 participationId) external nonReentrant {
        Participation storage participation = participations[participationId];
        Game storage game = games[participation.gameId];

        require(participation.participationId != 0, "Participation does not exist");
        require(participation.participant == msg.sender, "Not the participant");
        require(game.winner == msg.sender, "Not the winner");
        require(!participation.claimed, "Already claimed");

        participation.claimed = true;

        emit PrizeClaimed(participation.gameId, participationId, msg.sender);

        // 실제 상품 전달은 오프체인에서 처리
        // 온체인에서는 claimed 상태만 기록
    }

    // ============ 게임 취소 함수 ============

    /**
     * @notice 게임 취소 (ADMIN만 가능)
     * @param gameId 게임 ID
     * @dev 긴급 상황에만 사용
     */
    function cancelGame(uint256 gameId) external onlyRole(ADMIN_ROLE) {
        Game storage game = games[gameId];

        require(game.gameId != 0, "Game does not exist");
        require(game.status != GameStatus.CANCELLED, "Already cancelled");
        require(game.winner == address(0), "Winner already selected");

        game.status = GameStatus.CANCELLED;

        emit GameCancelled(gameId);

        // 참가비 환불은 백엔드에서 처리
    }

    // ============ 조회 함수 ============

    /**
     * @notice 게임 정보 조회
     */
    function getGame(uint256 gameId) external view returns (Game memory) {
        return games[gameId];
    }

    /**
     * @notice 참여 정보 조회
     */
    function getParticipation(uint256 participationId) external view returns (Participation memory) {
        return participations[participationId];
    }

    /**
     * @notice 게임의 모든 참여 ID 조회
     */
    function getGameParticipations(uint256 gameId) external view returns (uint256[] memory) {
        return gameParticipations[gameId];
    }

    /**
     * @notice 사용자의 모든 참여 ID 조회
     */
    function getUserParticipations(address user) external view returns (uint256[] memory) {
        return userParticipations[user];
    }

    /**
     * @notice 현재 게임 ID 카운터
     */
    function getCurrentGameId() external view returns (uint256) {
        return _gameIdCounter.current();
    }

    /**
     * @notice 현재 참여 ID 카운터
     */
    function getCurrentParticipationId() external view returns (uint256) {
        return _participationIdCounter.current();
    }

    // ============ 관리자 함수 ============

    /**
     * @notice 일시정지
     */
    function pause() external onlyRole(ADMIN_ROLE) {
        _pause();
    }

    /**
     * @notice 일시정지 해제
     */
    function unpause() external onlyRole(ADMIN_ROLE) {
        _unpause();
    }

    /**
     * @notice 컨트랙트 잔액 인출 (ADMIN만 가능)
     */
    function withdraw() external onlyRole(ADMIN_ROLE) {
        uint256 balance = address(this).balance;
        require(balance > 0, "No balance");

        (bool success, ) = msg.sender.call{value: balance}("");
        require(success, "Withdrawal failed");
    }

    /**
     * @notice 컨트랙트가 이더를 받을 수 있도록 설정
     */
    receive() external payable {}
}
```

## 5. Chainlink VRF 연동

### 5.1 Chainlink VRF란?

**Verifiable Random Function (검증 가능한 랜덤 함수)**:
- 블록체인에서 조작 불가능한 난수 생성
- 암호학적으로 안전한 랜덤성
- 누구나 검증 가능

### 5.2 VRF 설정

**Polygon Mainnet**:
```javascript
VRF_COORDINATOR: "0xAE975071Be8F8eE67addBC1A82488F1C24858067"
GAS_LANE (Key Hash): "0xcc294a196eeeb44da2888d17c0625cc88d70d9760a69d58d853ba6581a9ab0cd"
SUBSCRIPTION_ID: (Chainlink 대시보드에서 생성)
CALLBACK_GAS_LIMIT: 500000
```

**Amoy Testnet**:
```javascript
VRF_COORDINATOR: "0x343300b5d84D444B2ADc9116FEF1bED02BE49Cf2"
GAS_LANE: "0x816bedba8a50b294e5cbd47842baf240c2385f2eaf719edbd4f250a137a8c899"
SUBSCRIPTION_ID: (Chainlink 대시보드에서 생성)
CALLBACK_GAS_LIMIT: 500000
```

### 5.3 VRF 사용 플로우

```
1. Backend calls requestWinnerSelection(gameId)
   ↓
2. Contract requests randomness from VRF Coordinator
   ↓
3. VRF Coordinator generates random number off-chain
   ↓
4. VRF Coordinator calls fulfillRandomWords(requestId, randomWords)
   ↓
5. Contract calculates winningBlock = randomWords[0] % 1,000,000
   ↓
6. Backend decrypts coordinates and finds winner
   ↓
7. Backend calls setWinner(gameId, winner)
   ↓
8. Winner calls claimPrize(participationId)
```

### 5.4 VRF 비용

| 네트워크 | LINK 비용 | 시간 |
|----------|-----------|------|
| Polygon Mainnet | ~0.0001 LINK | 1-2 블록 (~2-4초) |
| Amoy Testnet | 무료 (테스트) | 1-2 블록 |
