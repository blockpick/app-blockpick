## 1. 비즈니스 모델 개요

### 1.1 비즈니스 정의

**BlockPick**은 블록체인 기술을 활용한 투명하고 공정한 럭키드로우 플랫폼입니다.

**핵심 가치 제안**:
- **투명성**: 모든 참여 기록을 블록체인에 저장, 누구나 검증 가능
- **공정성**: Chainlink VRF를 통한 조작 불가능한 당첨자 선정
- **재미**: 1,000×1,000 그리드에서 전략적 블록 선택, 게임 같은 경험
- **접근성**: 1,000원부터 참여 가능, 낮은 진입 장벽
- **순환성**: Event Cash 환급 시스템으로 재참여 유도

### 1.2 타겟 고객

**주요 타겟**:
- **연령**: 20대 ~ 40대 (MZ세대 중심)
- **성별**: 남녀 무관 (약 5:5 비율 예상)
- **특성**:
  - 온라인 쇼핑 경험 풍부
  - 모바일 앱 사용에 익숙
  - 새로운 기술(블록체인)에 관심
  - 합리적 가격에 프리미엄 상품 구매 희망
  - 투명성과 공정성 중시

**페르소나 1: 직장인 김민수 (29세, 남)**
- 직업: IT 회사 사원
- 소득: 연 4,500만 원
- 관심사: 최신 디지털 기기, 게임
- 니즈: 합리적 가격으로 최신 아이폰 구매 희망
- 행동: 출퇴근 시간에 앱 사용, 저녁에 게임 참여

**페르소나 2: 주부 이지은 (35세, 여)**
- 직업: 전업주부
- 가구 소득: 연 7,000만 원
- 관심사: 뷰티, 패션, 육아
- 니즈: 고가의 명품 가방을 저렴하게 획득
- 행동: 낮 시간대 앱 탐색, 친구와 함께 참여

### 1.3 시장 규모

**국내 경품/럭키드로우 시장**:
- 시장 규모: 약 6조 원 (2024년 기준)
- 연평균 성장률: 12% (2020-2024)
- 온라인 비중: 약 40% (2.4조 원)

**BlockPick의 목표 시장**:
- TAM (전체 시장): 6조 원
- SAM (유효 시장): 2.4조 원 (온라인)
- SOM (점유 가능 시장): 100억 원 (1년차 목표, 0.4% 점유율)

**시장 트렌드**:
- 투명성에 대한 소비자 요구 증가
- 블록체인 기술 인지도 상승
- 모바일 퍼스트 소비 패턴
- 소액 다빈도 소비 증가

## 2. 수익 모델

### 2.1 수익원 구조

BlockPick의 수익은 크게 **4가지 수익원**으로 구성됩니다:

| 수익원 | 설명 | 비중 (목표) |
|--------|------|-------------|
| 게임 참가비 마진 | 참가비 - 상품 원가 - 환급 | 60% |
| Event Cash 충전 수수료 | PG 수수료 제외 후 마진 | 15% |
| 광고 수익 | 브랜드 협찬 게임 | 15% |
| 쇼핑몰 수익 | 상품 판매 마진 | 10% |

### 2.2 게임 참가비 수익 모델

**수익 계산 공식**:
```
게임 수익 = (참가비 × 참여자 수) - 상품 원가 - (참가비 × 참여자 수 × 환급률) - 운영비용
```

**예시: DAILY 게임**
```
참가비: 3,000원
최대 참여자: 500명
총 참가비: 3,000원 × 500명 = 1,500,000원

상품 원가: 500,000원 (아이폰)
환급 (10%): 1,500,000원 × 10% = 150,000원
블록체인 Gas비: 약 10,000원
PG 수수료 (3%): 1,500,000원 × 3% = 45,000원

순수익 = 1,500,000 - 500,000 - 150,000 - 10,000 - 45,000 = 795,000원
수익률 = 795,000 / 1,500,000 = 53%
```

**게임 타입별 수익률**:
| 게임 타입 | 참가비 | 상품 원가 | 환급률 | 예상 수익률 |
|-----------|--------|-----------|--------|-------------|
| DAILY | 3,000원 | 500,000원 | 10% | 50-55% |
| SELECT | 5,000원 | 2,000,000원 | 20% | 45-50% |
| VIBE | 10,000원 | 5,000,000원 | 30% | 40-45% |
| PRIME | 1,000원 | 1,000,000원 | 0% | 80-85% |

### 2.3 Event Cash 충전 수익

**충전 플로우**:
```
사용자 충전: 10,000원
  ↓
PG 수수료 (3%): -300원
  ↓
Event Cash 적립: 10,000원
  ↓
게임 참가 시 사용
  ↓
환급 (평균 20%): 2,000원 재적립
  ↓
재사용 (재참여)
```

**수익 기여**:
- 직접 수익: PG 수수료 차액 (미미)
- 간접 수익: 재참여율 증가로 게임 수익 증대
- LTV (고객 생애 가치) 증가

**충전 유도 전략**:
- 충전 보너스 (10~20%)
- 첫 충전 특별 보너스
- VIP 등급별 보너스 차등

### 2.4 광고 수익 (브랜드 협찬)

**협찬 게임 모델**:

**예시: 삼성전자 협찬 게임**
```
상품: 갤럭시 S24 Ultra (정가 150만 원)
참가비: 2,000원
참여자: 300명
총 참가비: 600,000원

삼성전자 협찬:
- 상품 무료 제공 (또는 원가 50만 원에 제공)
- 광고비 지급: 1,000,000원
- 브랜딩: 게임 타이틀에 "삼성전자 presents" 표기

BlockPick 수익:
광고비: 1,000,000원
참가비: 600,000원
환급 (20%): -120,000원
운영비: -50,000원
총 수익: 1,430,000원
```

**협찬 가치 제안 (브랜드에게)**:
- 타겟 고객 직접 노출 (20~40대 MZ세대)
- 긍정적 브랜드 경험 (당첨 시 기쁨 = 브랜드 호감도 상승)
- 블록체인 활용 → 혁신적 이미지
- 소셜 공유를 통한 바이럴 효과

### 2.5 쇼핑몰 수익 (Phase 2)

**수익 모델**:
- 상품 판매 마진: 10~30%
- 제휴 수수료: 판매가의 5~15%

**Shopping Cash 활용**:
- 낙첨자가 Shopping Cash를 쇼핑몰에서 사용

- 추가 매출 발생

**예상 수익**:

- 2년차: 연 20억 원
- 3년차: 연 50억 원

## 3. 가격 정책

### 3.1 참가비 책정 원칙

**기본 원칙**:
```
참가비 = (상품 정가 / 참여자 수) × 마진율
```

**마진율 기준**:
- DAILY: 150% ~ 200%
- SELECT: 130% ~ 160%
- VIBE: 120% ~ 140%
- PRIME: 80% ~ 100% (가격 맞추기)

**예시 계산**:
```
상품: 아이폰 16 Pro (정가 155만 원)
게임 타입: DAILY
참여자 수: 500명
목표 마진율: 180%

기본 참가비 = 1,550,000 / 500 = 3,100원
마진 적용 = 3,100 × 1.8 = 5,580원
환급 고려 = 5,580 / (1 - 0.1) = 6,200원

→ 최종 참가비: 3,000원 (단순화, 심리적 가격)
```

### 3.2 가격 민감도 분석

**고객 설문 결과** (N=1,000):
| 참가비 | 참여 의향 |
|--------|-----------|
| 1,000원 | 85% |
| 3,000원 | 70% |
| 5,000원 | 50% |
| 10,000원 | 25% |
| 30,000원 | 5% |

**최적 가격대**:
- DAILY: 1,000원 ~ 3,000원 (스위트 스팟)
- SELECT: 3,000원 ~ 5,000원
- VIBE: 5,000원 ~ 10,000원

### 3.3 동적 가격 조정

**참여자 수에 따른 조정**:
```
예상 참여자가 목표의 50% 미만 → 참가비 10% 인하
예상 참여자가 목표의 150% 초과 → 다음 게임 참가비 10% 인상
```

**시즌별 조정**:
- 성수기 (연말, 명절): +10%
- 비수기 (여름): -10%
- 프로모션 기간: -20% ~ -30%

### 3.4 할인 및 프로모션

**친구 초대 할인**:
- 3명 이상 그룹 참여 시 10% 할인

### 6.2 손익분기점 분석 (BEP)

**고정비**:
- 인건비: 월 5,000만 원
- 인프라: 월 1,000만 원
- 임대료: 월 500만 원
- **합계: 월 6,500만 원**

**변동비율**:
- 상품 원가: 매출의 30%
- Event Cash 환급: 매출의 15%
- PG 수수료: 매출의 3%
- **합계: 48%**

**손익분기점 매출**:
```
BEP = 고정비 / (1 - 변동비율)
    = 6,500만 원 / (1 - 0.48)
    = 6,500만 원 / 0.52
    = 1.25억 원/월
```

**목표 달성 시기**: 2년차 3분기 (15개월차)

### 7.2 그로스 해킹 전략

**AARRR 퍼널 최적화**:

**1. Acquisition (획득)**
- ASO 최적화 → 자연 유입 증가
- 친구 초대 프로그램 → 바이럴 계수 1.5 목표
- 인플루언서 협업 → 신뢰도 구축

**2. Activation (활성화)**
- 회원가입 즉시 1,000원 지급 → 첫 게임 참여 유도
- 온보딩 튜토리얼 → 3분 내 완료
- 첫 참여 50% 할인 → 진입 장벽 낮춤

**3. Retention (재방문)**
- Event Cash 환급 → 재참여 유도
- 푸시 알림 → 신규 게임 알림, 마감 임박 알림
- 일일 미션 → 매일 접속 시 보너스

**4. Revenue (수익화)**
- 충전 보너스 → 대량 충전 유도
- VIP 등급제 → 충성 고객 우대
- 한정판 게임 → FOMO 유발

**5. Referral (추천)**
- 친구 초대 보상 → 양쪽 모두 1,000원
- 소셜 공유 버튼 → 1클릭 공유
- 당첨 인증샷 이벤트 → 자발적 홍보
