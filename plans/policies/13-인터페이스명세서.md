## 3. 결제 게이트웨이 (토스페이먼츠)

### 3.1 개요

**공식 문서**: https://docs.tosspayments.com/

**사용 API**:
- Payment API: 결제 승인, 취소
- Settlement API: 정산 조회

**Base URL**:
- Production: `https://api.tosspayments.com`
- Sandbox: `https://api.tosspayments.com` (테스트 키 사용)

### 3.2 인증

**API Key 방식**:
```javascript
const auth = Buffer.from(`${SECRET_KEY}:`).toString('base64');

headers: {
  'Authorization': `Basic ${auth}`,
  'Content-Type': 'application/json'
}
```

**환경 변수**:
```bash
TOSS_CLIENT_KEY=test_ck_... # 클라이언트 키 (프론트엔드)
TOSS_SECRET_KEY=test_sk_... # 시크릿 키 (백엔드)
```

### 3.3 결제 승인

**API**: `POST /v1/payments/confirm`

**요청 예시**:

      paymentKey,
      orderId,
      amount
    },
    {
      headers: {
        'Authorization': `Basic ${Buffer.from(`${TOSS_SECRET_KEY}:`).toString('base64')}`,
        'Content-Type': 'application/json'

async function cancelPayment(paymentKey, cancelReason, cancelAmount) {

### 3.5 에러 처리

**에러 응답 예시**:
```json
{
  "code": "INVALID_REQUEST",
  "message": "결제 금액이 일치하지 않습니다"
}
```

**주요 에러 코드**:
| 코드 | 설명 | 처리 방법 |
|------|------|-----------|
| `INVALID_REQUEST` | 잘못된 요청 | 요청 파라미터 확인 |
| `NOT_FOUND_PAYMENT` | 결제 건 없음 | paymentKey 확인 |
| `ALREADY_PROCESSED` | 이미 처리됨 | 중복 요청 방지 |
| `PROVIDER_ERROR` | PG사 오류 | 재시도 또는 고객 문의 |
| `FAILED_PAYMENT_INTERNAL_SYSTEM_ERROR` | 내부 오류 | 재시도 |

**재시도 로직**:
```javascript
async function confirmPaymentWithRetry(paymentKey, orderId, amount, maxRetries = 3) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await confirmPayment(paymentKey, orderId, amount);
    } catch (error) {
      if (error.response?.data?.code === 'PROVIDER_ERROR' && i < maxRetries - 1) {
        await new Promise(resolve => setTimeout(resolve, 2000 * (i + 1))); // 지수 백오프
        continue;
      }
      throw error;
    }
  }
}
```

## 4. 푸시 알림 (Firebase Cloud Messaging)

### 4.1 개요

**공식 문서**: https://firebase.google.com/docs/cloud-messaging

**Base URL**: `https://fcm.googleapis.com`

**버전**: FCM HTTP v1 API

### 4.2 인증

**Service Account JSON 사용**:

1. Firebase Console에서 Service Account JSON 다운로드
2. `google-auth-library` 사용

```javascript
const { google } = require('googleapis');

async function getAccessToken() {
  const key = require('./service-account.json');
  const jwtClient = new google.auth.JWT(
    key.client_email,
    null,
    key.private_key,
    ['https://www.googleapis.com/auth/firebase.messaging'],
    null
  );

  const tokens = await jwtClient.authorize();
  return tokens.access_token;
}
```

### 4.3 알림 발송

**API**: `POST /v1/projects/{project-id}/messages:send`

**요청 예시**:
```javascript
const axios = require('axios');

async function sendPushNotification(token, title, body, data) {
  const accessToken = await getAccessToken();

  const response = await axios.post(
    `https://fcm.googleapis.com/v1/projects/${PROJECT_ID}/messages:send`,
    {
      message: {
        token,
        notification: {
          title,
          body
        },
        data,
        android: {
          priority: 'high',
          notification: {
            sound: 'default',
            click_action: 'FLUTTER_NOTIFICATION_CLICK'
          }
        },
        apns: {
          payload: {
            aps: {
              sound: 'default',
              badge: 1
            }
          }
        }
      }
    },
    {
      headers: {
        'Authorization': `Bearer ${accessToken}`,
        'Content-Type': 'application/json'
      }
    }
  );

  return response.data;
}
```

**요청 페이로드**:
```typescript
interface FCMMessage {
  message: {
    token: string;  // FCM 디바이스 토큰
    notification?: {
      title: string;
      body: string;
      image?: string;
    };
    data?: {
      [key: string]: string;
    };
    android?: {
      priority: 'normal' | 'high';
      notification?: {
        sound?: string;
        click_action?: string;
        channel_id?: string;
      };
    };
    apns?: {
      payload: {
        aps: {
          sound?: string;
          badge?: number;
          alert?: {
            title?: string;
            body?: string;
          };
        };
      };
    };
  };
}
```

### 4.4 Topic 구독

**여러 사용자에게 한번에 발송**:

### 5.3 스마트 컨트랙트 호출

**게임 참가**:
```dart
import 'package:web3dart/web3dart.dart';

Future<String> joinGame(
  Web3Client client,
  EthPrivateKey credentials,
  String contractAddress,
  BigInt gameId,
  String encryptedCoordinates,
  BigInt entryFee,
) async {
  final contract = DeployedContract(
    ContractAbi.fromJson(ABI_JSON, 'BlockPickGame'),
    EthereumAddress.fromHex(contractAddress),
  );

  final joinGameFunction = contract.function('joinGame');

  final transaction = Transaction.callContract(
    contract: contract,
    function: joinGameFunction,
    parameters: [
      gameId,
      hexToBytes(encryptedCoordinates),
    ],
    value: EtherAmount.inWei(entryFee),
    maxGas: 200000,
  );

  final txHash = await client.sendTransaction(
    credentials,
    transaction,
    chainId: 137,
  );

  return txHash;
}
```

### 5.4 트랜잭션 대기

```dart
Future<TransactionReceipt?> waitForTransaction(
  Web3Client client,
  String txHash,
  {Duration timeout = const Duration(minutes: 2)}
) async {
  final stopwatch = Stopwatch()..start();

  while (stopwatch.elapsed < timeout) {
    try {
      final receipt = await client.getTransactionReceipt(txHash);
      if (receipt != null) {
        return receipt;
      }
    } catch (e) {
      // 트랜잭션이 아직 마이닝되지 않음
    }

    await Future.delayed(Duration(seconds: 2));
  }

  throw TimeoutException('Transaction not mined within timeout');
}
```

### 10.2 Apple Sign In

**공식 문서**: https://developer.apple.com/sign-in-with-apple/

**ID Token 검증**:
```javascript
const jwt = require('jsonwebtoken');
const jwksClient = require('jwks-rsa');

const client = jwksClient({
  jwksUri: 'https://appleid.apple.com/auth/keys'
});

function getKey(header, callback) {
  client.getSigningKey(header.kid, (err, key) => {
    const signingKey = key.publicKey || key.rsaPublicKey;
    callback(null, signingKey);
  });
}

async function verifyAppleToken(idToken) {
  return new Promise((resolve, reject) => {
    jwt.verify(idToken, getKey, {
      issuer: 'https://appleid.apple.com',
      audience: process.env.APPLE_CLIENT_ID
    }, (err, decoded) => {
      if (err) return reject(err);
      resolve({
        id: decoded.sub,
        email: decoded.email
      });
    });
  });
}
```

## 부록 B: 재시도 전략

```javascript
// 지수 백오프를 사용한 재시도
async function retryWithExponentialBackoff(
  fn,
  maxRetries = 3,
  initialDelay = 1000
) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      return await fn();
    } catch (error) {
      if (i === maxRetries - 1) throw error;

      const delay = initialDelay * Math.pow(2, i);
      console.log(`Retry ${i + 1}/${maxRetries} after ${delay}ms`);
      await new Promise(resolve => setTimeout(resolve, delay));
    }
  }
}

// 사용 예시
const result = await retryWithExponentialBackoff(
  () => sendPushNotification(token, title, body),
  3,
  1000
);
```
