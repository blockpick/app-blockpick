## 1. 문서 개요

### 1.1 목적

본 문서는 BlockPick 플랫폼의 Event Cash 시스템을 상세히 정의합니다. Event Cash는 플랫폼 내에서 게임 참가비로 사용되고, 상금으로 지급되는 가상 화폐입니다. 충전, 사용, 출금, 관리의 전 과정을 명확히 기술하여 사용자와 운영자가 시스템을 올바르게 이해하고 사용할 수 있도록 합니다.

### 1.2 범위

본 문서는 Event Cash의 모든 측면을 다룹니다. 여기에는 Event Cash의 정의와 특성, 현금 충전 방법과 수수료, 게임 참가 시 사용, 상금 수령, 현금 출금 절차, 거래 내역 관리, 보안 정책, 법적 준수 사항, 프로모션 및 이벤트, 고객 지원이 포함됩니다.

### 1.3 대상 독자

본 문서의 주요 독자는 다음과 같습니다. 첫째, 재무 운영팀은 Event Cash 시스템을 관리하고 모니터링합니다. 둘째, 개발팀은 충전, 출금, 거래 기록 기능을 구현합니다. 셋째, 고객 지원팀은 사용자의 Event Cash 관련 문의에 답변합니다. 넷째, 법무팀은 법적 준수 여부를 검토합니다. 다섯째, 사용자는 Event Cash를 충전하고 사용하는 방법을 이해합니다.

### 1.4 용어 정의

**Event Cash**: BlockPick 플랫폼 내에서만 사용 가능한 가상 화폐로, 게임 참가비를 지불하고 상금을 받는 데 사용됩니다. 1 Event Cash = 1원의 가치를 가집니다.

**충전(Charge)**: 실제 현금을 지불하여 Event Cash를 구매하는 행위입니다.

**사용(Spend)**: Event Cash를 게임 참가비로 소비하는 행위입니다.

**상금 수령(Win)**: 게임에서 당첨되어 Event Cash를 받는 행위입니다.

**출금(Withdraw)**: Event Cash를 실제 현금으로 변환하여 은행 계좌로 이체받는 행위입니다.

**잔액(Balance)**: 사용자가 현재 보유하고 있는 Event Cash의 총량입니다.

**PG사(Payment Gateway)**: 온라인 결제를 중개하는 업체로, 토스페이먼츠, 나이스페이, KG이니시스 등이 있습니다.

**본인인증**: 사용자가 실제 본인임을 확인하는 절차로, 휴대폰 인증이나 신분증 확인이 포함됩니다.

**KYC(Know Your Customer)**: 고객 신원 확인 절차로, 자금 세탁 방지와 미성년자 보호를 위해 필요합니다.

**AML(Anti-Money Laundering)**: 자금 세탁 방지를 위한 규정과 절차입니다.

## 2. Event Cash 개념

### 2.1 정의 및 특성

Event Cash는 BlockPick 플랫폼에서 사용되는 선불 전자지급수단입니다. 법적으로는 「전자금융거래법」상의 선불전자지급수단에 해당하며, 다음과 같은 특성을 가집니다.

**가상 화폐성**: Event Cash는 실물이 아닌 디지털 형태로만 존재합니다. 블록체인 네트워크에 기록되지 않고, BlockPick의 데이터베이스에만 저장됩니다.

**플랫폼 한정**: Event Cash는 오직 BlockPick 플랫폼 내에서만 사용 가능합니다. 다른 플랫폼이나 서비스에서는 사용할 수 없으며, 다른 사용자에게 양도할 수도 없습니다.

**고정 환율**: 1 Event Cash는 항상 1원의 가치를 가집니다. 환율 변동이 없어 사용자가 가치를 쉽게 이해할 수 있습니다.

**충전 및 출금 가능**: 사용자는 실제 현금을 지불하여 Event Cash를 충전할 수 있고, 보유한 Event Cash를 다시 현금으로 출금할 수 있습니다. 단, 출금 시 수수료가 부과됩니다.

**이자 없음**: Event Cash를 보유하고 있어도 이자가 발생하지 않습니다.

**유효기간 없음**: 일반적인 선불카드와 달리 Event Cash는 유효기간이 없습니다. 계정을 삭제하지 않는 한 영구적으로 보유할 수 있습니다.

**소수점 없음**: Event Cash는 정수 단위로만 존재합니다. 0.5 캐시와 같은 소수점은 없으며, 모든 거래는 1 캐시 단위로 이루어집니다.

### 2.2 법적 지위

Event Cash는 법적으로 다음과 같이 분류됩니다.

**전자금융거래법 적용**: Event Cash는 전자금융거래법상의 선불전자지급수단에 해당합니다. BlockPick은 전자금융업자로 등록해야 하며, 관련 규정을 준수해야 합니다.

**게임머니와의 구분**: Event Cash는 게임산업진흥에 관한 법률상의 게임머니와는 구분됩니다. 게임머니는 환전이 금지되지만, Event Cash는 선불전자지급수단으로서 합법적으로 출금이 가능합니다.

**도박과의 구분**: BlockPick 게임은 우연적 요소가 있지만, 모든 과정이 투명하게 공개되고, 결과를 조작할 수 없으며, 사행성이 과도하지 않아 합법적인 경품 제공 게임에 해당합니다.

**소비자 보호**: 전자금융거래법에 따라 사용자의 Event Cash는 보호됩니다. BlockPick은 예치금 보전 의무를 이행해야 하며, 파산 시에도 사용자의 Event Cash는 우선 변제됩니다.

### 2.3 용도

Event Cash는 다음 용도로만 사용할 수 있습니다.

**게임 참가비 지불**: DAILY, SELECT, VIBE, PRIME 등 모든 게임 타입의 참가비를 Event Cash로 지불합니다.

**상금 수령**: 게임에서 당첨되면 상금을 Event Cash 형태로 받습니다.

**출금**: 보유한 Event Cash를 실제 현금으로 출금하여 은행 계좌로 이체받습니다.

**프로모션 및 이벤트 참여**: 특정 이벤트나 프로모션에 Event Cash를 사용할 수 있습니다.

**사용 제한**: Event Cash는 다른 사용자에게 양도, 선물, 판매할 수 없습니다. 오직 본인만 사용할 수 있습니다. 또한 게임 참가 및 출금 외의 용도(예: 상품 구매)로는 사용할 수 없습니다.

### 2.4 잔액 표시

사용자의 Event Cash 잔액은 다음 위치에 항상 표시됩니다.

**앱 상단**: 모든 화면의 상단 바에 현재 잔액이 숫자로 표시됩니다. 예: "15,320 캐시"

**메인 홈**: 메인 홈 화면에 큰 글씨로 잔액이 표시되며, "충전하기" 버튼이 함께 제공됩니다.

**내 정보 화면**: 사용자 프로필 화면에서 상세한 잔액 정보를 확인할 수 있습니다. 여기에는 총 충전 금액, 총 사용 금액, 총 상금 등의 통계도 포함됩니다.

**거래 내역**: 모든 충전, 사용, 상금 수령, 출금 내역이 시간순으로 나열되며, 각 거래 후 잔액이 함께 표시됩니다.

## 3. 충전 시스템

### 3.1 충전 개요

Event Cash 충전은 사용자가 실제 현금을 지불하여 Event Cash를 구매하는 과정입니다. 다양한 결제 수단을 지원하며, 충전 즉시 잔액에 반영됩니다.

### 3.2 충전 금액 옵션

사용자는 다음의 사전 정의된 금액 중 하나를 선택하여 충전할 수 있습니다.

**5,000 캐시**: 5,000원. 소액 충전으로 DAILY 게임 5회 참여 가능.

**10,000 캐시**: 10,000원. 가장 인기 있는 옵션으로 DAILY 게임 10회 또는 PRIME 게임 1회 참여 가능.

**30,000 캐시**: 30,000원. 중간 금액으로 다양한 게임 타입에 여러 번 참여 가능.

**50,000 캐시**: 50,000원. 집중적인 게임 플레이를 위한 옵션.

**100,000 캐시**: 100,000원. 대량 충전으로 보너스 혜택 제공.

**직접 입력**: 사용자가 원하는 금액을 직접 입력할 수 있습니다. 최소 3,000원, 최대 1,000,000원까지 가능하며, 1,000원 단위로만 입력 가능합니다.

### 3.3 보너스 충전 이벤트

특정 금액 이상 충전 시 보너스 Event Cash를 추가로 제공합니다.

**50,000원 이상 충전**: 추가 5% 보너스. 50,000원 충전 시 2,500 캐시 추가, 총 52,500 캐시 지급.

**100,000원 이상 충전**: 추가 10% 보너스. 100,000원 충전 시 10,000 캐시 추가, 총 110,000 캐시 지급.

**첫 충전 보너스**: 신규 사용자가 처음 충전할 때 충전 금액과 관계없이 추가 3,000 캐시를 보너스로 지급합니다.

**이벤트 기간 보너스**: 특별한 기념일이나 프로모션 기간에는 보너스 비율을 상향 조정합니다. 예: 앱 출시 기념일에는 모든 충전 시 20% 보너스.

### 3.4 결제 수단

다양한 결제 수단을 지원하여 사용자 편의성을 높입니다.

**신용카드/체크카드**: 비자, 마스터카드, 국내 모든 카드사 지원. 카드 번호, 유효기간, CVC를 입력하여 결제합니다. 결제 정보는 PG사에 안전하게 저장되며, 다음 충전 시 재입력 없이 사용 가능합니다(사용자 동의 시).

**계좌이체**: 사용자의 은행 계좌에서 직접 이체합니다. 모든 주요 은행(국민, 신한, 우리, 하나, 농협 등) 지원. 실시간 계좌이체로 즉시 충전 완료됩니다.

**간편결제**: 카카오페이, 네이버페이, 토스페이, 페이코 등 주요 간편결제 서비스를 지원합니다. 해당 앱이 설치되어 있으면 원클릭으로 결제 가능합니다.

**애플페이(iOS)**: iPhone 및 iPad 사용자는 애플페이로 결제할 수 있습니다. Face ID나 Touch ID로 간편하게 인증합니다.

**구글페이(Android)**: Android 사용자는 구글페이로 결제할 수 있습니다.

**휴대폰 결제**: 휴대폰 요금에 합산하여 결제합니다. 통신사는 SKT, KT, LG U+ 모두 지원. 월 한도는 통신사 및 연령에 따라 다릅니다(일반적으로 월 30만 원).

### 3.5 충전 절차

Event Cash 충전은 다음 단계로 이루어집니다.

**1단계: 충전 화면 진입**
사용자는 메인 홈 화면 또는 상단 바의 "충전하기" 버튼을 터치하여 충전 화면으로 이동합니다.

**2단계: 충전 금액 선택**
사전 정의된 금액 옵션 중 하나를 선택하거나, "직접 입력"을 선택하여 원하는 금액을 입력합니다. 선택한 금액과 보너스 금액(있는 경우)이 표시됩니다. 예: "10,000원 충전 → 10,000 캐시 지급"

**3단계: 결제 수단 선택**
신용카드, 계좌이체, 간편결제, 휴대폰 결제 중 하나를 선택합니다. 이전에 저장된 결제 수단이 있다면 "최근 사용한 결제 수단"으로 표시되어 빠르게 선택할 수 있습니다.

**4단계: 결제 정보 입력**
선택한 결제 수단에 따라 필요한 정보를 입력합니다. 신용카드의 경우 카드 번호, 유효기간, CVC를 입력합니다. 간편결제의 경우 해당 앱으로 자동 전환되어 인증합니다.

**5단계: 결제 확인**
"총 결제 금액: 10,000원", "지급될 Event Cash: 10,000 캐시" 등의 정보가 표시됩니다. 사용자는 "결제하기" 버튼을 터치하여 최종 확인합니다.

**6단계: 결제 처리**
PG사로 결제 요청이 전송되고, 결제가 승인되면 로딩 인디케이터가 표시됩니다. 평균 처리 시간은 2-5초입니다.

**7단계: 충전 완료**
결제가 성공하면 "충전이 완료되었습니다!" 메시지와 함께 지급된 Event Cash와 현재 잔액이 표시됩니다. 상단 바의 잔액도 즉시 업데이트됩니다. 거래 내역에 충전 기록이 추가됩니다.

**8단계: 영수증**
사용자는 영수증을 이메일로 받거나 PDF로 다운로드할 수 있습니다. 영수증에는 거래 일시, 금액, 결제 수단, 거래 ID가 포함됩니다.

### 3.6 충전 실패 처리

결제가 실패할 수 있는 경우와 처리 방법은 다음과 같습니다.

**카드 승인 거부**: 카드사가 결제를 거부한 경우입니다. 잔액 부족, 한도 초과, 도난 카드, 해외 사용 제한 등이 원인일 수 있습니다. 사용자에게 "카드 승인이 거부되었습니다. 카드사에 문의하거나 다른 결제 수단을 사용해 주세요"라는 메시지를 표시합니다.

**네트워크 오류**: 일시적인 네트워크 문제로 결제 요청이 전송되지 않았습니다. 사용자에게 "네트워크 오류가 발생했습니다. 잠시 후 다시 시도해 주세요"라는 메시지를 표시하고, "재시도" 버튼을 제공합니다.

**PG사 서버 오류**: PG사의 서버가 일시적으로 응답하지 않습니다. 사용자에게 "결제 시스템에 일시적인 문제가 발생했습니다. 잠시 후 다시 시도해 주세요"라는 메시지를 표시합니다. 5분 후에도 문제가 지속되면 고객센터 연락처를 안내합니다.

**중복 결제 방지**: 사용자가 "결제하기" 버튼을 여러 번 빠르게 터치하여 중복 결제가 발생하는 것을 방지합니다. 첫 번째 터치 후 버튼을 비활성화하고, 결제 처리 중에는 재터치를 무시합니다.

**결제 승인 후 충전 실패**: 매우 드물지만, 결제는 승인되었으나 시스템 오류로 Event Cash가 충전되지 않는 경우가 있을 수 있습니다. 이 경우 결제 기록과 Event Cash 잔액을 자동으로 검증하고, 불일치가 발견되면 관리자에게 알림을 보내고 수동으로 처리합니다. 사용자에게는 "충전 처리 중입니다. 잠시 후 잔액이 업데이트됩니다"라는 메시지를 표시하고, 최대 1시간 내에 해결합니다.

### 3.7 충전 한도

안전한 운영과 법적 준수를 위해 충전에는 다음의 한도가 적용됩니다.

**1회 최소 충전**: 3,000원. 너무 소액의 충전은 PG 수수료로 인해 비효율적입니다.

**1회 최대 충전**: 1,000,000원. 과도한 충전을 방지하고, 자금 세탁 위험을 낮춥니다.

**일일 충전 한도**: 성인 사용자는 일일 3,000,000원까지 충전 가능합니다. 이를 초과하면 "일일 충전 한도를 초과했습니다. 내일 다시 시도해 주세요"라는 메시지가 표시됩니다.

**월 충전 한도**: 성인 사용자는 월 10,000,000원까지 충전 가능합니다.

**미성년자 제한**: 만 19세 미만 사용자는 BlockPick 서비스를 이용할 수 없습니다. 회원가입 시 본인인증을 통해 연령을 확인하며, 미성년자는 가입이 거부됩니다.

**한도 상향 요청**: VIP 사용자나 특별한 사유가 있는 경우, 고객센터를 통해 한도 상향을 요청할 수 있습니다. 본인 확인과 자금 출처 확인 후 승인될 수 있습니다.

### 3.8 결제 보안

Event Cash 충전 과정에서 보안을 최우선으로 합니다.

**HTTPS 통신**: 모든 결제 데이터는 HTTPS로 암호화되어 전송됩니다. TLS 1.2 이상 사용.

**PCI DSS 준수**: PG사는 PCI DSS(Payment Card Industry Data Security Standard) 인증을 받았으며, 카드 정보를 안전하게 처리합니다.

**카드 정보 비저장**: BlockPick 서버는 사용자의 카드 정보를 직접 저장하지 않습니다. 모든 카드 정보는 PG사에 저장되며, BlockPick은 토큰만 받아 사용합니다.

**3D Secure**: 신용카드 결제 시 3D Secure(VISA Secure, Mastercard Identity Check) 인증을 지원하여 추가 보안 계층을 제공합니다.

**이상 거래 탐지**: 비정상적인 충전 패턴(예: 단시간 내 대량 충전, 해외 IP에서의 충전)을 자동으로 탐지하고 차단합니다. 의심스러운 거래는 수동 검토를 거칩니다.

## 4. 사용 시스템

### 4.1 Event Cash 사용 개요

Event Cash는 주로 게임 참가비를 지불하는 데 사용됩니다. 게임에 참여할 때 자동으로 차감되며, 거래 내역에 기록됩니다.

### 4.2 게임 참가비 지불

게임에 참여하는 과정에서 Event Cash가 차감됩니다.

**1단계: 게임 선택**
사용자는 게임 목록에서 참여하고 싶은 게임을 선택합니다. 게임 상세 화면에서 참가비가 명확히 표시됩니다. 예: "참가비: 1,000 캐시"

**2단계: 잔액 확인**
시스템은 사용자의 현재 Event Cash 잔액을 확인합니다. 잔액이 참가비보다 적으면 "Event Cash가 부족합니다. 현재 잔액: 500 캐시, 필요 금액: 1,000 캐시. 충전하시겠습니까?"라는 메시지를 표시하고 "충전하기" 버튼을 제공합니다.

**3단계: 블록 선택**
잔액이 충분하면 사용자는 그리드에서 9개의 블록을 선택합니다.

**4단계: 참가 확인**
블록 선택을 완료한 후 "참가 완료" 버튼을 터치하면 확인 팝업이 나타납니다. "정말 참가하시겠습니까? 참가비 1,000 캐시가 차감됩니다. 현재 잔액: 10,000 캐시 → 참가 후 잔액: 9,000 캐시"라는 정보가 표시됩니다.

**5단계: Event Cash 차감**
사용자가 "확인"을 터치하면 Event Cash가 즉시 차감됩니다. 잔액이 업데이트되고, 거래 내역에 "DAILY 게임 참가 - 1,000 캐시 사용, 잔액: 9,000 캐시"라는 기록이 추가됩니다.

**6단계: 블록체인 기록**
선택한 블록의 암호화된 좌표와 참여 사실이 블록체인에 기록됩니다. 이는 참가비 지불과는 별개의 프로세스이며, Event Cash 차감 후 비동기적으로 수행됩니다.

### 4.3 복수 참여

한 게임에 여러 번 참여할 경우, 각 참여마다 참가비가 차감됩니다.

**예시**: 사용자가 PRIME 게임에 3번 참여하는 경우:
- 첫 번째 참여: 10,000 캐시 차감, 잔액 90,000 → 80,000
- 두 번째 참여: 10,000 캐시 차감, 잔액 80,000 → 70,000
- 세 번째 참여: 10,000 캐시 차감, 잔액 70,000 → 60,000
- 총 30,000 캐시가 차감됩니다.

각 참여는 독립적인 거래로 기록되며, 게임 결과도 각각 별도로 결정됩니다.

### 4.4 참가 취소 불가

게임에 참여하고 Event Cash가 차감된 후에는 취소할 수 없습니다. 이는 공정성을 위한 규칙입니다. 참여 확인 팝업에 "참가 후에는 취소할 수 없습니다"라는 경고 문구가 표시됩니다.

### 4.5 잔액 부족 시 자동 충전

사용자 편의를 위해 잔액 부족 시 자동 충전 옵션을 제공할 수 있습니다.

**자동 충전 설정**: 사용자는 설정 화면에서 "잔액이 5,000 캐시 이하로 떨어지면 자동으로 10,000원 충전"과 같은 규칙을 설정할 수 있습니다.

**결제 수단 미리 등록**: 자동 충전을 위해 사용자는 결제 수단을 미리 등록하고, 비밀번호나 생체인증으로 보호합니다.

**알림**: 자동 충전이 실행되면 사용자에게 푸시 알림과 이메일이 발송됩니다. "10,000원이 자동 충전되었습니다. 현재 잔액: 15,000 캐시"

**한도**: 자동 충전도 일일/월 충전 한도에 포함됩니다. 한도를 초과하면 자동 충전이 실행되지 않고, 사용자에게 알림이 발송됩니다.

## 5. 출금 시스템

### 5.1 출금 개요

출금은 보유한 Event Cash를 실제 현금으로 변환하여 은행 계좌로 이체받는 과정입니다. 출금에는 수수료가 부과되며, 본인인증과 계좌 확인이 필요합니다.

### 5.2 출금 조건

출금을 하기 위해서는 다음 조건을 만족해야 합니다.

**최소 출금 금액**: 10,000 캐시 이상부터 출금 가능합니다. 소액 출금은 수수료로 인해 비효율적이므로 제한합니다.

**최대 출금 금액**: 1회 최대 10,000,000 캐시까지 출금 가능합니다. 이를 초과하는 경우 여러 번에 나누어 출금해야 합니다.

**본인인증 완료**: 최초 출금 시 휴대폰 본인인증을 완료해야 합니다. 이는 자금 세탁 방지와 도용 방지를 위한 조치입니다.

**계좌 등록**: 출금받을 은행 계좌를 등록해야 합니다. 계좌는 본인 명의여야 하며, 예금주 이름이 회원가입 시 입력한 이름과 일치해야 합니다.

**대기 기간 없음**: 충전 즉시 출금이 가능합니다. 일부 플랫폼은 충전 후 일정 기간 출금을 제한하지만, BlockPick은 사용자 편의를 위해 이러한 제한을 두지 않습니다. 단, 이상 거래 탐지 시스템이 의심스러운 패턴을 감지하면 출금이 일시적으로 보류될 수 있습니다.

### 5.3 출금 수수료

출금 시 다음의 수수료가 부과됩니다.

**기본 수수료**: 출금 금액의 5%. 예를 들어, 100,000 캐시를 출금하면 5,000원의 수수료가 차감되어 95,000원이 입금됩니다.

**최소 수수료**: 500원. 출금 금액이 10,000 캐시라도 최소 500원의 수수료가 부과됩니다.

**수수료 면제 조건**: VIP 등급 사용자나 특별 프로모션 기간에는 수수료가 면제되거나 할인될 수 있습니다. 예를 들어, 월 1회 출금은 수수료 무료, 2회째부터 수수료 부과.

**수수료 공지**: 출금 신청 전에 수수료가 명확히 표시됩니다. "출금 신청 금액: 100,000 캐시, 수수료: 5,000원, 실제 입금액: 95,000원"

### 5.4 출금 절차

Event Cash 출금은 다음 단계로 이루어집니다.

**1단계: 출금 화면 진입**
사용자는 메뉴에서 "출금하기" 옵션을 선택하여 출금 화면으로 이동합니다.

**2단계: 출금 금액 입력**
출금하고 싶은 Event Cash 금액을 입력합니다. 전액 출금을 위한 "전체" 버튼도 제공됩니다. 입력한 금액에 따라 수수료와 실제 입금액이 자동으로 계산되어 표시됩니다.

**3단계: 본인인증 (최초 1회)**
최초 출금 시에는 휴대폰 본인인증을 수행해야 합니다. "본인인증하기" 버튼을 터치하면 본인인증 서비스(PASS, NICE 평가정보 등)로 연결됩니다. 휴대폰 번호를 입력하고, 수신한 인증번호를 입력하여 본인임을 확인합니다. 인증이 완료되면 이름과 주민등록번호 뒷자리가 확인됩니다. 이후 출금 시에는 본인인증이 생략됩니다.

**4단계: 계좌 등록 (최초 1회)**
최초 출금 시에는 출금받을 은행 계좌를 등록해야 합니다. 은행을 선택하고, 계좌번호를 입력하며, 예금주 이름을 입력합니다. 예금주 이름은 본인인증 시 확인된 이름과 일치해야 합니다. "계좌 확인" 버튼을 터치하면 은행 API를 통해 계좌 유효성을 검증합니다. 유효한 계좌이고 예금주가 일치하면 등록이 완료됩니다. 등록된 계좌는 저장되어 이후 출금 시 선택할 수 있습니다.

**5단계: 출금 신청 확인**
모든 정보가 입력되면 최종 확인 화면이 표시됩니다. "출금 신청 금액: 100,000 캐시, 수수료: 5,000원, 실제 입금 금액: 95,000원, 입금 계좌: 국민은행 123-456-789 (홍길동)"과 같은 정보가 표시됩니다. 사용자는 "출금 신청" 버튼을 터치하여 최종 확인합니다.

**6단계: Event Cash 차감**
출금 신청이 접수되면 해당 금액의 Event Cash가 즉시 차감됩니다. 잔액이 업데이트되고, 거래 내역에 "출금 신청 - 100,000 캐시 (처리 중)"이라는 기록이 추가됩니다.

**7단계: 출금 처리**
출금 신청은 수동 또는 자동으로 검토됩니다. 이상 거래 탐지 시스템이 의심스러운 패턴을 발견하지 않으면 자동으로 승인됩니다. 의심스러운 경우 관리자가 수동으로 검토하며, 필요시 사용자에게 추가 확인을 요청합니다. 승인되면 은행 API를 통해 계좌 이체가 실행됩니다.

**8단계: 입금 완료**
이체가 완료되면 사용자에게 푸시 알림과 이메일이 발송됩니다. "출금이 완료되었습니다. 95,000원이 국민은행 123-456-789 계좌로 입금되었습니다." 거래 내역에서 "출금 완료"로 상태가 업데이트됩니다.

### 5.5 출금 처리 시간

출금 신청부터 실제 입금까지의 소요 시간은 다음과 같습니다.

**자동 승인 (정상 거래)**: 신청 후 1시간 이내에 처리됩니다. 대부분의 출금은 자동으로 승인되어 빠르게 처리됩니다.

**수동 검토 (의심 거래)**: 신청 후 영업일 기준 1-2일 내에 처리됩니다. 관리자가 거래 내역을 검토하고, 필요시 사용자에게 추가 정보를 요청합니다.

**은행 처리 시간**: 승인 후 은행의 이체 처리 시간은 일반적으로 즉시에서 수 시간 이내입니다. 단, 은행 점검 시간(보통 밤 11시-12시)이나 주말/공휴일에는 지연될 수 있습니다.

**최대 처리 시간**: 모든 출금은 신청 후 영업일 기준 3일 이내에 처리됩니다. 이를 초과하는 경우 자동으로 고객센터에 에스컬레이션됩니다.

### 5.6 출금 실패 처리

출금이 실패할 수 있는 경우와 처리 방법은 다음과 같습니다.

**계좌 정보 오류**: 계좌번호가 잘못되었거나 폐쇄된 계좌인 경우입니다. 사용자에게 "출금이 실패했습니다. 계좌 정보를 확인해 주세요"라는 알림을 보내고, 차감된 Event Cash를 즉시 환원합니다.

**은행 시스템 오류**: 은행의 일시적인 시스템 장애로 이체가 실패한 경우입니다. 자동으로 재시도하며, 3회 재시도 후에도 실패하면 사용자에게 알리고 Event Cash를 환원합니다.

**한도 초과**: 은행의 1일 이체 한도를 초과한 경우입니다. 사용자에게 안내하고, 다음 날 자동으로 재시도하거나 금액을 나누어 출금하도록 안내합니다.

**사기 의심**: 이상 거래 탐지 시스템이 사기 가능성을 감지한 경우입니다. 출금을 일시 보류하고, 사용자에게 신원 확인을 요청합니다. 본인 확인이 완료되면 출금을 진행하고, 확인되지 않으면 계정을 정지합니다.

### 5.7 출금 한도

안전한 운영을 위해 출금에도 한도가 적용됩니다.

**1회 최소 출금**: 10,000 캐시 (10,000원).

**1회 최대 출금**: 10,000,000 캐시 (10,000,000원).

**일일 출금 한도**: 성인 사용자는 일일 10,000,000 캐시까지 출금 가능합니다.

**월 출금 한도**: 성인 사용자는 월 50,000,000 캐시까지 출금 가능합니다.

**출금 횟수 제한**: 일일 최대 5회까지 출금 신청 가능합니다. 너무 잦은 출금은 시스템 부하와 수수료 증가를 초래하므로 제한합니다.

**한도 상향 요청**: VIP 사용자는 고객센터를 통해 한도 상향을 요청할 수 있습니다.

### 5.8 세금 및 법적 의무

출금 시 세금과 법적 의무 사항은 다음과 같습니다.

**소득세**: 게임 상금은 기타소득으로 분류되며, 소득세법에 따라 과세될 수 있습니다. 단, 연간 300만 원 이하의 기타소득은 비과세입니다. 연간 상금이 300만 원을 초과하는 경우, BlockPick은 원천징수를 하고 지급명세서를 제출해야 할 수 있습니다. 사용자는 출금 시 이에 동의해야 합니다.

**금융정보 분석원 보고**: 대량의 현금 거래는 「특정 금융거래정보의 보고 및 이용 등에 관한 법률」에 따라 금융정보분석원(FIU)에 보고될 수 있습니다. 일일 1,000만 원 이상의 출금은 의심거래로 간주되어 보고될 수 있습니다.

## 6. 거래 내역 관리

### 6.1 거래 내역 조회

사용자는 모든 Event Cash 관련 거래 내역을 조회할 수 있습니다.

**거래 내역 화면**: 메뉴에서 "거래 내역" 옵션을 선택하면 모든 거래가 시간순으로 나열됩니다. 최신 거래가 맨 위에 표시됩니다.

**거래 유형**: 각 거래는 유형에 따라 아이콘과 색상으로 구분됩니다.
- 충전 (CHARGE): 초록색 ↑ 아이콘
- 사용 (SPEND): 빨간색 ↓ 아이콘
- 상금 수령 (WIN): 금색 ★ 아이콘
- 출금 (WITHDRAW): 파란색 ⇄ 아이콘

**거래 정보**: 각 거래 항목에는 다음 정보가 표시됩니다.
- 날짜 및 시간
- 거래 유형 및 설명 (예: "DAILY 게임 참가", "10,000원 충전", "PRIME 게임 당첨")
- 금액 (+ 또는 - 부호 포함)
- 거래 후 잔액
- 거래 상태 (완료, 처리 중, 실패)

**필터링**: 거래 유형별로 필터링할 수 있습니다. "충전만 보기", "출금만 보기" 등의 옵션을 선택하면 해당 유형의 거래만 표시됩니다.

**검색**: 날짜 범위를 지정하여 특정 기간의 거래만 조회할 수 있습니다. "지난 7일", "지난 30일", "지난 1년", "직접 입력" 등의 옵션이 제공됩니다.

**내보내기**: 거래 내역을 CSV 또는 Excel 파일로 내보낼 수 있습니다. 세금 신고나 개인 회계 목적으로 유용합니다.

### 6.2 영수증 및 증빙

각 거래에 대한 영수증과 증빙 자료를 제공합니다.

**충전 영수증**: 충전 시 결제 영수증이 자동으로 생성됩니다. 거래 내역에서 해당 충전 항목을 터치하면 "영수증 보기" 옵션이 나타나며, 이를 선택하면 PDF 형식의 영수증이 표시됩니다. 영수증에는 상호명(BlockPick), 사업자등록번호, 거래일시, 거래금액, 결제수단, 승인번호 등이 포함됩니다. 사용자는 이를 이메일로 전송하거나 다운로드할 수 있습니다.

**출금 확인서**: 출금 완료 시 확인서가 생성됩니다. 출금 금액, 수수료, 실제 입금액, 입금 계좌, 처리 일시 등이 포함됩니다.

**게임 참가 확인서**: 게임 참가 내역도 확인서로 제공됩니다. 게임 이름, 참가비, 선택한 블록 좌표, 참가 시간, 블록체인 트랜잭션 해시 등이 포함됩니다.

**연간 거래 내역서**: 연말에는 1년간의 모든 거래를 요약한 내역서를 제공합니다. 총 충전 금액, 총 사용 금액, 총 상금, 총 출금 금액 등이 포함되며, 세금 신고 시 참고할 수 있습니다.

### 6.3 거래 ID 및 추적

모든 거래에는 고유한 ID가 부여되어 추적이 가능합니다.

**거래 ID 형식**: 각 거래는 고유한 UUID 형식의 ID를 가집니다. 예: "TXN-12345678-ABCD-1234-EFGH-1234567890AB"

**블록체인 트랜잭션 해시**: 게임 참가와 같이 블록체인에 기록되는 거래는 Polygon 블록체인의 트랜잭션 해시도 함께 기록됩니다. 사용자는 이 해시를 Polygon 블록체인 탐색기(PolygonScan)에서 검색하여 거래를 검증할 수 있습니다.

**고객센터 문의 시**: 거래 관련 문의 시 거래 ID를 제공하면 신속하고 정확한 지원을 받을 수 있습니다.

## 7. 보안 및 사기 방지

### 7.1 계정 보안

Event Cash는 금전적 가치가 있으므로 계정 보안이 중요합니다.

**강력한 비밀번호**: 사용자는 최소 8자 이상의 강력한 비밀번호를 설정해야 합니다. 대문자, 소문자, 숫자, 특수문자를 조합하도록 권장합니다.

**2단계 인증 (2FA)**: 사용자는 설정에서 2단계 인증을 활성화할 수 있습니다. 로그인 시 비밀번호 외에 휴대폰으로 전송된 인증번호를 입력해야 합니다.

**생체인증**: 중요한 작업(출금, 설정 변경 등)을 할 때 생체인증(지문, Face ID)을 요구할 수 있습니다.

**로그인 알림**: 새로운 기기나 위치에서 로그인하면 사용자에게 알림이 발송됩니다. "새로운 기기에서 로그인했습니다. 본인이 아니라면 즉시 비밀번호를 변경하세요"

**세션 관리**: 사용자는 현재 로그인된 모든 기기와 세션을 확인하고, 의심스러운 세션을 원격으로 로그아웃할 수 있습니다.

### 7.2 이상 거래 탐지

시스템은 이상한 거래 패턴을 자동으로 탐지하여 사기를 방지합니다.

**대량 충전 탐지**: 단시간 내에 비정상적으로 많은 금액을 충전하는 경우 경고합니다. 예: 1시간 내에 10회 이상 충전.

**잦은 충전/출금**: 충전 후 즉시 출금하는 패턴이 반복되면 자금 세탁 가능성으로 간주하여 계정을 일시 정지하고 검토합니다.

**해외 IP 접속**: 평소와 다른 국가의 IP에서 접속하여 출금을 시도하면 추가 인증을 요구합니다.

**도용 카드**: 신용카드 도용 데이터베이스와 연동하여 도난 카드로 결제를 시도하면 차단합니다.

**봇 탐지**: 비정상적으로 빠른 속도로 반복적인 작업(예: 초당 여러 번 게임 참가)을 수행하면 봇으로 간주하여 차단합니다.

### 7.3 사기 유형 및 대응

예상되는 사기 유형과 대응 방안은 다음과 같습니다.

**도용 계정**: 타인의 계정을 해킹하여 Event Cash를 사용하거나 출금하려는 시도입니다. 2단계 인증, 생체인증, 로그인 알림으로 방어합니다. 의심스러운 활동이 감지되면 계정을 일시 정지하고 본인 확인을 요청합니다.

**카드 사기**: 도난 신용카드로 Event Cash를 충전한 후 출금하려는 시도입니다. PG사의 사기 탐지 시스템과 연동하여 의심스러운 카드를 차단합니다. 충전 후 일정 기간 내에 출금을 시도하면 추가 검증을 수행합니다.

**자금 세탁**: 불법 자금을 Event Cash로 전환하여 세탁하려는 시도입니다. 대량 충전/출금 패턴을 모니터링하고, 의심 거래는 FIU에 보고합니다. KYC를 강화하여 고액 거래 사용자의 신원을 확인합니다.

**다중 계정**: 프로모션 보너스를 여러 번 받기 위해 다중 계정을 생성하는 시도입니다. 이메일, 휴대폰 번호, 지갑 주소, 결제 카드 정보를 분석하여 다중 계정을 탐지하고 차단합니다.

**담합 및 부정 참여**: 여러 사용자가 담합하여 특정 블록을 집중 선택하거나 부정한 방법으로 당첨을 노리는 시도입니다. 게임 참여 패턴을 분석하여 이상한 협력 관계를 탐지합니다. 단, VIBE 게임에서 소규모 친구 그룹의 협력은 게임의 일부로 허용됩니다.

### 7.4 사용자 보호

사용자를 보호하기 위한 추가 조치는 다음과 같습니다.

**피싱 방지**: BlockPick은 절대로 이메일이나 문자로 비밀번호, 카드 정보, 개인키를 요청하지 않습니다. 이러한 요청을 받으면 피싱 시도이므로 무시하고 신고하도록 안내합니다.

**공식 채널 안내**: 사용자에게 공식 웹사이트, 앱스토어 링크, 고객센터 연락처를 명확히 안내하여 가짜 사이트나 앱에 속지 않도록 합니다.

**교육**: 앱 내에서 보안 팁과 사기 예방 가이드를 제공합니다. "절대 개인키를 공유하지 마세요", "의심스러운 링크를 클릭하지 마세요" 등의 안내를 정기적으로 표시합니다.

## 8. 법적 준수 사항

### 8.1 전자금융거래법 준수

BlockPick은 전자금융거래법을 준수합니다.

**전자금융업 등록**: BlockPick은 선불전자지급수단 발행업자로 금융위원회에 등록해야 합니다. 등록 번호는 사용자에게 공개됩니다.

**이용자 보호**: 전자금융거래법 제15조에 따라 사용자의 예치금을 보호합니다. 사용자가 보유한 Event Cash 총액의 100%를 은행에 예치하거나 금융위원회가 인정하는 방법으로 보전합니다.

**거래 기록 보관**: 모든 거래 기록은 최소 5년간 보관해야 합니다. 사용자는 언제든지 자신의 거래 내역을 조회하고 증빙 자료를 요청할 수 있습니다.

**분쟁 처리**: 전자금융 거래와 관련한 분쟁이 발생하면 금융감독원의 금융분쟁조정위원회에 조정을 신청할 수 있습니다.

### 8.2 자금 세탁 방지 (AML)

자금 세탁을 방지하기 위한 조치를 이행합니다.

**KYC (고객 신원 확인)**: 모든 사용자는 회원가입 시 본인인증을 완료해야 합니다. 휴대폰 인증을 통해 이름, 생년월일, 성별을 확인합니다.

**고액 거래 모니터링**: 일일 100만 원 이상의 충전이나 출금은 자동으로 모니터링됩니다. 의심스러운 패턴이 발견되면 추가 신원 확인을 요청합니다.

**의심 거래 보고**: 자금 세탁이 의심되는 거래는 금융정보분석원(FIU)에 보고합니다. 특정 금융거래정보의 보고 및 이용 등에 관한 법률(특정금융정보법)을 준수합니다.

**거래 기록 제공**: 법 집행 기관의 합법적인 요청이 있을 경우, 법원 영장에 따라 거래 기록을 제공합니다.

### 8.3 미성년자 보호

미성년자의 서비스 이용을 엄격히 금지합니다.

**연령 확인**: 회원가입 시 본인인증을 통해 만 19세 이상임을 확인합니다. 미성년자는 가입이 거부됩니다.

**미성년자 발견 시**: 가입 후 미성년자임이 밝혀지면 즉시 계정을 정지하고, 보유한 Event Cash는 법정대리인에게 환불합니다.

**광고 제한**: 미성년자를 대상으로 한 광고나 마케팅은 하지 않습니다.

### 8.4 세금 신고

게임 상금에 대한 세금 의무를 이행합니다.

**기타소득 신고**: 사용자가 연간 300만 원을 초과하는 상금을 받은 경우, BlockPick은 이를 기타소득으로 세무서에 신고해야 합니다.

**원천징수**: 필요시 상금에서 소득세를 원천징수하고, 영수증을 사용자에게 제공합니다.

**지급명세서 제출**: 연말에 지급명세서를 세무서에 제출하고, 사용자에게도 사본을 제공합니다.

### 8.5 개인정보 보호

개인정보보호법을 준수합니다.

**개인정보 수집 동의**: 회원가입 시 개인정보 수집 및 이용에 대한 동의를 받습니다. 필수 항목과 선택 항목을 구분하여 안내합니다.

**개인정보 암호화**: 이름, 생년월일, 휴대폰 번호, 계좌 정보 등 민감한 개인정보는 암호화하여 저장합니다.

**개인정보 파기**: 사용자가 계정을 삭제하거나 보유 기간이 만료되면 개인정보를 즉시 파기합니다.

**제3자 제공 금지**: 사용자의 개인정보를 사용자 동의 없이 제3자에게 제공하거나 판매하지 않습니다.

## 9. 이벤트 및 프로모션

### 9.1 Event Cash 프로모션

사용자 유치와 활성화를 위해 다양한 Event Cash 프로모션을 진행합니다.

**신규 가입 보너스**: 신규 회원가입 시 3,000 Event Cash를 무료로 지급합니다. 사용자는 충전 없이 바로 DAILY 게임 3회 또는 VIBE 게임 1회에 참여할 수 있습니다.

**첫 충전 보너스**: 첫 충전 시 충전 금액에 관계없이 추가 3,000 Event Cash를 지급합니다.

**대량 충전 보너스**: 50,000원 이상 충전 시 5% 보너스, 100,000원 이상 충전 시 10% 보너스를 지급합니다.

**출석 체크 보너스**: 매일 앱에 접속하면 출석 체크를 할 수 있습니다. 7일 연속 출석 시 1,000 Event Cash, 30일 연속 출석 시 5,000 Event Cash를 보너스로 지급합니다.

**친구 초대 보너스**: 친구를 초대하여 가입하면 초대한 사람과 초대받은 사람 모두에게 3,000 Event Cash를 지급합니다. 초대받은 친구가 첫 게임에 참여하면 추가 2,000 Event Cash를 지급합니다.

**리워드 프로그램**: 게임 참여 횟수나 충전 금액에 따라 포인트를 적립하고, 포인트를 Event Cash로 교환할 수 있습니다. 예: 100 포인트 = 1,000 Event Cash.

### 9.2 시즌 이벤트

특별한 기간에 한시적으로 이벤트를 진행합니다.

**여름 시즌 (6-8월)**: 모든 충전 시 15% 보너스 Event Cash 지급.

**겨울 시즌 (12-2월)**: 연말연시 기념으로 매일 추첨을 통해 50명에게 10,000 Event Cash 지급.

**명절 이벤트**: 설날, 추석 연휴에는 특별 보너스와 할인을 제공합니다.

**기념일 이벤트**: 앱 출시 1주년, 가입자 10만 명 달성 등 기념일에는 대규모 이벤트를 진행합니다. 예: 전체 사용자에게 5,000 Event Cash 지급.

### 9.3 VIP 프로그램

고액 사용자를 위한 VIP 프로그램을 운영합니다.

**VIP 등급**: 월 충전 금액이나 게임 참여 빈도에 따라 Bronze, Silver, Gold, Platinum 등급으로 구분합니다.

**VIP 혜택**:
- 충전 시 추가 보너스 (등급별 5-20%)
- 출금 수수료 면제 또는 할인
- 전용 고객 지원 채널
- 특별 게임 이벤트 초대
- 생일 축하 Event Cash 지급

**등급 유지**: VIP 등급은 3개월간 유지되며, 이후 활동이 없으면 등급이 하락합니다.

### 9.4 이벤트 규정

모든 이벤트는 다음 규정을 준수합니다.

**투명성**: 이벤트 조건, 기간, 혜택을 명확히 공지합니다.

**공정성**: 모든 사용자에게 동등한 기회를 제공하며, 차별하지 않습니다.

**변경 및 취소**: 부득이한 사유로 이벤트를 변경하거나 취소할 수 있으며, 이 경우 사전에 공지합니다.

**중복 혜택 제한**: 일부 이벤트는 중복 적용이 제한될 수 있습니다. 예: 첫 충전 보너스와 대량 충전 보너스는 중복 적용 안 됨.

**부정 참여 방지**: 다중 계정, 매크로, 기타 부정한 방법으로 이벤트에 참여하는 것은 금지되며, 발각 시 혜택이 회수되고 계정이 정지됩니다.

## 10. 고객 지원

### 10.1 Event Cash 관련 문의

Event Cash와 관련한 문의는 다음 채널을 통해 할 수 있습니다.

**인앱 채팅**: 앱 내에서 "고객센터" → "채팅 문의"를 선택하면 실시간 채팅으로 상담원과 대화할 수 있습니다. 운영 시간은 평일 오전 9시부터 오후 6시까지이며, 이외 시간에는 챗봇이 기본적인 질문에 답변합니다.

**이메일**: support@blockpick.com으로 이메일을 보내면 24시간 내에 답변을 받을 수 있습니다.

**전화**: 고객센터 전화번호는 1234-5678이며, 평일 오전 9시부터 오후 6시까지 운영됩니다.

**FAQ**: 앱 내 FAQ 섹션에서 자주 묻는 질문과 답변을 확인할 수 있습니다. "Event Cash 충전이 안 돼요", "출금은 얼마나 걸리나요?" 등 일반적인 질문에 대한 답변이 정리되어 있습니다.

### 10.2 자주 묻는 질문 (FAQ)

**Q: Event Cash 충전이 완료되었는데 잔액에 반영되지 않았어요.**
A: 일반적으로 충전은 즉시 반영됩니다. 1분 이상 지났는데도 반영되지 않으면 앱을 재시작해 보세요. 그래도 안 되면 거래 내역에서 충전 기록을 확인하고, 고객센터에 거래 ID와 함께 문의해 주세요.

**Q: 출금은 얼마나 걸리나요?**
A: 정상적인 경우 1시간 이내에 처리됩니다. 수동 검토가 필요한 경우 영업일 기준 1-2일이 소요될 수 있습니다. 최대 3일 내에는 반드시 처리됩니다.

**Q: 출금 수수료는 얼마인가요?**
A: 출금 금액의 5%이며, 최소 500원입니다. 예를 들어, 100,000 캐시를 출금하면 5,000원의 수수료가 차감되어 95,000원이 입금됩니다.

**Q: Event Cash를 다른 사람에게 양도할 수 있나요?**
A: 아니요, Event Cash는 본인만 사용할 수 있으며 양도, 선물, 판매가 불가능합니다.

**Q: Event Cash에 유효기간이 있나요?**
A: 아니요, Event Cash는 유효기간이 없습니다. 계정을 유지하는 한 영구적으로 보유할 수 있습니다.

**Q: 충전한 금액을 환불받을 수 있나요?**
A: 충전한 Event Cash는 출금을 통해 현금으로 전환할 수 있습니다. 단, 5%의 수수료가 부과됩니다. 직접적인 환불은 제공하지 않습니다.

**Q: 게임에 참여했는데 Event Cash가 차감되지 않았어요.**
A: 참가 확인 팝업에서 "확인"을 누르지 않았거나, 네트워크 오류로 참여가 완료되지 않았을 수 있습니다. 거래 내역과 내 참가 목록을 확인해 보세요. 참가가 기록되어 있지 않다면 다시 참여해야 합니다.

### 10.3 분쟁 해결

Event Cash와 관련한 분쟁은 다음과 같이 해결합니다.

**고객센터 문의**: 먼저 고객센터에 문의하여 문제를 설명합니다. 대부분의 문제는 고객센터에서 신속하게 해결됩니다.

**내부 조사**: 고객센터가 사안을 조사하고, 시스템 로그와 거래 기록을 분석합니다. 조사 결과는 사용자에게 투명하게 공유됩니다.

**보상**: 시스템 오류나 BlockPick의 실수로 인한 손실이 확인되면 즉시 보상합니다. 예를 들어, 충전이 완료되었으나 Event Cash가 지급되지 않았다면 즉시 지급하고, 불편에 대한 추가 보너스도 제공할 수 있습니다.

**외부 조정**: 내부적으로 해결되지 않는 분쟁은 금융감독원의 금융분쟁조정위원회나 한국소비자원의 소비자분쟁조정위원회에 조정을 신청할 수 있습니다.

**법적 절차**: 최후의 수단으로 법원에 소송을 제기할 수 있습니다. 이용약관에 분쟁 해결 절차와 관할 법원이 명시되어 있습니다.
