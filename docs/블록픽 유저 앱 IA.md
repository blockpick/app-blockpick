# 블록픽 유저 앱 IA

# 1. 하단 탭 최종 구성

## 최종 추천안

1. **홈**
2. **블록픽**
3. **참여내역**
4. **친구초대**
5. **마이**

---

# 2. 왜 이 구조가 적합한가

## 2-1. 홈

- 추천형 진입 화면
- 지금 참여할 만한 블록픽을 빠르게 보여줌
- 신규/인기/마감임박 이벤트 중심 노출

## 2-2. 블록픽

- 전체 블록픽 리스트 전용 탭
- 검색, 카테고리, 정렬, 필터의 중심 화면
- 유저가 여러 판을 둘러보고 참여 대상을 선택하는 핵심 공간

## 2-3. 참여내역

- 내가 참여한 블록픽 확인
- 당첨 여부 확인
- 추가 참여 가능 여부 확인
- 재참여 유도

## 2-4. 친구초대

- 블록픽의 핵심 확산 장치
- 초대 링크 발급, 공유, 실적 확인
- 추가 참여 보상과 직접 연결

## 2-5. 마이

- 계정/설정/고객센터/정책 관리
- 알림함, 알림 설정 포함

# 4. 하단 탭별 상세 IA

---

## 4-1. 홈 탭

### 목적

- 유저가 앱에 들어왔을 때 바로 참여할 만한 블록픽을 발견하게 함
- 추천/인기/신규/마감임박 중심으로 참여를 유도
- 운영 프로모션과 시즌성 이벤트 노출

### 구조

```
홈
├── 상단 영역
│   ├── 로고/서비스명
│   ├── 검색 진입
│   ├── 알림 벨 아이콘
│   └── 마이 바로가기
│
├── 메인 배너
│   ├── 프로모션 배너
│   ├── 추천 캠페인 배너
│   └── 시즌/이벤트 배너
│
├── 추천 블록픽
├── 진행 중 블록픽
├── 신규 오픈
├── 마감 임박
├── 친구 초대 인기 판
└── 블록픽 카드 클릭 → 블록픽 상세
```

### 주요 액션

- 블록픽 상세 진입
- 검색 이동
- 알림 확인
- 마이 이동

---

## 4-2. 블록픽 탭

### 목적

- 전체 블록픽 리스트를 탐색하는 메인 탭
- 유저가 원하는 이벤트를 직접 찾고 비교하게 함
- 검색/정렬/카테고리 필터의 중심 화면

### 구조

```
블록픽
├── 검색바
├── 카테고리 필터
│   ├── 전체
│   ├── 쇼핑
│   ├── 앱/서비스
│   ├── 쿠폰/리워드
│   ├── 오프라인 이벤트
│   └── 기타
│
├── 정렬 옵션
│   ├── 인기순
│   ├── 최신순
│   ├── 마감임박순
│   └── 참여 많은순
│
├── 필터
│   ├── 무료 참여 가능
│   ├── 진행중
│   ├── 신규
│   ├── 친구 초대 가능
│   ├── 광고 참여 가능
│   └── 미션 참여 가능
│
├── 블록픽 리스트
│   ├── 카드형 리스트
│   └── 검색/필터 결과 리스트
│
└── 블록픽 상세 진입
```

### 주요 액션

- 블록픽 검색
- 카테고리 선택
- 정렬 변경
- 필터 적용
- 블록픽 상세 진입

# 6. 화면 간 핵심 이동 흐름

## 6-1. 참여 중심 흐름

- 홈 → 블록픽 상세 → 블록 선택 → 참여 결과
- 블록픽 → 블록픽 상세 → 블록 선택 → 참여 결과

## 6-2. 재참여 중심 흐름

- 참여내역 → 참여 상세 → 친구초대 / 광고 / 미션 → 재참여
- 참여 결과 → 친구초대 / 광고 / 미션 → 재참여

## 6-3. 리퍼럴 중심 흐름

- 친구초대 → 링크 공유 → 초대 성공 → 참여권 획득 → 재참여

## 6-4. 당첨 확인 흐름

- 참여내역 → 당첨 상세
- 알림함 → 당첨 상세

# 7. MVP 기준 핵심 포인트

## 7-1. 블록픽 탭은 반드시 필요

- 전체 블록픽 리스트를 모아보는 메인 탐색 허브 역할
- 홈만으로는 충분하지 않음

## 7-2. 알림은 별도 탭 불필요

- 상단 벨 아이콘 + 마이 내부 알림함으로 충분
- MVP 하단 탭 자원을 더 중요한 목적지에 배치하는 게 유리

## 7-3. 친구초대는 별도 탭 유지

- 블록픽의 리퍼럴 구조가 핵심이기 때문
- 초대 실적과 보상 상태를 자주 확인하는 구조가 필요
- 추가 참여와 직접 연결되는 핵심 행동 탭

# 9. 한 줄 정의
