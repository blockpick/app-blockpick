# 블록픽 유저 앱 화면 구성서

## UI 요소 / CTA 중심 정리

---

# 1. 공통 UI 원칙

## 1-1. 핵심 원칙

- 유저가 **빠르게 참여**할 수 있어야 한다.
- 화면마다 **다음 행동 CTA가 명확**해야 한다.
- 당첨/미당첨 여부보다 **재참여 유도 흐름**이 자연스럽게 이어져야 한다.
- 친구초대 / 광고시청 / 미션수행은 모두 **추가 참여 획득 수단**으로 일관되게 보여야 한다.

## 1-2. 공통 UI 요소

- 상단 앱바
    - 뒤로가기
    - 화면명
    - 알림 벨 아이콘(필요 시)
- 카드형 블록픽 아이템
- 강조 배너 영역
- 상태 배지
    - 진행중
    - 마감임박
    - 당첨
    - 종료
- CTA 버튼
    - 주 CTA: 진한 강조
    - 보조 CTA: 외곽선/텍스트형
- 하단 고정 버튼 영역
- Empty 화면
- 로딩 화면
- 오류 안내 화면

## 1-3. 공통 CTA 문구 원칙

- 참여 시작: **지금 참여하기**
- 재참여: **한 번 더 참여하기**
- 친구초대: **친구 초대하고 기회 받기**
- 광고시청: **광고 보고 기회 받기**
- 미션수행: **미션하고 기회 받기**
- 당첨 확인: **당첨 정보 확인**
- 상세 이동: **자세히 보기**

# 2. 홈 탭 화면 구성

## 2-1. 홈 메인 화면

### 화면 목적

- 유저가 앱 진입 직후 참여할 만한 블록픽을 빠르게 발견하게 함
- 추천 / 신규 / 인기 / 마감임박 콘텐츠를 한 화면에서 노출
- 블록픽 상세로 자연스럽게 이동시킴

### 주요 UI 요소

- 상단 앱바
    - 좌측: 로고 또는 서비스명
    - 우측: 검색 아이콘, 알림 벨 아이콘
- 메인 프로모션 배너
- 추천 블록픽 섹션
- 진행 중 블록픽 섹션
- 신규 오픈 섹션
- 마감 임박 섹션
- 친구초대 인기 판 섹션
- 블록픽 카드 리스트

### 블록픽 카드 공통 구성

- 썸네일 이미지
- 블록픽 제목
- 파트너명
- 남은 기간 또는 종료 시간
- 혜택 요약
- 상태 배지
    - 진행중 / 신규 / 마감임박
- 참여 가능 여부
- CTA 버튼

### CTA

- **지금 참여하기**
- **자세히 보기**
- **전체 보기**
- 상단 검색 아이콘 → **검색**
- 알림 벨 → **알림함**

### 비고

- 홈은 “소비형 추천 화면”이라 스크롤형 구성이 적합
- 카드 클릭 전체 영역도 상세 진입 가능하게 하는 것이 좋음

# 3. 블록픽 탭 화면 구성

## 3-1. 블록픽 리스트 화면

### 화면 목적

- 전체 블록픽을 탐색하는 메인 허브
- 검색 / 필터 / 정렬을 통해 원하는 블록픽을 찾게 함

### 주요 UI 요소

- 상단 앱바
    - 화면명: 블록픽
    - 우측: 검색 아이콘 또는 검색창 내장형
- 검색바
    - 플레이스홀더: `브랜드명, 이벤트명으로 검색`
- 카테고리 칩
    - 전체
    - 쇼핑
    - 앱/서비스
    - 쿠폰/리워드
    - 오프라인 이벤트
    - 기타
- 정렬 드롭다운
    - 인기순
    - 최신순
    - 마감임박순
    - 참여 많은순
- 필터 버튼
- 블록픽 리스트 카드

### 필터 항목 예시

- 무료 참여 가능
- 진행중
- 친구초대 가능
- 광고 참여 가능
- 미션 참여 가능
- 글로벌 참여 가능
- 배송 국가 제한 있음

### 블록픽 카드 UI

- 썸네일
- 제목
- 파트너명
- 혜택 요약
- 마감 정보
- 참여 방식 태그
    - 무료 1회
    - 친구초대
    - 광고보상
    - 미션참여
- CTA

### CTA

- **지금 참여하기**
- **자세히 보기**
- **필터 적용**
- **초기화**
- **검색**
- **정렬 변경**

### 비고

- 이 화면은 “블록픽 전체 리스트 탭”이므로 검색/정렬/필터가 핵심
- 카드 하단에 “무료 참여 가능” 배지를 두면 전환에 유리

# 4. 블록픽 상세 화면 구성

## 4-1. 블록픽 상세 화면

### 화면 목적

- 유저가 참여 전 필요한 모든 정보를 확인
- 참여 진입 장벽을 낮춤
- `지금 참여하기`로 연결

### 주요 UI 요소

- 상단 앱바
    - 뒤로가기
    - 공유 아이콘
    - 알림 벨(선택)
- 대표 이미지
- 블록픽 제목
- 파트너명
- 상태 배지
    - 진행중 / 마감임박 / 종료
- 남은 시간
- 참여 혜택 요약 카드
- 참여 방법 안내
- 무료 참여 가능 여부
- 추가 참여 방법 영역
    - 친구초대
    - 광고시청
    - 미션수행
- 유의사항 아코디언
- 파트너 정보
- 글로벌 관련 안내
    - 참여 가능 국가
    - 배송 가능 국가(실물 보상 시)
- 하단 고정 CTA 영역

### CTA

- **지금 참여하기**
- **친구에게 공유하기**
- **참여 방법 보기**
- **유의사항 보기**

### 비고

- 하단 CTA는 스크롤 중에도 고정되는 게 좋음
- 블록픽 상세는 “정보 전달 + 참여 전환”이 핵심

# 5. 블록 선택 화면 구성

## 5-1. 블록 선택 화면

### 화면 목적

- 블록픽의 핵심 인터랙션 제공
- 현재 보유한 참여권으로 블록을 선택하게 함

### 주요 UI 요소

- 상단 앱바
    - 뒤로가기
    - 화면명
- 블록픽 제목 요약
- 참여 방식 표시 배지
    - 무료 참여
    - 친구초대 보상 참여
    - 광고 보상 참여
    - 미션 보상 참여
- 현재 보유 참여권 수
- 안내 문구
    - 블록을 선택해 참여하세요
- 그리드 보드
- 선택된 블록 상태 표시
- 선택 유의사항
- 하단 고정 버튼

### CTA

- **선택 완료**
- **다시 선택하기**
- **취소**
- 참여권 부족 시
    - **친구 초대하고 기회 받기**
    - **광고 보고 기회 받기**
    - **미션하고 기회 받기**

### 비고

- 선택 전/후 상태가 명확해야 함
- 실수 방지를 위해 최종 확정 1회는 필요

---

## 5-2. 선택 확인 바텀시트 / 팝업

### 화면 목적

- 선택 실수를 줄이고 확정 전 최종 확인

### 주요 UI 요소

- 선택한 블록 번호/위치
- 사용될 참여권 종류
- 주의 문구
- 확정 버튼

### CTA

- **이 블록으로 참여할게요**
- **다시 고를래요**

---

# 6. 참여 결과 화면 구성

## 6-1. 참여 결과 화면

### 화면 목적

- 결과를 직관적으로 보여주고
- 곧바로 다음 행동으로 이어지게 함

### 주요 UI 요소

- 결과 상태 일러스트/아이콘
- 결과 헤드라인
    - 당첨되었어요
    - 아쉽지만 다음 기회에
    - 참여가 완료되었어요
- 결과 설명 문구
- 보상/혜택 안내 카드
- 내 참여 내역 요약
- 추가 참여 가능 영역
    - 친구초대
    - 광고시청
    - 미션수행
- 하단 CTA 그룹

### 결과별 UI 분기

### 당첨

- 당첨 안내 강조
- 보상명
- 지급 방식
- 당첨 정보 확인 링크

### 미당첨

- 아쉬움 최소화 문구
- 추가 기회 획득 CTA 강조

### 참여 완료/추첨 대기

- 추첨 예정일/안내
- 내역 보기 CTA

### CTA

- **당첨 정보 확인**
- **내 참여 내역 보기**
- **친구 초대하고 한 번 더**
- **광고 보고 한 번 더**
- **미션하고 한 번 더**
- **다른 블록픽 보러가기**

### 비고

- 미당첨 시 이탈하지 않게 추가 행동 CTA 배치가 중요
- 결과 화면은 단순 종료 화면이 아니라 “재참여 유도 화면”이어야 함

# 16. 최종 정리

이 유저 앱 화면 구성서는 다음 흐름을 중심으로 설계된다.

## 핵심 흐름

- **탐색**
    - 홈 / 블록픽
- **참여**
    - 상세 / 블록 선택 / 결과
- **재참여**
    - 친구초대 / 광고 / 미션
- **확인**
    - 참여내역 / 당첨상세 / 알림함
- **관리**
    - 마이 / 설정 / 고객센터

## 최종 핵심 원칙

- 유저는 쉽게 블록픽을 찾을 수 있어야 한다.
- 참여는 짧고 직관적이어야 한다.
- 결과 후에는 반드시 다음 행동이 보여야 한다.
- 친구초대는 별도 탭으로 강하게 운영해야 한다.
- 알림은 하단 탭보다 보조 진입 구조가 적합하다.
