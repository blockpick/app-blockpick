# IA / 화면 구성 / 파트너 대시보드 메뉴 구조 / 요금제 상세안

# 1. 정리 기준

본 문서는 **1차 MVP 기준**으로 정리한다.

즉, 현재 범위는 다음에 집중한다.

- 파트너 리퍼럴 SaaS 구조
- 파트너의 블록픽 판 생성/운영
- 유저 무료 1회 참여
- 친구 초대 / 광고 시청 / 미션 수행을 통한 추가 참여
- 파트너 대시보드 기반 운영
- 구독형 요금제

---

# 2. 서비스 IA 개요

블록픽 1차 MVP의 IA는 크게 3개 영역으로 나뉜다.

1. **유저 영역**
2. **파트너 영역**
3. **운영자(Admin) 영역**

---

# 7. 화면 구성

## 7-1. 유저 화면 구성

---

## A. 유저 홈

### 목적

- 유저가 참여 가능한 블록픽을 빠르게 탐색하게 함
- 신규/인기/마감임박 이벤트를 노출
- 반복 방문을 유도

### 주요 UI 요소

- 상단 배너
- 추천 블록픽 카드
- 진행중인 이벤트 리스트
- 인기순 / 최신순 / 마감임박 탭
- 검색창
- 카테고리 필터
- 내 참여 내역 바로가기

### 핵심 액션

- 블록픽 상세 진입
- 검색
- 카테고리 탐색

---

## B. 블록픽 상세 화면

### 목적

- 이벤트 참여 전 필요한 모든 정보를 명확하게 전달
- 유저가 참여 여부를 쉽게 판단하게 함

### 주요 UI 요소

- 썸네일 / 파트너명
- 이벤트 제목
- 혜택/경품 요약
- 참여 기간
- 남은 시간
- 참여 방법 안내
- 무료 참여 가능 여부
- 추가 참여 획득 방법
- 유의사항
- CTA 버튼: 참여하기

### 핵심 액션

- 무료 참여 시작
- 공유하기
- 파트너 페이지 이동
- 친구 초대 안내 보기

---

## C. 블록 선택 화면

### 목적

- 블록픽의 핵심 인터랙션 제공
- 유저가 직접 칸을 선택하게 함

### 주요 UI 요소

- 그리드 보드
- 남은 참여권 표시
- 현재 참여 방식 표시
    - 무료 참여
    - 친구 초대 보상 참여
    - 광고 시청 보상 참여
- 참여 가이드
- 선택 완료 버튼

### 핵심 액션

- 블록 선택
- 선택 확정

---

## D. 참여 결과 화면

### 목적

- 결과를 직관적으로 보여주고 다음 행동을 유도
- 당첨/비당첨 여부와 추가 참여를 연결

### 주요 UI 요소

- 결과 상태
    - 당첨 / 미당첨 / 추첨 대상 등록
- 혜택 정보
- 다음 행동 CTA
    - 친구 초대하고 한 번 더
    - 광고 보고 한 번 더
    - 미션 수행하고 한 번 더
- 공유 버튼
- 내 참여 내역 보기

### 핵심 액션

- 친구 초대 진입
- 광고 시청
- 미션 보기
- 종료

---

## E. 친구 초대 화면

### 목적

- 리퍼럴 전파 극대화

### 주요 UI 요소

- 내 초대 코드 / 링크
- 복사 버튼
- 카카오톡 / 문자 / 링크 공유 버튼
- 보상 조건 안내
- 초대 현황
    - 클릭 수
    - 참여 완료 수
    - 보상 지급 수

### 핵심 액션

- 링크 공유
- 공유 앱 선택
- 내 초대 실적 확인

---

## F. 광고 시청 보상 화면

### 목적

- 광고 시청 후 추가 참여권 지급

### 주요 UI 요소

- 광고 시청 가능 횟수
- 보상 내용
- 광고 시청하기 버튼
- 유의사항

### 핵심 액션

- 광고 시청
- 보상 수령
- 다시 참여

---

## G. 내 활동 화면

### 목적

- 유저가 자신의 활동을 확인하고 재참여를 유도

### 탭 구성

- 내 참여 내역
- 내 당첨 내역
- 내 초대 내역
- 내 보상/참여권

### 핵심 액션

- 재참여 가능한 판 바로가기
- 당첨 정보 확인
- 초대 현황 확인

# 8. 화면 구성

## 8-2. 파트너 화면 구성

---

## A. 파트너 로그인 / 온보딩 화면

- 파트너가 빠르게 가입하고 구독 시작하도록 유도

- 서비스 소개
- 가입 폼
- 일반 가입 가능, 사업자/브랜드 정보 입력 선택
- 플랜 선택
- 결제 등록
- 시작하기 버튼

### 핵심 액션

- 회원가입
- 플랜 선택
- 결제수단 등록(스트라이프, 웹 결제)

---

## B. 파트너 대시보드 홈

### 목적

- 파트너가 현재 운영 성과를 한눈에 파악

### 주요 UI 요소

- 총 방문 수
- 총 참여 수
- 무료→추가 참여 전환율
- 친구 초대 성과
- 광고 시청 수
- 진행중 블록픽 수
- 최근 알림
- 빠른 액션
    - 새 블록픽 만들기
    - 당첨자 확인
    - 플랜 업그레이드

### 핵심 액션

- 블록픽 생성
- 성과 상세 진입
- 구독 변경

---

## C. 블록픽 리스트 화면

### 목적

### 필터

- 진행중

- 종료됨
- 임시저장

    - 복제

## D. 새 블록픽 생성 화면

### 단계형 Wizard 추천

### Step 1. 기본 정보

- 캠페인명
- 대표 이미지
- 설명
- 파트너 표기명
- 공개 방식

### Step 2. 그리드/참여 설정

- 그리드 크기
- 무료 참여 수
- 1인 최대 참여 수
- 추가 참여 허용 방식
    - 친구 초대
    - 광고 시청
    - 미션 수행

### Step 3. 보상 설정

- 경품명
- 수량
- 유형
- 지급 방식
- 유효기간
- 유의사항

### Step 4. 공유/리퍼럴 설정

- 기본 공유 문구

- 초대 보상 조건
- 초대 성공 인정 기준

### Step 5. 검토 및 발행

- 요약 확인
- 임시저장
- 예약 발행

# 20. 최종 추천 구조

## IA 관점

- 유저는 **참여와 재참여가 쉽도록**
- 파트너는 **생성과 운영이 빠르도록**
- 운영자는 **승인과 제재가 가능하도록**

## 제품 관점

1차 MVP의 핵심은

**“파트너가 돈 내고 반복적으로 블록픽을 운영하게 만드는 것”**이야.

그래서 실제 우선순위는 아래 순서가 좋아.

1. 블록픽 생성이 쉬워야 함
2. 유저 참여가 쉬워야 함
3. 친구 초대/광고 보상이 자연스럽게 이어져야 함
4. 파트너가 성과를 눈으로 확인할 수 있어야 함
5. 플랜 업그레이드 이유가 분명해야 함

# 21. 한 줄 요약

**1차 MVP의 IA와 화면 구조는 “유저의 쉬운 참여”와 “파트너의 쉬운 캠페인 운영”에 집중하고, 요금제는 블록픽 생성 수·참여 수·브랜딩·분석 기능을 기준으로 단계적으로 업셀되도록 설계한다.**
