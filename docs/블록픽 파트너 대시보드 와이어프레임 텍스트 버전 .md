**파트너 대시보드 와이어프레임은 `홈 → 블록픽 생성/상세 운영 → 참여자/당첨자 관리 → 성과 분석 → 구독 관리` 흐름을 중심으로, 파트너 실무자가 반복적으로 캠페인을 운영하고 확장하도록 설계한다.**
