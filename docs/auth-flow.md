# 프론트엔드 인증 프로세스 플로우

## 개요
로그인 / 회원가입 프로세스 (비로그인 포함)

---

## 1. 앱 실행 플로우

```
앱 실행 → 스플래시 화면 → 자동로그인 유무 확인
                              │
                    ┌─────────┴─────────┐
                    │                   │
               [설정됨]              [비설정]
                    │                   │
                    ▼                   ▼
          서버에서 자동로그인 체크    로그인 화면으로 이동
                    │
            ┌───────┴───────┐
            │               │
         [성공]           [실패]
            │               │
            ▼               ▼
         홈 화면      로그인 화면으로 이동
```

### 상세 설명
1. **앱 실행**: 스플래시 화면 표시
2. **자동로그인 유무 확인**: 로컬 저장소에서 자동로그인 설정 확인
3. **자동로그인 설정됨**: 서버에서 토큰 유효성 검증
   - 성공 시: 홈 화면으로 이동
   - 실패 시: 로그인 화면으로 이동
4. **자동로그인 비설정**: 로그인 화면으로 이동

---

## 2. 로그인 플로우

```
로그인 화면 → 로그인 유형 선택
                  │
        ┌─────────┴─────────┐
        │                   │
   SNS 계정 로그인       이메일 로그인
   (구글/애플)
        │                   │
        └─────────┬─────────┘
                  │
                  ▼
           회원가입 여부 확인
                  │
        ┌─────────┴─────────┐
        │                   │
      [회원]              [비회원]
        │                   │
        ▼                   ▼
     홈 화면          회원가입 유도 dialog 노출
                            │
                            ▼
                       회원가입 화면
```

### 상세 설명
1. **로그인 유형 선택**
   - SNS 계정 로그인 (구글/애플)
   - 이메일 로그인

2. **SNS 계정 로그인**
   - OAuth 인증 진행
   - 서버에서 회원가입 여부 확인

3. **이메일 로그인**
   - 이메일/비밀번호 입력
   - 서버에서 회원가입 여부 확인

4. **회원가입 여부에 따른 분기**
   - 회원: 자동로그인 설정 후 홈 화면 이동
   - 비회원: 회원가입 유도 dialog 노출

---

## 3. 회원가입 플로우

### 3.1 SNS 계정 가입 (구글/애플)

```
회원가입 → SNS 계정 가입 선택 → 계정 확인
                                   │
                                   ▼
                           휴대폰 번호 인증
                                   │
                           ┌───────┴───────┐
                           │               │
                        [성공]           [실패]
                           │               │
                           ▼               ▼
                    계정 중복 유무 확인   재시도
                           │
                   ┌───────┴───────┐
                   │               │
                [신규]           [중복]
                   │               │
                   ▼               ▼
              필수 약관 동의   로그인 유도 dialog
                   │           "이미 가입된 계정입니다"
                   ▼           "이메일 주소"
              필수 약관 동의    "로그인 방법"
                   │
                   ▼
              회원 DB 저장
                   │
                   ▼
              가입 완료 → 홈 화면
```

### 3.2 이메일 가입

```
회원가입 → 이메일 가입 선택 → 계정 확인
                                  │
                                  ▼
                           휴대폰 번호 인증
                                  │
                          ┌───────┴───────┐
                          │               │
                       [성공]           [실패]
                          │               │
                          ▼               ▼
                   계정 중복 유무 확인   재시도
                          │
                  ┌───────┴───────┐
                  │               │
               [신규]           [중복]
                  │               │
                  ▼               ▼
             필수 약관 동의   로그인 유도 dialog
                  │
                  ▼
             이메일 인증
                  │
          ┌───────┴───────┐
          │               │
       [성공]           [실패]
          │               │
          ▼               ▼
   인증 코드 생성 및 DB 저장  재시도
          │
          ▼
     인증 이메일 발송
          │
          ▼
   앱 인증코드 6자리 입력
          │
          ▼
     코드 유효성 검증
          │
    ┌─────┴─────┐
    │           │
 [성공]       [실패]
    │           │
    ▼           ▼
비밀번호 설정  코드 재발송 여부
    │               │
    ▼           ┌───┴───┐
회원 DB 저장    │       │
    │        [허용]   [거부]
    ▼           │       │
 가입 완료      ▼       ▼
    │       재발송   회원가입 취소
    ▼
 홈 화면
```

---

## 4. 이메일 인증코드 규칙

| 항목 | 내용 |
|------|------|
| 코드 형식 | 6자리 숫자 조합 |
| 유효 케이스 | 회원가입, 비밀번호 변경, 회원탈퇴 |

---

## 5. 비밀번호 규칙

| 항목 | 내용 |
|------|------|
| 최소 길이 | 8자 이상 |
| 조합 규칙 | 영문/숫자/특수문자 3가지 이상 조합 |
| 대소문자 | 구분함 |

## 6. 로그인 성공 후 처리

```
로그인 성공 → 로그인 모드 (dialog 노출)
                   │
                   ▼
        ┌─────────────────────┐
        │ 이미 가입된 계정입니다 │
        │ - 이메일 주소        │
        │ - 로그인 방법        │
        └─────────────────────┘
                   │
                   ▼
              홈 화면 이동
```

---

## 7. 화면별 주요 기능 요약

### 스플래시 화면
- 앱 로고/브랜딩 표시
- 자동로그인 체크 진행

### 로그인 화면
- SNS 로그인 버튼 (구글/애플)
- 이메일 로그인 버튼
- 회원가입 링크

### 회원가입 화면
- SNS 계정 가입 (구글/애플)
- 이메일 가입
- 휴대폰 번호 인증
- 필수 약관 동의
- 이메일 인증 (이메일 가입 시)
- 비밀번호 설정 (이메일 가입 시)

### 홈 화면
- 가입 환영 메시지 클릭 시 자동로그인으로 홈 화면 이동

---

## 8. 에러 처리 플로우

### 휴대폰 인증 실패
- 재시도 안내
- 인증번호 재발송 옵션

### 이메일 인증 실패
- 코드 재발송 여부 확인
- 최대 재발송 횟수 제한 (확인 필요)
- 재발송 거부 시 회원가입 취소

### 계정 중복
- 로그인 유도 dialog 표시
- 기존 가입 정보 (이메일, 로그인 방법) 안내
