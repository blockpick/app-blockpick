## §1 빈 상태(Empty State) 5종 표준화 점검

### 개요
블록픽 유저 앱의 5개 주요 빈 상태 화면을 IA 표준(§4-4 친구초대 탭 기준)과 비교 검증하고, 현재 구현 상태를 파악하여 개선 방향을 제시합니다.

## §2 친구초대 가이드 콘텐츠 초안

### 2-1 초대 방법 (3단계 + 보상)

#### 단계 1: 초대 링크 발급 및 공유
**가이드 텍스트**:
```
내 초대 코드는 자동으로 발급되어 있습니다.
[초대 링크 복사] 또는 [공유하기]를 통해 친구들에게 보낼 수 있습니다.

링크 공유 방법:
• 카카오톡, 문자 등 메신저 앱
• SNS (인스타그램, 페이스북 등)
• 이메일
```

#### 단계 2: 친구 참여 완료
**가이드 텍스트**:
```
초대받은 친구가:
1. 링크를 통해 앱에 회원가입
2. 첫 번째 블록픽에 참여 완료

위 두 조건을 모두 완료할 때 초대가 성공으로 인정됩니다.
```

#### 단계 3: 보상 지급
**가이드 텍스트**:
```
친구의 첫 참여가 완료되면, 24시간 이내에:
• 초대자: 추가 참여권 1개 획득
• 친구: 추가 참여권 1개 획득

보상은 "내 참여내역" → "추가 참여" 섹션에서 사용 가능합니다.
```

---

### 2-2 초대 가이드 전문(마크다운)

#### 제목
```markdown
# 블록픽 친구초대 가이드

친구를 초대하고 추가 참여 기회를 얻어보세요!
```

#### 본문
```markdown
## 초대 방법

### 1단계: 초대 링크 공유하기
- "친구초대" 탭에서 **내 초대 코드** 확인
- **[링크 복사]** 또는 **[공유하기]** 클릭
- 친구에게 링크 전송

### 2단계: 친구가 앱 가입 및 참여
- 친구가 초대 링크를 통해 가입
- 친구가 첫 번째 블록픽에 참여 완료

### 3단계: 보상 획득
- 친구의 첫 참여 완료 후 24시간 이내 보상 지급
- 추가 참여권 1개 자동 적립

## 초대 성공 조건

✓ 친구가 정상적인 계정으로 회원가입  
✓ 친구가 첫 번째 블록픽에 참여 완료  
✓ 초대자와 친구의 계정이 서로 다른 기기/IP 주소 사용

> 같은 기기에서 여러 계정을 만들거나 비정상적인 활동이 감지된 경우 
> 초대가 무효 처리될 수 있습니다.

## 보상 현황 확인

1. "친구초대" 탭 상단의 **내 초대 요약** 카드에서 한눈에 확인:
   - 총 초대 수
   - 성공한 초대 수
   - 획득한 추가 참여권 수

2. **초대 실적** 목록에서 각 친구의 상태 확인:
   - 초대 일시
   - 친구 가입 상태
   - 첫 참여 완료 여부
   - 보상 지급 상태
```

## §3 친구초대 FAQ 초안

### FAQ 목록 (7개 항목)

```markdown
# 친구초대 자주 묻는 질문(FAQ)

## Q1. 친구가 가입했는데 보상이 안 와요.
**A.** 초대 보상은 친구가 **첫 번째 블록픽에 참여를 완료**해야 지급됩니다.
- 친구가 회원가입만 하면 보상이 지급되지 않습니다.
- 친구에게 첫 참여를 완료하도록 안내해주세요.
- 첫 참여 후 24시간 이내에 추가 참여권이 자동 적립됩니다.

## Q2. 초대 링크가 작동하지 않습니다.
**A.** 다음을 확인해주세요:
- 링크가 완전히 복사되었는지 확인
- 친구의 기기에서 브라우저나 카톡을 통해 직접 클릭
- 이미 블록픽 앱이 설치되어 있다면 앱을 먼저 삭제 후 링크 클릭
- 문제가 계속되면 고객센터로 문의해주세요.

## Q3. 같은 가족/친구 여럿을 초대할 수 있나요?
**A.** 네, 많은 친구를 초대할 수 있습니다.
- 초대 인원의 제한은 없습니다.
- 다만 각 친구는 **각각 서로 다른 기기와 IP 주소**를 사용해야 합니다.
- 한 기기에서 여러 계정을 만들어 초대하는 것은 어뷰징으로 적발될 수 있습니다.

## Q4. 초대 실적은 언제까지 조회할 수 있나요?
**A.** 초대 실적은 **영구 조회 가능**합니다.
- "초대 실적" 목록에서 모든 초대 기록 확인 가능
- 기간별 필터 제공: 최근 7일, 최근 30일, 전체

## Q5. 친구가 다시 참여하면 또 보상을 받나요?
**A.** 아니요, 각 친구당 **처음 한 번만** 보상을 받습니다.
- 같은 친구가 여러 번 참여해도 처음 참여 완료 시점에만 보상 지급
- 다른 친구를 새로 초대하면 그 친구마다 보상 획득 가능

## Q6. 초대한 친구가 탈퇴하면 어떻게 되나요?
**A.** 초대 보상은 **친구가 탈퇴 후에도 유지**됩니다.
- 이미 지급된 추가 참여권은 계속 사용 가능
- 친구가 다시 가입하더라도 중복 보상은 제공되지 않습니다.

## Q7. 초대 링크를 여러 번 보낼 수 있나요?
**A.** 네, 같은 링크를 여러 친구에게 보낼 수 있습니다.
- 링크 개수 제한이 없습니다.
- 각 친구는 같은 초대 코드로 가입하더라도 개별 계정으로 인정됩니다.
```

## §4 어뷰징 방지 안내

### 4-1 어뷰징 정책 (표준 안내문)

```markdown
# 초대 보상 어뷰징 방지 안내

블록픽은 공정한 초대 시스템을 위해 다음과 같은 어뷰징을 적발합니다.

## 금지 행위

### 1. 다계정 생성 및 자가 초대
❌ 같은 기기에서 여러 계정을 만들어 서로 초대
❌ 같은 전화번호/이메일로 여러 계정 생성 후 초대
❌ 가족 계정이라는 명목으로 한 기기에서 불법 생성

**결과**: 모든 어뷰징 계정 정지 및 보상 무효 처리

### 2. IP 주소 조작
❌ VPN, 프록시 등을 이용한 동일 IP 초대
❌ 같은 Wi-Fi 네트워크에서 의도적 다계정 생성

**결과**: 어뷰징 계정 적발 시 경고 후 정지

### 3. 자동화 도구 사용
❌ 봇, 매크로, 자동 초대 프로그램 사용
❌ 초대 링크를 스팸 채널에 대량 배포

**결과**: 계정 영구 정지

## 정상적인 초대

✓ 서로 다른 기기에서 각각 가입
✓ 서로 다른 IP 주소 사용 (다른 집, 학교, 회사 등)
✓ 실제 친구/가족에게만 공유
✓ 친구가 자발적으로 앱 설치 및 참여

## 의심 사항 신고

어뷰징을 목격했다면 고객센터로 신고해주세요.
- 성명, 이메일, 신고 내용 포함
- 블록픽이 직접 조사하여 적절한 조치 실시
```

## §5 초대 보상 조건 안내

### 5-1 보상 획득 조건 (상세)

```markdown
# 초대 보상 조건 안내

## 보상 획득 조건 (초대자 기준)

### 필수 조건 (모두 충족해야 함)
1. **초대 링크 공유**: 나의 초대 코드를 친구에게 전송
2. **친구 회원가입**: 초대받은 친구가 블록픽 앱에 회원가입 완료
3. **친구 첫 참여**: 친구가 첫 번째 블록픽에 참여 완료
4. **정상 계정**: 초대자와 친구 모두 비정상 활동 없음

### 보상 미지급 사유
❌ 친구가 회원가입만 하고 참여하지 않음 → 보상 없음
❌ 같은 기기에서 초대자와 친구 계정이 생성됨 → 무효 처리
❌ 초대 링크를 통하지 않고 직접 가입 → 인정 불가
❌ 어뷰징으로 적발됨 → 보상 몰수

## 보상 내용

### 초대자 보상
- **추가 참여권 1개** 획득
- 사용 기간: 제한 없음 (영구)
- 사용처: "참여내역" → "추가 참여" 섹션

### 친구 보상
- **환영 보너스 추가 참여권 1개** 획득
- 초대 보상과 별도로 신규 가입자에게 자동 지급

## 보상 지급 일정

| 시점 | 상태 | 보상 |
|------|------|------|
| 친구 가입 완료 | 링크 추적 대기 | 없음 |
| 친구 첫 참여 완료 | 보상 지급 대기 | 없음 |
| 친구 참여 후 24시간 이내 | **보상 지급 완료** | **추가 참여권 1개** |
```
