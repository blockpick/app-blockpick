**운영자(Admin) 와이어프레임은 `홈 → 파트너 승인/관리 → 블록픽 검수/통제 → 신고·제재 → 과금·정책 운영 → 감사 로그` 흐름을 중심으로, 플랫폼 전체를 안정적으로 운영하고 통제하도록 설계한다.**
