# 블록픽 운영자(Admin) IA

# 1. IA 설계 기준

## 1-1. 운영자(Admin) 대시보드의 핵심 목적

운영자 대시보드는 아래 6가지를 빠르게 처리할 수 있어야 한다.

1. **파트너 승인 및 상태 관리**
2. **블록픽 검수 및 모니터링**
3. **신고 / 제재 / 강제 중지 처리**
4. **구독 / 과금 / 사용량 관리**
5. **광고 / 공통 정책 / 약관 관리**
6. **플랫폼 전체 KPI 및 이상 징후 모니터링**

## 1-2. 핵심 설계 원칙

- 운영자 메뉴는 **전체 현황 → 파트너 관리 → 블록픽 관리 → 정책/과금 관리** 흐름으로 간다.
- 실무상 가장 자주 쓰는 것은 **승인 대기 / 신고됨 / 이상 징후 / 결제 이슈**다.
- Admin은 “캠페인 생성”이 아니라 **검수와 통제**가 중심이다.
- 파트너 대시보드보다 더 강한 **필터 / 상태관리 / 로그 조회** 기능이 필요하다.

# 3. 운영자(Admin) 기본 레이아웃

## 3-1. 기본 구조

운영자(Admin) 대시보드는 파트너 대시보드와 유사한 웹 콘솔 구조를 사용하되, 더 강한 관리 기능을 가진다.

### 레이아웃 구성

- **좌측 사이드바**
    - 주요 관리 메뉴
- **상단 바**
    - 관리자 역할/조직
    - 통합 검색
    - 긴급 알림
    - 계정 메뉴
- **메인 콘텐츠 영역**
    - 대시보드 KPI / 테이블 / 상태 변경 패널 / 로그
- **우측 보조 영역(선택)**
    - 긴급 이슈 / 미처리 건수 / 최근 제재

# 5. 메뉴별 목적 정의

---

## 5-1. 홈

### 목적

- 플랫폼 전체 상태를 한눈에 보여주는 요약 화면
- 운영자가 오늘 처리해야 할 우선순위를 확인

### 핵심 정보

- 전체 파트너 수
- 유료 구독 수
- 전체 블록픽 수
- 진행중 블록픽 수
- 신고 처리 대기 수
- 승인 대기 파트너 수
- 결제 실패 건수
- 긴급 알림 / 이상 징후

---

## 5-2. 파트너 관리

### 목적

- 파트너 승인, 상태 변경, 제재 관리
- 파트너별 운영 이력과 위험도 확인

### 하위 메뉴 설명

### 전체 파트너

- 전체 파트너 목록
- 상태, 플랜, 국가, 최근 활동 확인

### 승인 대기

- 신규 가입 파트너 검토
- 사업자/브랜드/업종 확인
- 승인 / 반려

### 운영 중

- 현재 정상 운영 중인 파트너
- 성과 / 이슈 / 과금 상태 확인

### 정지 / 제재

- 이용 제한 또는 제재 이력 보유 파트너
- 정지 사유 / 해제 상태 관리

---

## 5-3. 블록픽 관리

### 목적

- 플랫폼 전체 블록픽 검수 및 모니터링
- 신고 대응 및 강제 중지 처리

### 하위 메뉴 설명

### 전체 블록픽

- 전체 캠페인 리스트
- 상태, 파트너, 국가, 기간, 참여 수 확인

### 검수 대기

- 발행 전 또는 검수 필요 상태의 블록픽
- 승인 / 반려 / 수정 요청

### 진행중

- 실시간 운영 중인 블록픽
- 이상 징후 / 신고 / 급증 트래픽 확인

### 종료됨

- 종료된 블록픽 이력 확인

### 신고됨

- 신고가 접수된 블록픽
- 신고 사유와 처리 상태 확인

### 강제 중지 이력

- 운영자가 수동으로 중지한 블록픽 이력

---

## 5-4. 신고 / 제재

### 목적

- 유저 신고 또는 내부 탐지 결과를 처리
- 파트너 / 블록픽 / 보상 구조에 대한 제재 관리

### 하위 메뉴 설명

### 신고 목록

- 전체 신고 건 통합 조회

### 처리 대기

- 아직 조치되지 않은 신고

### 처리 완료

- 완료된 신고와 결과 확인

### 제재 이력

- 제재 대상, 사유, 기간, 해제 여부 기록

---

## 5-5. 과금 / 구독 관리

### 목적

- 파트너 결제 상태, 사용량, 플랜 관리
- 결제 실패, 연체, 수동 조정 대응

### 하위 메뉴 설명

### 전체 플랜 현황

- 플랜별 파트너 수
- 업그레이드/다운그레이드 흐름

### 결제 상태

- 정상 결제 / 실패 / 유예 / 해지

### 결제 실패 / 연체

- 미납 상태 파트너 관리

### 사용량 현황

- 참여 수 / 블록픽 수 / 팀 수 사용량 모니터링

### 수동 조정 이력

- 운영자가 수동으로 변경한 과금/플랜 이력

---

## 5-6. 광고 / 보상 정책

### 목적

- 플랫폼 공통 정책 관리
- 광고 보상, 미션 정책, 보상 지급 제한 등 기준 설정

### 하위 메뉴 설명

### 공통 광고 정책

- 광고 시청 가능 여부
- 기본 광고 정책값

### 광고 제한 정책

- 일일 제한 / 판당 제한 / 국가별 제한

### 공통 미션 정책

- 기본 미션 유형, 허용 범위

### 기본 보상 정책

- 기본 보상 상한, 주의 문구

---

## 5-7. 콘텐츠 / 정책

### 목적

- 유저/파트너 공통으로 노출되는 운영 콘텐츠 관리

### 하위 메뉴 설명

### 공지사항

- 서비스 공지 노출 관리

### FAQ

- 유저 / 파트너 FAQ 관리

### 약관

- 이용약관, 개인정보처리방침 등

### 운영 정책

- 블록픽 운영 기준, 제한 업종, 제재 기준

### 배너 관리

- 홈 배너, 운영 공지 배너, 프로모션 배너

---

## 5-8. 분석

### 목적

- 플랫폼 전체 관점의 성과 및 위험 신호 확인

### 하위 메뉴 설명

### 플랫폼 전체 성과

- 전체 방문, 참여, 유료 전환, 리퍼럴 성과

### 파트너별 성과

- 파트너별 운영 효율과 위험도 비교

### 블록픽별 성과

- 캠페인 단위 비교

### 국가별 현황

- 글로벌 운영 국가별 참여/보상 현황

### 이상 징후 분석

- 비정상 참여 급증, 광고 악용, 초대 어뷰징 탐지

---

## 5-9. 로그 / 감사

### 목적

- 운영 추적성과 내부 통제 확보

### 하위 메뉴 설명

### 관리자 활동 로그

- 누가 어떤 관리 액션을 했는지 기록

### 파트너 주요 변경 로그

- 파트너가 설정을 크게 바꾼 이력

### 블록픽 상태 변경 로그

- 발행, 반려, 강제 중지, 종료 이력

### 과금 변경 로그

- 플랜 변경, 수동 조정, 예외 승인

---

## 5-10. 설정

### 목적

- 관리자 계정, 권한, 시스템 기본값 관리

### 하위 메뉴 설명

### 관리자 계정 관리

- 운영자 계정 추가/비활성화

### 권한 관리

- 슈퍼관리자 / 운영자 / CS / 재무 역할 분리

### 알림 설정

- 긴급 이슈, 결제 실패, 신고 접수 알림

### 시스템 설정

- 기본 시간대, 기본 국가, 운영 플래그 등

# 6. 운영자(Admin) 상세 화면 IA

운영자도 특정 파트너나 특정 블록픽에 들어가면 상세 화면 탭 구조가 있으면 좋다.

---

## 6-1. 파트너 상세 내부 탭 구조

```
파트너 상세
├── 개요
├── 계정 정보
├── 블록픽
├── 과금 / 플랜
├── 신고 / 제재 이력
└── 로그
```

### 탭별 설명

### 개요

- 파트너 상태, 플랜, 최근 성과, 위험 신호

### 계정 정보

- 사업자 정보, 국가, CS 정보, 승인 상태

### 블록픽

- 해당 파트너가 만든 블록픽 목록

### 과금 / 플랜

- 결제 상태, 사용량, 변경 이력

### 신고 / 제재 이력

- 해당 파트너 관련 신고, 제재 기록

### 로그

- 주요 설정 변경 및 운영 기록

---

## 6-2. 블록픽 상세 내부 탭 구조

```
블록픽 상세
├── 개요
├── 설정
├── 참여 현황
├── 당첨자 현황
├── 신고 / 제재
├── 로그
└── 강제 조치
```

### 탭별 설명

### 개요

- 상태, 파트너, 기간, KPI, 리스크 알림

### 설정

- 제목, 보상, 국가, 노출 상태, 검수 상태

### 참여 현황

- 참여 급증, 국가별 참여, 참여 패턴 확인

### 당첨자 현황

- 보상 유형, 배송 국가, 입력 정보 누락 확인

### 신고 / 제재

- 신고 목록, 처리 결과, 제재 여부

### 로그

- 변경 기록, 상태 변화 기록

### 강제 조치

- 강제 중지, 노출 제한, 수정 요청, 재심 승인

홈 → 승인 대기 → 파트너 상세 → 승인 / 반려

## 8-2. 블록픽 검수 흐름

홈 → 검수 대기 → 블록픽 상세 → 승인 / 수정 요청 / 반려

## 8-3. 신고 처리 흐름

홈 → 처리 대기 → 신고 상세 → 블록픽/파트너 확인 → 제재 / 보류 / 종료

## 8-4. 과금 이슈 처리 흐름

홈 → 결제 실패 / 연체 → 파트너 상세 → 유예 / 정지 / 수동 조정

## 8-5. 이상 징후 대응 흐름

홈 → 이상 징후 알림 → 블록픽 상세 / 파트너 상세 → 강제 조치

# 9. 운영자(Admin) IA 한 줄 정의

**운영자(Admin) IA는 `홈 / 파트너 관리 / 블록픽 관리 / 신고·제재 / 과금·구독 / 광고·보상 정책 / 콘텐츠·정책 / 분석 / 로그·감사 / 설정` 구조를 기본으로 하며, 플랫폼 전체의 승인·검수·제재·과금·정책 운영을 담당하도록 설계한다.**
