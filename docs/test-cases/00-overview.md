# 블록픽 유저 앱 — TC 개요 및 시나리오 트리

> 작성 기준일: 2026-05-07  
> 대상 버전: MVP v1.0  
> 앱: app-blockpick (Flutter)

---

## 1. 시나리오 트리

```
블록픽 유저 앱 TC
├── 01. 인증 (Auth)
│   ├── 회원가입 (이메일)
│   ├── 소셜 로그인 (카카오/애플)
│   ├── 휴대폰 인증
│   └── 비밀번호 찾기
│
├── 02. 블록픽 탐색 (Discovery)
│   ├── 홈 탭 진입 및 섹션 노출
│   ├── 블록픽 탭 리스트
│   ├── 검색
│   ├── 카테고리 필터
│   ├── 정렬
│   └── 상세 진입
│
├── 03. 참여 흐름 (Entry Flow)
│   ├── 블록픽 상세
│   ├── 블록 선택 (무료 1회)
│   ├── 추가 참여 (초대/광고/미션)
│   └── 결과 분기 (당첨 / 미당첨 / 대기)
│
├── 04. 포인트 & 리워드 (Points)
│   ├── 출석체크
│   ├── 미니게임
│   ├── 광고 시청
│   └── 포인트 잔액 확인
│
├── 05. 친구초대 (Referral)
│   ├── 초대 링크 발급
│   ├── 공유
│   └── 보상 확인
│
├── 06. 미션 (Mission)
│   ├── 미션 목록
│   ├── 외부 링크 연동
│   └── 완료 처리
│
├── 07. 당첨 내역 (Winning)
│   ├── 당첨 확인
│   ├── 배송지 입력
│   └── 고객 문의
│
├── 08. 알림 (Notification)
│   ├── 알림함
│   ├── 알림 설정
│   └── 딥링크 진입
│
├── 09. 빈 상태 & 오류 (Empty & Error)
│   ├── 빈 상태 5종
│   ├── 네트워크 오류
│   └── 권한 거부
│
└── 10. Cross-track 시나리오
    ├── 파트너 캠페인 생성
    ├── Admin 검수
    ├── 유저 참여
    ├── 당첨 처리
    └── 배송 완료
```

## 3. 우선순위 정의

| 등급 | 정의 | 예시 |
|------|------|------|
| P0 | 서비스 불가 수준의 장애 | 로그인 불가, 참여 불가, 앱 크래시 |
| P1 | 핵심 사용자 시나리오 이상 | 검색 오동작, 포인트 미적립, 당첨 화면 오류 |
| P2 | UX 저하, 비핵심 기능 이상 | 빈 상태 미노출, 정렬 순서 이상, 딥링크 일부 오동작 |

---

## 4. 자동화 전략

| 레이어 | 도구 | 대상 |
|--------|------|------|
| 단위 테스트 | Flutter `test` | Provider, 비즈니스 로직 |
| 위젯 테스트 | Flutter `flutter_test` | 개별 위젯 렌더링 |
| E2E 통합 테스트 | Patrol ^3.x | 핵심 5개 흐름 (auth / discovery / entry / points / referral) |
| Cross-track | 수동 (시나리오 문서) | 파트너 → Admin → 유저 전체 흐름 |
