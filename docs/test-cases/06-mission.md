# TC-06: 미션 (Mission)

> 대상 화면: 미션 목록 / 미션 상세 / 외부 링크 / 완료 처리

---

## TC-006-001 | 미션 목록 진입 및 노출

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 로그인 완료
- 서버에 활성화된 미션 1개 이상 존재

### Steps
1. 참여 결과 화면 → "미션하고 기회 받기" 탭
   또는 참여내역 → 추가 참여 가능 목록 → 미션 수행 탭

### Expected
- 미션 목록 화면 노출
- 미션 카드: 미션명, 완료 조건, 보상 (포인트 또는 참여권), 완료 여부 배지
- 완료된 미션은 비활성화 또는 "완료" 배지 표시

---

## TC-006-002 | 미션 — 외부 링크 이동 (앱 설치 유도형)

- **우선순위**: P1
- **자동화 가능**: 부분 가능 (외부 앱 설치 불가 자동화)

### Pre-condition
- "앱 설치" 미션이 목록에 있음
- 해당 앱 미설치 상태

### Steps
1. 미션 목록에서 "앱 설치" 미션 탭
2. 미션 상세 화면 확인
3. "미션 수행하기" 버튼 탭

### Expected
- 외부 링크(스토어 또는 웹) 이동 (인앱 브라우저 또는 외부 앱)
- 앱으로 복귀 시 "미션 완료 확인" 버튼 또는 자동 감지 안내 노출

---

## TC-006-003 | 미션 — 채널 추가 (카카오 채널)

- **우선순위**: P1
- **자동화 가능**: 부분 가능

### Pre-condition
- "카카오 채널 추가" 미션 존재

### Steps
1. 미션 목록 → "카카오 채널 추가" 탭
2. 카카오 채널 추가 링크 이동
3. 채널 추가 완료 후 앱 복귀
4. "완료 확인" 탭

### Expected
- 미션 완료 처리 (서버 검증 또는 콜백 수신)
- 보상 지급 토스트 노출
- 해당 미션 "완료" 배지 표시

---

## TC-006-004 | 미션 완료 후 보상 지급 확인

- **우선순위**: P0
- **자동화 가능**: 부분 가능 (mock 완료 이벤트)

### Pre-condition
- 완료 가능한 미션 존재

### Steps
1. 미션 수행 완료 (mock: 완료 이벤트 전송)
2. 미션 목록 화면으로 복귀

### Expected
- 해당 미션 "완료" 상태로 변경
- 보상 (포인트 또는 참여권) 즉시 지급
- 포인트 내역 또는 참여권 수에 반영

---

## TC-006-005 | 이미 완료한 미션 재시도 방지

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 특정 미션이 이미 완료 상태

### Steps
1. 미션 목록에서 완료된 미션 탭

### Expected
- "이미 완료한 미션입니다" 안내 노출
- "미션 수행하기" 버튼 비활성화
- 보상 중복 지급 없음

---

## TC-006-006 | 미션 목록 — 빈 상태 (활성 미션 없음)

- **우선순위**: P2
- **자동화 가능**: 가능 (Patrol — 서버 빈 응답 mock)

### Pre-condition
- 현재 활성화된 미션 없음 (모두 완료 또는 서버 미설정)

### Steps
1. 미션 화면 진입

### Expected
- 빈 상태 화면 노출: "현재 진행 중인 미션이 없습니다"
- 안내 텍스트 또는 일러스트 노출
- "홈으로 가기" CTA 또는 다른 적립 수단 안내
