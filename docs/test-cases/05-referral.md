# TC-05: 친구초대 (Referral)

> 대상 화면: 친구초대 탭 / 초대 링크 발급 / 공유 / 보상 확인

---

## TC-005-001 | 친구초대 탭 진입 및 초대 링크 노출

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 로그인 완료

### Steps
1. 하단 탭 "친구초대" 탭
2. 화면 확인

### Expected
- 내 초대 요약 (총 초대 수 / 성공 수 / 보상 획득 수) 노출
- 내 초대 링크 표시
- 링크 복사 버튼 노출
- 공유 버튼 노출
- 보상 조건 안내 텍스트 노출

---

## TC-005-002 | 초대 링크 복사

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 친구초대 탭 진입

### Steps
1. "링크 복사" 버튼 탭

### Expected
- 클립보드에 초대 링크 복사
- "링크가 복사되었습니다" 토스트 노출
- 복사된 링크 형식: `https://blockpick.io/invite/[코드]`

## TC-005-003 | 공유 시트 열기

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol — 시트 열림 확인)

### Pre-condition
- 친구초대 탭 진입

### Steps

### Expected

- 공유 텍스트에 초대 링크 포함

---

## TC-005-004 | 초대 코드로 신규 가입 — 보상 지급 확인

- **우선순위**: P0
- **자동화 가능**: 부분 가능 (2기기 또는 2계정 필요)

### Pre-condition
- A 유저: 초대 링크 발급 완료
- B 유저: 초대 링크를 통해 신규 가입 예정 (미가입)

### Steps
1. B 유저가 A 유저의 초대 링크 탭
2. B 유저 앱 설치 후 회원가입 완료
3. A 유저 친구초대 탭 확인

### Expected
- A 유저의 "초대 성공 수" +1
- A 유저에게 보상 지급 (추가 참여권 또는 포인트)
- B 유저에게도 신규 가입 혜택 지급

---

## TC-005-005 | 초대 실적 내역 확인

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 초대 성공 이력 1건 이상 존재

### Steps
1. 친구초대 탭 → "초대 실적 내역" 섹션 스크롤

### Expected
- 각 초대 건 목록 노출
- 항목: 초대 일시, 친구 가입 여부, 보상 지급 여부, 지급 일시
- 보상 지급 완료 항목에 완료 배지

---

## TC-005-006 | 중복 초대 방지 (동일 기기/계정)

- **우선순위**: P1
- **자동화 가능**: 부분 가능

### Pre-condition
- A 유저가 B 유저를 초대 → B 가입 완료
- B 유저가 다시 C 기기로 재가입 시도

### Steps
1. 이미 초대 성공한 B 유저가 재가입 시도
2. A 유저 친구초대 탭 확인

### Expected
- 동일 계정/기기 재가입은 초대 성공으로 인정하지 않음
- A 유저 초대 성공 수 불변
- 어뷰징 제한 안내 노출 (해당 시)

## TC-005-008 | 초대 보상으로 블록픽 추가 참여

- **우선순위**: P1
- **자동화 가능**: 부분 가능

### Pre-condition
- 초대 보상으로 추가 참여권 1개 보유
- 진행 중인 블록픽 존재

### Steps
1. 블록픽 상세 화면 → "추가 참여" CTA 탭
2. 보유 참여권 소진하여 블록 선택
3. 확정

### Expected
- 추가 참여권 -1
- 참여 완료 결과 화면 노출
- 참여내역에 "초대 보상 참여" 기록
