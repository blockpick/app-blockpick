# TC-09: 빈 상태 & 오류 처리 (Empty & Error)

> 대상: 빈 상태 5종 / 네트워크 오류 / 권한 거부

---

## TC-009-001 | 빈 상태 — 블록픽 리스트 (데이터 없음)

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol — mock 빈 응답)

### Pre-condition
- 서버에 블록픽 데이터 없음 (또는 필터 결과 없음)

### Steps
1. 블록픽 탭 진입
2. 특정 필터 조합으로 결과 0건

### Expected
- 빈 상태 화면: 일러스트 + "현재 진행 중인 블록픽이 없습니다"
- 필터 초기화 버튼 노출
- 전체 보기 CTA 노출

## TC-009-006 | 네트워크 오류 — API 응답 실패

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol — 네트워크 차단 mock)

### Pre-condition
- 기기 네트워크 비활성화 상태

### Steps
1. 앱 실행
2. 홈 탭 진입 시도

### Expected
- 오류 안내 화면 또는 스낵바: "네트워크 연결을 확인해 주세요"
- "다시 시도" 버튼 노출
- 앱 크래시 없음

## TC-009-007 | 네트워크 오류 — 재시도 성공

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 네트워크 오류 화면 노출 중
- 네트워크 복구

### Steps
1. 네트워크 활성화
2. "다시 시도" 버튼 탭

### Expected
- 정상 데이터 로드
- 홈 탭 콘텐츠 노출
- 오류 화면 제거

## TC-009-008 | 권한 거부 — 카메라 / 알림 권한

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol — 권한 거부 시나리오)

### Pre-condition
- 카메라 또는 알림 권한 거부 상태

### Steps
1. 권한이 필요한 기능 진입 (예: QR 스캔 또는 알림 설정)
2. 권한 요청 다이얼로그에서 "거부" 선택 (또는 이미 거부 상태)

### Expected
- 권한 거부 안내 화면 또는 바텀시트 노출
- "설정으로 이동" 버튼 노출
- 앱이 강제 종료되지 않음
- 권한 없이 사용 가능한 기능은 정상 작동
