# TC-01: 인증 (Auth)

> 대상 화면: 로그인 / 회원가입 / 휴대폰 인증 / 비밀번호 찾기

---

## TC-001-001 | 이메일 신규 회원가입 성공

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 앱 최초 실행 상태
- 해당 이메일로 가입된 계정 없음

### Steps
1. 앱 실행 → 시작 화면 진입
2. "회원가입" 버튼 탭
3. 이메일 입력: `test_user_001@blockpick.io`
4. 비밀번호 입력: `Test1234!`
5. 비밀번호 확인 입력: `Test1234!`
6. "다음" 버튼 탭
7. 약관 동의 화면에서 전체 동의 체크
8. "가입 완료" 버튼 탭

### Expected
- 회원가입 성공 토스트 또는 확인 화면 노출
- 자동 로그인 후 홈 탭 진입
- 상단 앱바에 알림 벨 아이콘 노출

## TC-001-005 | 소셜 로그인 (카카오)

- **우선순위**: P0
- **자동화 가능**: 부분 가능 (카카오 SDK 인터셉트 필요)

### Pre-condition
- 기기에 카카오톡 앱 설치 또는 카카오 계정 보유

### Steps
1. 시작 화면 → "카카오로 로그인" 버튼 탭
2. 카카오 인증 화면에서 계정 선택 / 동의
3. 약관 미동의 시 약관 동의 화면 진입 후 동의
4. 완료

### Expected
- 홈 탭 진입
- 마이 탭 > 프로필에 카카오 연동 아이콘 표시

## TC-001-006 | 소셜 로그인 (Apple)

- **우선순위**: P0
- **자동화 가능**: 부분 가능 (iOS 시뮬레이터 Sign in with Apple)

### Pre-condition
- iOS 기기 / 시뮬레이터, Apple ID 보유

### Steps
1. 시작 화면 → "Apple로 로그인" 버튼 탭
2. Face ID / Touch ID 인증 또는 Apple ID 입력
3. "이름 공유 여부" 선택 후 계속
4. 약관 동의 화면 진입 후 동의

### Expected
- 홈 탭 진입
- 마이 탭 > 프로필에 Apple 연동 표시

## TC-001-007 | 휴대폰 인증 성공

- **우선순위**: P1
- **자동화 가능**: 부분 가능 (SMS mock 필요)

### Pre-condition
- 회원가입 진행 중 또는 마이 > 인증 정보 화면

### Steps
1. "휴대폰 인증" 버튼 탭
2. 휴대폰 번호 입력: `01012345678`
3. "인증번호 발송" 버튼 탭
4. 인증번호 6자리 입력 (테스트 환경: `123456`)
5. "확인" 버튼 탭

### Expected
- "인증 완료" 안내 노출
- 마이 탭 > 인증 정보에 휴대폰 인증 완료 표시

## TC-001-008 | 비밀번호 찾기 이메일 발송

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol — 이메일 수신 제외)

### Pre-condition
- `test_user_001@blockpick.io` 계정 존재

### Steps
1. 로그인 화면 → "비밀번호 찾기" 탭
2. 이메일 입력: `test_user_001@blockpick.io`
3. "재설정 링크 발송" 버튼 탭

### Expected
- "비밀번호 재설정 이메일을 발송했습니다" 안내 화면 노출
- 이메일 재발송 버튼 활성화 (60초 타이머 후)
