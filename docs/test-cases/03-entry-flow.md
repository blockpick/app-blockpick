# TC-03: 참여 흐름 (Entry Flow)

> 대상 화면: 블록픽 상세 → 블록 선택 → 참여 결과

---

## TC-003-001 | 무료 1회 블록 선택 완료

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 로그인 완료
- 진행 중인 블록픽에 해당 유저 미참여 상태

### Steps
1. 블록픽 상세 화면 진입
2. "지금 참여하기" 버튼 탭
3. 블록 선택 화면에서 그리드 블록 1개 탭
4. "선택 확정" 버튼 탭

### Expected
- 참여 결과 화면 진입
- "참여 완료" 상태 표시
- 참여한 블록 번호/위치 표시
- "내 참여내역 보기" 버튼 노출

---

## TC-003-002 | 이미 무료 참여 완료 후 재참여 시도

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 해당 블록픽에 무료 1회 이미 참여 완료

### Steps
1. 동일 블록픽 상세 화면 재진입
2. CTA 버튼 상태 확인

### Expected
- "이미 참여한 블록픽입니다" 또는 "추가 참여 방법으로 기회 얻기" 안내 노출
- 친구 초대 / 광고 시청 / 미션 수행 CTA 노출
- 기존 "지금 참여하기" 버튼 비활성화 또는 변경

---

## TC-003-003 | 블록 선택 화면 — 참여권 수 표시

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 블록픽 상세 → "지금 참여하기" 탭 → 블록 선택 화면 진입

### Steps
1. 블록 선택 화면 상단 UI 확인

### Expected
- 현재 보유 참여권 수 표시
- 그리드 보드 렌더링
- 선택 가이드 문구 노출
- "선택 확정" 버튼 비활성 상태 (블록 선택 전)

---

## TC-003-004 | 블록 선택 후 취소 재선택

- **우선순위**: P2
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 블록 선택 화면 진입

### Steps
1. 그리드에서 블록 A 선택
2. 동일 블록 A 다시 탭 (취소)
3. 블록 B 선택

### Expected
- 블록 A 선택 해제
- 블록 B 강조(선택) 상태
- "선택 확정" 버튼 활성화

---

## TC-003-005 | 참여 결과 — 당첨

- **우선순위**: P0
- **자동화 가능**: 부분 가능 (당첨 조건 mock 필요)

### Pre-condition
- 블록 선택 완료
- 서버에서 당첨으로 판정된 시나리오 (staging mock)

### Steps
1. 블록 선택 → 확정
2. 결과 화면 로드

### Expected
- 당첨 애니메이션 / 시각 효과 노출
- "당첨!" 상태 텍스트 노출
- 경품 정보 노출
- "당첨 정보 확인" CTA 버튼 노출
- "친구에게 공유하기" 버튼 노출

- **자동화 가능**: 부분 가능

## TC-003-008 | 친구 초대 보상으로 추가 참여권 획득 후 참여

- **우선순위**: P1
- **자동화 가능**: 부분 가능 (초대 보상 mock)

### Pre-condition
- 무료 1회 참여 완료
- 친구 초대 보상으로 추가 참여권 1개 보유

### Steps
1. 블록픽 상세 화면 → "추가 참여" 탭
2. "친구 초대 보상 사용" 선택
3. 블록 선택 화면에서 블록 선택
4. 확정

### Expected
- 참여권 1개 차감 표시
- 참여 완료 결과 화면 진입
- 참여내역에 2회 참여 기록

---

## TC-003-009 | 광고 시청 후 추가 참여권 획득

- **우선순위**: P1
- **자동화 가능**: 부분 가능 (광고 SDK mock)

### Pre-condition
- 무료 1회 참여 완료
- 광고 시청 가능 횟수 잔여 있음

### Steps
1. 참여 결과 화면 → "광고 보고 다시 참여" 탭
2. 광고 시청 완료 (mock: 5초 스킵)
3. "기회 받기" 확인

### Expected
- "추가 참여권 1개 획득" 토스트 노출
- 블록 선택 화면으로 자동 이동 또는 CTA 활성화

---

## TC-003-010 | 참여 완료 후 참여내역 탭 확인

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 특정 블록픽에 1회 참여 완료

### Steps
1. 참여 결과 화면 → "내 참여내역 보기" 탭
2. 참여내역 탭 확인

### Expected
- 참여한 블록픽 카드 노출
- 상태: "진행중" 또는 "대기중"
- 참여 횟수 표시

---

## TC-003-011 | 블록 선택 화면 — 타인 선택 블록 표시

- **우선순위**: P1
- **자동화 가능**: 부분 가능

### Pre-condition
- 이미 다른 유저가 일부 블록 선택한 블록픽

### Steps
1. 블록 선택 화면 진입
2. 그리드 확인

### Expected
- 타인 선택 블록: 회색 또는 비활성 상태
- 선택 불가 블록 탭 시 안내 메시지 또는 무반응
- 선택 가능 블록만 탭 가능

---

## TC-003-012 | 참여 흐름 — 비로그인 상태에서 참여 시도

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 비로그인 상태

### Steps
1. 블록픽 상세 화면 진입 (딥링크 또는 공유 링크)
2. "지금 참여하기" 버튼 탭

### Expected
- 로그인 화면으로 이동 또는 로그인 바텀시트 노출
- 로그인 완료 후 원래 블록픽 상세로 복귀
