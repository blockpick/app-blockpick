# TC-08: 알림 (Notification)

> 대상 화면: 알림함 / 알림 설정 / 딥링크 진입

---

## TC-008-001 | 알림함 진입 및 목록 노출

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 로그인 완료
- 수신된 알림 1개 이상 존재

### Steps
1. 홈 상단 벨 아이콘 탭
   또는 마이 탭 → "알림함" 탭

### Expected
- 알림 목록 노출
- 각 알림: 제목, 내용 요약, 수신 시간
- 읽지 않은 알림: 강조(굵게 또는 dot) 표시
- 읽은 알림: 일반 표시

---

## TC-008-002 | 알림 읽음 처리

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 읽지 않은 알림 1개 이상 존재

### Steps
1. 알림함 진입
2. 읽지 않은 알림 항목 탭

### Expected
- 해당 알림 읽음 처리 (강조 해제)
- 상단 벨 아이콘 뱃지 숫자 -1
- 알림 내용에 따른 화면으로 이동 (딥링크)

---

## TC-008-003 | 알림 딥링크 — 당첨 알림

- **우선순위**: P0
- **자동화 가능**: 부분 가능 (푸시 mock)

### Pre-condition
- 당첨 알림 수신

### Steps
1. 알림함에서 당첨 알림 탭

### Expected
- 당첨 상세 화면으로 직접 이동
- 배송지 입력 CTA 노출

---

## TC-008-004 | 알림 설정 — 푸시 알림 ON/OFF

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 마이 탭 → 알림 설정 화면 진입

### Steps
1. "당첨 알림" 토글 OFF
2. "마케팅 알림" 토글 OFF
3. 확인 후 화면 재진입

### Expected
- 토글 상태 저장 유지
- 알림 설정 변경 사항 서버에 반영
- 해당 알림 유형 미수신 확인

---

## TC-008-005 | 알림 전체 삭제

- **우선순위**: P2
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 알림 2개 이상 존재

### Steps
1. 알림함 → "전체 삭제" 버튼 탭
2. 확인 다이얼로그 → "삭제" 탭

### Expected
- 알림 목록 전체 삭제
- 빈 상태 화면 노출: "알림이 없습니다"
- 벨 아이콘 뱃지 제거

---

## TC-008-006 | 알림함 — 빈 상태

- **우선순위**: P2
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 수신된 알림 없음

### Steps
1. 알림함 진입

### Expected
- 빈 상태 화면: "새로운 알림이 없습니다"
- 홈 또는 블록픽 탭 이동 CTA 노출
