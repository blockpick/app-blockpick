# TC-02: 블록픽 탐색 (Discovery)

> 대상 화면: 홈 탭 / 블록픽 탭 / 검색 / 필터 / 정렬 / 상세 진입

---

## TC-002-001 | 홈 탭 진입 및 섹션 정상 노출

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 로그인 완료 상태
- 서버에 진행 중인 블록픽 1개 이상 존재

### Steps
1. 하단 탭 "홈" 탭 탭
2. 화면 스크롤 다운

### Expected
- 메인 프로모션 배너 노출
- "추천 블록픽" 섹션 노출
- "진행 중 블록픽" 섹션 노출
- "신규 오픈" 섹션 노출
- "마감 임박" 섹션 노출
- 각 섹션에 블록픽 카드 1개 이상 노출

---

## TC-002-002 | 블록픽 탭 리스트 정상 로드

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 로그인 완료
- 서버에 블록픽 데이터 2개 이상 존재

### Steps
1. 하단 탭 "블록픽" 탭 탭
2. 리스트 렌더링 확인

### Expected
- 블록픽 카드 리스트 노출 (썸네일 / 제목 / 파트너명 / 마감 정보 / 상태 배지)
- 카테고리 칩 (전체 / 쇼핑 / 앱·서비스 / 쿠폰·리워드 / 오프라인 이벤트 / 기타) 노출
- 정렬 드롭다운 노출
- 필터 버튼 노출

---

## TC-002-003 | 키워드 검색 — 결과 있음

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 블록픽 탭 진입
- 서버에 "스타벅스" 포함 블록픽 존재

### Steps
1. 검색바 탭
2. "스타벅스" 입력
3. 키보드 엔터 또는 검색 버튼 탭

### Expected
- "스타벅스" 관련 블록픽 카드 1개 이상 노출
- 검색 결과 수 표시 (`N개의 결과`)
- 검색어 하이라이트 표시 (선택적)

---

## TC-002-004 | 키워드 검색 — 결과 없음

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 블록픽 탭 진입

### Steps
1. 검색바 탭
2. "존재하지않는브랜드XYZ" 입력
3. 검색 실행

### Expected
- 빈 상태 화면 노출: "검색 결과가 없습니다"
- 검색어 초기화 버튼 노출
- 리스트 영역 비어있음

## TC-002-005 | 카테고리 필터 — 쇼핑

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 블록픽 탭 진입
- "쇼핑" 카테고리 블록픽 존재

### Steps
1. 카테고리 칩에서 "쇼핑" 탭
2. 리스트 결과 확인

### Expected
- "쇼핑" 카테고리 칩 강조(선택) 상태
- 쇼핑 카테고리 블록픽만 노출
- 다른 카테고리 블록픽 미노출

## TC-002-006 | 카테고리 필터 — 전체 복귀

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- "쇼핑" 카테고리 필터 적용 상태

### Steps

### Expected

## TC-002-007 | 정렬 변경 — 마감임박순

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 블록픽 탭 리스트 노출 중

### Steps
1. 정렬 드롭다운 탭
2. "마감임박순" 선택

### Expected
- 리스트가 마감 임박 순서로 재정렬
- 첫 번째 카드의 마감 시간이 두 번째 카드보다 빠름
- 정렬 드롭다운에 "마감임박순" 표시

## TC-002-008 | 필터 적용 — 무료 참여 가능

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 블록픽 탭 리스트 노출 중

### Steps
1. 필터 버튼 탭
2. "무료 참여 가능" 옵션 선택
3. "적용" 버튼 탭

### Expected
- 무료 참여 가능 블록픽만 노출
- 필터 버튼에 활성화 뱃지 노출 (숫자 또는 dot)

## TC-002-009 | 블록픽 상세 진입 (홈 탭 카드)

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 홈 탭 진입, 블록픽 카드 1개 이상 노출

### Steps
1. 홈 탭 블록픽 카드 탭

### Expected
- 블록픽 상세 화면 진입
- 대표 이미지, 캠페인명, 파트너명, 참여 기간, 혜택 정보, 참여 방법 노출
- 하단 "지금 참여하기" CTA 버튼 노출

## TC-002-010 | 블록픽 상세 — 마감된 캠페인

- **우선순위**: P1
- **자동화 가능**: 부분 가능

### Pre-condition
- 마감된 블록픽 존재 (status: closed)

### Steps
1. 마감된 블록픽 카드 탭
2. 상세 화면 확인

### Expected
- "종료" 배지 노출
- "지금 참여하기" CTA 버튼 비활성화 또는 미노출
- "이미 종료된 블록픽입니다" 안내 문구 노출
