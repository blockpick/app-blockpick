# TC-07: 당첨 내역 (Winning)

> 대상 화면: 당첨 내역 / 당첨 상세 / 배송지 입력 / 고객 문의

---

## TC-007-001 | 참여내역 탭 — 당첨 필터 확인

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 로그인 완료
- 당첨 이력 1건 이상 존재

### Steps
1. 하단 탭 "참여내역" 탭
2. 상단 세그먼트에서 "당첨" 탭

### Expected
- 당첨된 블록픽 카드만 노출
- 각 카드: 블록픽명, 경품명, 당첨 일시, 지급 상태
- "당첨" 배지 노출

---

## TC-007-002 | 당첨 상세 화면 진입

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 당첨 내역 1건 이상 존재

### Steps
1. 참여내역 → 당첨 탭 → 당첨 카드 탭

### Expected
- 당첨 상세 화면 진입
- 당첨된 블록픽 정보, 당첨 일시, 경품명 노출
- 지급 상태 표시 (대기 / 처리 중 / 완료)
- 수령 정보 입력 CTA (미입력 시) 또는 배송 정보 노출 (입력 완료 시)

---

## TC-007-003 | 배송지 입력 — 성공

- **우선순위**: P0
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 당첨 상세 화면 진입
- 배송지 미입력 상태

### Steps
1. "배송지 입력하기" CTA 탭
2. 수령자명 입력: `홍길동`
3. 연락처 입력: `01012345678`
4. 주소 검색: `서울시 강남구 테헤란로 123`
5. 상세 주소 입력: `456호`
6. "저장" 버튼 탭

### Expected
- "배송지가 저장되었습니다" 토스트 노출
- 당첨 상세 화면에 입력한 배송지 정보 표시
- 지급 상태 "처리 중"으로 변경 (또는 파트너 검토 대기)

---

## TC-007-004 | 배송지 수정

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 배송지 1회 입력 완료 상태
- 수정 가능 기간 이내

### Steps
1. 당첨 상세 → "배송지 수정" 버튼 탭
2. 상세 주소 수정: `789호`
3. "저장" 탭

### Expected
- 수정된 배송지 정보 저장
- "배송지가 수정되었습니다" 토스트 노출
- 수정 불가 기간(배송 처리 시작 후) 시 "수정 불가" 안내

## TC-007-007 | 당첨 상세 — 고객 문의하기

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol — 화면 전환 확인)

## TC-007-008 | 지급 상태별 UI 구분

- **우선순위**: P1
- **자동화 가능**: 가능 (Patrol)

### Pre-condition
- 지급 상태가 다른 당첨 건 여러 개 존재

### Steps
1. 참여내역 → 당첨 목록 확인

### Expected
- "대기 중": 회색 또는 노란 배지
- "처리 중": 파란 배지
- "지급 완료": 초록 배지
- "지급 불가/취소": 빨간 배지
- 각 상태별 배지 색상 및 텍스트 구분 명확
