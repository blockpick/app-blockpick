# TC-10: Cross-track 시나리오

> 파트너(partner-blockpick) → Admin(admin-blockpick) → 유저(app-blockpick) 전체 흐름

---

## TC-010-001 | 파트너 캠페인 생성 → 유저 탐색 노출

- **우선순위**: P0
- **자동화 가능**: 부분 가능 (파트너 웹 + 유저 앱 연동)

### Pre-condition
- 파트너 계정 로그인 완료 (partner-blockpick)
- Admin 검수 승인 설정 있음

### Steps
1. [파트너] 파트너 대시보드 → "새 블록픽 생성"
2. [파트너] 캠페인명: "스타벅스 신메뉴 이벤트", 카테고리: 쇼핑, 기간 설정, 경품 정보 입력
3. [파트너] "게시 요청" 버튼 클릭
4. [Admin] 관리자 대시보드 → 검수 대기 목록 확인
5. [Admin] 해당 캠페인 검수 후 "승인" 클릭
6. [유저앱] 블록픽 탭 새로고침

### Expected
- [Admin] 검수 대기 목록에 파트너 캠페인 노출
- [유저앱] 블록픽 리스트에 "스타벅스 신메뉴 이벤트" 카드 노출
- [유저앱] 홈 탭 "신규 오픈" 섹션에도 노출

---

## TC-010-002 | 파트너 캠페인 생성 → Admin 반려 → 파트너 수정 재요청

- **우선순위**: P1
- **자동화 가능**: 부분 가능 (수동 검수 과정)

### Pre-condition
- 파트너 게시 요청 완료

### Steps
1. [Admin] 검수 대기 캠페인 → "반려" 클릭 + 반려 사유 입력
2. [파트너] 대시보드 → 반려 알림 확인
3. [파트너] 캠페인 수정 (이미지 변경 등)
4. [파트너] "재검수 요청"
5. [Admin] 재검수 후 "승인"

### Expected
- [파트너] 반려 사유 화면에 노출
- [파트너] 수정 후 재요청 가능
- [Admin] 재검수 목록에 정상 표시
- [유저앱] 최종 승인 후 정상 노출

## TC-010-003 | 유저 블록픽 참여 → Admin 참여자 확인

- **우선순위**: P1
- **자동화 가능**: 부분 가능

### Pre-condition
- 파트너 캠페인 승인 완료, 유저앱에 노출

### Steps
1. [유저앱] 해당 블록픽 상세 → "지금 참여하기" → 블록 선택 → 완료
2. [Admin] 관리자 대시보드 → 해당 캠페인 → 참여자 목록

### Expected
- [Admin] 참여자 목록에 유저 정보 실시간 반영
- 참여 일시, 선택 블록 번호 확인 가능
- [파트너] 파트너 대시보드에도 참여 통계 반영

## TC-010-004 | 캠페인 종료 → 당첨자 선정 → 유저 알림

- **우선순위**: P0
- **자동화 가능**: 부분 가능 (당첨 선정 트리거 mock)

### Pre-condition
- 블록픽 캠페인 기간 종료
- 참여자 3명 이상 존재

### Steps
1. [Admin] 캠페인 상세 → "추첨 실행" 버튼 클릭
2. [Admin] 당첨자 확인
3. [유저앱] 당첨 유저 알림함 확인

### Expected
- [Admin] 당첨자 목록 생성 (블록체인 기록)
- [유저앱] 당첨 유저에게 푸시 알림 전송
- [유저앱] 알림 탭 → "축하합니다! 당첨되었습니다" 노출
- [유저앱] 참여내역 → 당첨 세그먼트에 해당 캠페인 노출

---

## TC-010-005 | 당첨자 배송지 입력 → 파트너 배송 처리

- **우선순위**: P0
- **자동화 가능**: 부분 가능

### Pre-condition
- TC-010-004 완료
- 당첨 유저 앱 로그인 상태

### Steps
1. [유저앱] 당첨 알림 탭 → 당첨 상세 진입
2. [유저앱] "배송지 입력" → 수령자 정보 입력 → 저장
3. [파트너] 파트너 대시보드 → 당첨자 배송지 정보 확인
4. [파트너] "배송 완료" 처리
5. [유저앱] 지급 상태 확인

### Expected
- [파트너] 당첨자 배송지 정보 수신 확인
- [파트너] 배송 완료 처리 후 상태 변경
- [유저앱] 지급 상태 "배송 완료"로 업데이트
- [유저앱] 알림: "경품이 발송되었습니다"

## TC-010-006 | 친구 초대 → 신규 유저 가입 → 파트너 통계 반영

- **우선순위**: P1
- **자동화 가능**: 부분 가능 (2계정 필요)

### Pre-condition
- 파트너 캠페인에 친구 초대 기능 활성화
- A 유저가 해당 캠페인에 참여 중

### Steps
1. [유저앱 A] 블록픽 상세 → "친구 초대하고 기회 받기" → 초대 링크 공유
2. [유저앱 B] 초대 링크로 앱 설치 → 회원가입 → 캠페인 참여
3. [Admin] 캠페인 통계 확인
4. [파트너] 파트너 대시보드 → 리퍼럴 통계 확인

### Expected
- [유저앱 A] 초대 보상 지급 (추가 참여권)
- [유저앱 B] 신규 가입 혜택 지급
- [Admin] 리퍼럴 참여자로 B 유저 기록
- [파트너] 친구 초대 통계 +1

## TC-010-007 | 캠페인 강제 종료 (Admin) → 유저 참여 차단

- **우선순위**: P1
- **자동화 가능**: 부분 가능

### Pre-condition
- 진행 중인 캠페인 존재
- 긴급 운영 이슈 발생 시나리오

### Steps
1. [Admin] 캠페인 상세 → "즉시 종료" 버튼 클릭 → 사유 입력
2. [유저앱] 해당 블록픽 상세 화면 새로고침

### Expected
- [유저앱] "종료된 블록픽입니다" 안내 노출
- [유저앱] "지금 참여하기" 버튼 비활성화
- [유저앱] 이미 참여한 유저의 참여내역에 "종료" 상태 표시
- [파트너] 파트너 대시보드에 캠페인 종료 알림
