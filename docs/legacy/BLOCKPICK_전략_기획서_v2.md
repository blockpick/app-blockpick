## 1. 현재 진단

### 1.1 잘 설계된 것 (유지)

| 항목 | 의미 |
|------|------|
| 커밋-리빌 구조 | 온체인 기반 조작 불가 신뢰 확보 |
| 참가비 1,000원 | 낮은 진입장벽 → 충동 참여 유도 |
| 실물 경품 | 비크립토 유저 유입 가능 |
| Ronin 체인 | 게임 최적화 체인, 가스비 6원 수준 |
| 광고→포인트→게임 순환 | 무료 유입→유료 전환 퍼널 |
| 싱가포르 법인 보유 | 규제 리스크 선제 대응 기반 |

### 1.2 즉시 수정 필요 (위험)

| 항목 | 문제 | 대응 |
|------|------|------|
| P2E를 처음부터 붙이려는 방향 | 리텐션 검증 전 토큰 도입은 Axie 실패 반복 | 포인트로 6개월 시뮬레이션 후 전환 |
| 토큰 발행 타이밍 너무 이름 | 유저 기반 없는 토큰은 가치 0 | MAU 10만 + BEP 달성 후 발행 |
| 유동성 풀 설계 부재 | 유동성 없으면 $PICK 환금 불가 | 최소 3,000만원 유동성 + Lock 1년 |
| 경품 지속성 재원 불명확 | 경품 못 주면 법적 문제 + 신뢰 붕괴 | 최소 참여자 기준 + 브랜드 협찬 병행 |
| 법적 리스크 미대응 | 복권법/가상자산법 위반 시 서비스 중단 | Web3 법무법인 선계약 |
| 토큰 가치 붕괴 시나리오 대비 부족 | SLP 사태 반복 가능 | 원화 최소 보장선 + 소각 메커니즘 |

### 1.3 방향은 맞지만 보완 필요

- 가차 시스템 → 재미 검증 데이터 수집 필요
- 데일리 미션 → 보상 밸런스 수치 설정 미완
- 파트너스 구조 → 수익 쉐어율 확정 필요
- $PICK 발행량/소각률 → 포인트 운영 데이터 기반 설계
- DEX 유동성 공급 주체·금액 → 투자 유치 or 자체 확보 결정

### 1.4 숨겨진 강점

- "복권 + 블록체인" 포지션 → 국내 경쟁자 0
- 한국 P2E 1위 공백 상태 (Axie/Stepn 이후)
- Axie/Stepn 이탈 유저풀 존재 (국내 30~50만)
- 빠른 피벗 가능한 소규모 조직

## 3. 3중 비즈니스 레이어

블록픽은 단일 사업이 아니라, **3개 비즈니스를 순서대로 쌓는 구조**이다.

| 순서 | 레이어 | 핵심 수익 | 유저 가치 | 시기 |
|------|--------|-----------|-----------|------|
| **1순위** | 게임 플랫폼 | 참가비 × 참여자 | 재미 + 경품 기대감 | **지금** |
| **2순위** | 광고 미디어 | CPM × 유저 수 | 무료 포인트 | **3개월 후** |
| **3순위** | P2E 생태계 | 토큰 수수료 | 경제적 보상 | **12개월 후** |

> **핵심 원칙: 아래 레이어가 안정되기 전에 위 레이어를 붙이지 않는다.**

## 4. 5대 핵심 전략

### 전략 1: 게임 퍼스트 (Game First)

P2E, 토큰, 광고 그 어떤 것보다 **게임이 재밌어야** 한다.

- 7일 리텐션 30% 달성 전까지 P2E를 붙이지 않는다
- "다음에 또 하고 싶다"는 감각이 핵심
- **즉시 액션:**
  - 큐브 UI 완성도 개선
  - 당첨 연출 임팩트 극대화
  - 탈락 시 "아쉽다" 감정 설계 (니어미스 효과)

### 전략 2: 무료 유입 → 유료 전환 퍼널

- 광고 10편 시청 = 1회 무료 참여
- 지갑 설치 없이 앱만 깔면 즉시 시작
- 무료 3~5회 경험 → 유료 전환
- **즉시 액션:**
  - 원화 결제 + 광고 포인트 동시 지원
  - 지갑은 선택 사항으로 (강제 X)

### 전략 3: 바이럴 엔진 설계

- 당첨 연출을 **영상으로 캡처하고 싶게** 만든다
- "나 블록픽에서 에르메스 당첨됐다" 한 장면 = 수억 원 광고 효과
- **즉시 액션:**
  - 당첨 연출 화면 공유 버튼 필수
  - 공유 시 추가 보상 (포인트/무료 참여권)
  - 틱톡/릴스 형식 자동 영상 생성

### 전략 4: 포인트로 P2E 시뮬레이션

- $PICK 토큰을 바로 만들지 않는다
- **포인트 시스템으로 6개월 운영**하며 경제 구조 검증
- 포인트 발행/소비 데이터가 토큰 설계의 기반
- **즉시 액션:**
  - DB 기반 포인트 시스템 구축
  - 발행/소각 로그 전부 기록
  - 포인트 경제 대시보드 구축

### 전략 5: 법적 리스크 선제 해결

- 복권법, 가상자산업법, 경품 한도 규제 동시 적용
- ADNORI PTE.(싱가포르)를 서비스 주체로, 한국은 중개 구조
- **즉시 액션:**
  - Web3 법무법인 자문 계약
  - 싱가포르 MAS 가이드라인 검토
  - 한국 경품 한도 확인 (현재 10만원 이하 면세)

## 5. P2E 3단계 온도 조절

### Phase 1: 냉 — 포인트 경제 (0~6개월)

| 항목 | 내용 |
|------|------|
| **개요** | P2E 없는 순수 게임. 포인트만 운영 |
| **결제** | 원화 결제만 (인앱 결제 / PG) |
| **보상** | 광고→포인트→참여 구조. 탈락자 포인트 위로 보상 |
| **온체인** | 없음 (커밋-리빌만 유지) |
| **목표** | 빠르게 만들고 빠르게 검증 |
| **다음 단계 진입 조건** | 7일 리텐션 30% 달성 |
| **KPI** | MAU 1만명, 7일 리텐션 30%, 재참여율 40% |

### Phase 2: 온 — 하이브리드 (6~12개월)

| 항목 | 내용 |
|------|------|
| **개요** | 포인트 + $PICK 동시 운영 |
| **지갑** | Ronin 지갑 연동 선택 지원 |
| **전환** | 포인트 → $PICK 전환 가능 (단방향) |
| **DEX** | Katana DEX 유동성 공급 (최소 3,000만원) |
| **스테이킹** | 베타 오픈 |
| **원칙** | "지갑 없어도 게임 가능" 유지 |
| **전제 조건** | 법적 구조 완료 필수 |
| **KPI** | MAU 5만명, DEX 상장, BEP 달성 |

### Phase 3: 열 — 풀 P2E (12개월~)

| 항목 | 내용 |
|------|------|
| **개요** | $PICK이 게임 경제의 중심 |
| **인센티브** | $PICK 결제 시 10% 할인 → 실용 수요 |
| **NFT** | 아이템 마켓 오픈 |
| **거버넌스** | DAO 운영 (경품·규칙·수수료 투표) |
| **디플레이션** | 소각 > 발행 전환 |
| **CEX** | 중소→대형 순차 상장 추진 |
| **글로벌** | 동남아 P2E 유저 흡수 |
| **KPI** | MAU 20만명, 소각>발행, CEX 상장 |

## 6. $PICK 토큰 경제 설계

### 6.1 핵심 수치

| 항목 | 값 | 비고 |
|------|-----|------|
| 총 발행량 | **10억 개 (고정 상한)** | 추가 발행 불가 — 희소성 보장 |
| 초기 유통량 | 10% (1억 개) | 나머지 락업 후 단계적 해제 |
| 게임 보상 풀 | 40% — 5년간 배포 | 탈락/당첨 보상 재원 |
| 소각 조건 | **$PICK 결제 시 20% 즉시 소각** | 디플레이션 압력 |
| 디플레이션 전환점 | 월 40만 참여자 | 소각 ≥ 발행 달성 시점 |
| 원화 보장선 | 탈락 보상 최소 20원 상당 | 토큰 가격 무관 — Axie SLP 방지 |

### 6.2 토큰 배분 구조

| 배분 대상 | 비율 | 용도 |
|-----------|------|------|
| 게임 보상 풀 | **40%** | 탈락/당첨 보상 재원 |
| 생태계 개발 | 20% | 파트너십, 이벤트 |
| 팀 / 운영 | 15% | 4년 베스팅, 1년 클리프 |
| 초기 유동성 | 10% | DEX 유동성 풀 공급 |
| 스테이킹 리워드 | 10% | APY 5~15% |
| 마케팅 / 파트너 | 5% | 인플루언서, 광고 |

### 6.3 Axie SLP 방지 메커니즘

| 실패 원인 (SLP) | BlockPick 대응 |
|------------------|---------------|
| 무제한 발행 | 총량 10억 고정, 자동 축소 컨트랙 |
| 소각 수요 없음 | $PICK 결제 시 20% 소각 + 참가비 5% 소각 |
| 가격 하락 → 이탈 악순환 | 원화 최소 보장선 20원 (토큰 가격 무관) |
| 유저가 팔기만 함 | 스테이킹 인센티브 + 게임 내 $PICK 할인 |

## 7. 코인 발행 및 DEX 전략

### 7.1 기술 난이도

| 항목 | 난이도 | 비용 |
|------|--------|------|
| 기본 ERC-20 발행 | 쉬움 | 가스비 15~75원 |
| 소각·세금 커스텀 로직 | 중간 | 개발 1~2주 |
| Katana DEX 상장 | 쉬움 | 유동성 자금만 필요 |
| 보안 감사 (Audit) | 어려움 | 500만~2,000만원 |
| CEX 상장 (업비트 등) | 매우 어려움 | 수억원 + 실적 필요 |

### 7.2 DEX vs CEX — 왜 처음엔 DEX만

| | DEX (Katana) | CEX (업비트/바이낸스) |
|---|---|---|
| 심사 | 없음 | 엄격 |
| 비용 | 가스비 + 유동성 자금 | 수억 원 상장비 |
| 시간 | 몇 분 | 수개월 |
| 허가 | 불필요 | 필요 |
| 시기 | **지금 당장 가능** | 12~18개월 후 |

### 7.3 토큰 발행 → DEX 상장 전체 플로우

```
Step 1. Ronin 개발자 등록 (1~3일, 무료)
    ↓
Step 2. ERC-20 스마트컨트랙 작성 (Solidity + OpenZeppelin)
    ↓
Step 3. Saigon 테스트넷 배포 및 검증 (무료)
    ↓
Step 4. 보안 감사 2개사 (500만~2,000만원, 2~4주)
    ↓
Step 5. Ronin 메인넷 배포 (가스비 15~75원)
    ↓
Step 6. Katana DEX 유동성 풀 생성 (즉시 거래 가능)
```

### 7.4 유동성 전략

> **유동성 풀 없으면 유저가 $PICK을 팔 수 없다.**

| 항목 | 값 |
|------|-----|
| 유동성 페어 | $PICK / RON |
| 초기 공급 규모 | **최소 3,000만원 상당** |
| 유동성 재원 | 토큰 배분 10% + 투자 유치 RON |
| 러그풀 방지 | **유동성 Lock 최소 1년** (온체인 공개) |
| Lock 도구 | Team Finance / Unicrypt |
| 마켓메이킹 | 전문 MM 파트너 계약 |

### 7.5 DEX → CEX 상장 로드맵

```
Katana DEX (6~12개월)  →  중소 CEX (12~18개월)  →  대형 CEX (18~24개월)
  누구나 가능               MEXC, Gate.io            업비트, 바이낸스
  유동성만 필요             MAU 10만 + 거래량         커뮤니티 + 법적 구조
```
