# 블록픽 마이페이지 기획서

## 1. 개요

블록픽 앱의 마이페이지는 사용자의 **재화 관리**, **게임 참가 내역**, **쇼핑 내역**, **충전/환불** 기능을 제공합니다.

**구성 요소:**

  - 닉네임

  - 회원 등급 (BRONZE/SILVER/GOLD/VIP 등)
- **알림 아이콘** 🔔
  - 새로운 알림 배지 표시
- **설정 아이콘** ⚙️

### 3.2 총 자산 영역 (Hero Section)

```
┌─────────────────────────────────────┐
│  Est total value 👁️                 │
│                                     │
│  28,000 USDT ▼                      │
│             📈 (미니 차트)          │
│                                     │
│  Today's PnL: +5,000원 (+21.7%) >  │
└─────────────────────────────────────┘
```

**표시 정보:**
- **총 보유 캐시 금액**
  - 충전캐시 + 이벤트캐시 + 쇼핑캐시 합계
  - 원화(₩) 표시
- **오늘의 변동 (Today's PnL)**
  - 당일 게임 승리금, 쇼핑 환급 등으로 인한 증감
  - 금액 + 퍼센트 표시
  - 증가: 초록색 ↗️ / 감소: 빨간색 ↘️
- **미니 차트**
  - 최근 7일간 캐시 잔액 변동 추이

**인터랙션:**
- 금액 우측 ▼: 통화 단위 변경 (원화 ↔ USD 등)
- 차트 영역 탭: 상세 통계 페이지로 이동

### 3.3 주요 액션 버튼 (3개)

```
┌─────────────────────────────────────┐
│  ┌────┐  ┌────┐  ┌────┐            │
│  │ 💳 │  │ 💸 │  │ 📊 │            │
│  │충전│  │환불│  │내역│            │
│  └────┘  └────┘  └────┘            │
└─────────────────────────────────────┘
```

#### 1) 충전 (Deposit)
- **기능**: Stripe/토스페이먼츠로 캐시 충전
- **흐름**:
  1. 금액 입력
  2. 받게 될 재화 미리보기 (이벤트+쇼핑 캐시)
  3. 결제 수단 선택
  4. 결제 진행

#### 2) 환불 (Refund)
- **기능**: 미사용 충전캐시 환불 신청
- **조건**:
  - 이벤트 캐시 **AND** 쇼핑 캐시 **모두 미사용**
  - 환불 가능 금액만 표시
- **흐름**:
  1. 환불 가능 금액 확인
  2. 환불 계좌 입력
  3. 환불 신청

#### 3) 내역 (History)
- **기능**: 전체 거래 내역 조회
- **필터**:
  - 충전/환불
  - 게임 참가/상금
  - 쇼핑 구매/환급

### 3.4 캐시 배분 영역 (Allocation)

```
┌─────────────────────────────────────┐
│  📦 내 캐시 잔액               ⌄    │
├───────────┬───────────┬─────────────┤
│    💼     │    🎮     │     🛒      │
│  충전캐시  │ 이벤트캐시 │  쇼핑캐시   │
│           │           │             │
│ ₩10,000   │  ₩8,000   │  ₩10,000    │
│           │           │             │
│ 🔒 잠금   │ 🔓 사용가능│ 🔓 사용가능 │
└───────────┴───────────┴─────────────┘
```

**3가지 캐시 유형:**

#### 1) 💼 충전캐시 (Funding)
- **설명**: 충전했지만 아직 분배되지 않은 원본 금액
- **상태**: 🔒 환불 가능 (미사용 시)
- **용도**: 환불 신청 대상 금액

#### 2) 🎮 이벤트 캐시 (Gaming)
- **설명**: 블록픽 게임 참가에 사용되는 캐시
- **상태**: 🔓 사용 가능
- **용도**: 게임 라운드 참가비 결제

#### 3) 🛒 쇼핑 캐시 (Shopping)
- **설명**: 쇼핑몰 상품 구매에 사용되는 캐시
- **상태**: 🔓 사용 가능
- **용도**: 쇼핑몰 결제

**인터랙션:**
- 각 카드 탭: 해당 캐시의 상세 사용 내역으로 이동
- ⌄ 버튼: 섹션 접기/펼치기

**재화 흐름 시각화:**
```
충전 10,000원
    ↓
충전캐시 10,000원 (환불 가능)
    ↓ (자동 분배)
├─ 이벤트 캐시 10,000원
└─ 쇼핑 캐시 10,000원

※ 이벤트/쇼핑 캐시 중 하나라도 사용 시
  → 충전캐시 잠금 해제 (환불 불가)
```

```
마이페이지
  ↓ [충전] 버튼 탭

  ↓ 금액 입력 + 결제 수단 선택 + 동의

  ↓ 결제 성공

```

```

  ↓ [환불] 버튼 탭

  ↓ 계좌 정보 입력

  ↓
환불 완료 알림
```

```
게임 목록
  ↓ 게임 선택

  ↓ [참가하기]

  ↓ (잔액 충분)
이벤트 캐시 차감
  ↓
게임 참가 완료
  ↓ (자동으로)
충전캐시 환불 불가 처리
```
