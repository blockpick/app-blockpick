# 프론트엔드 인증 프로세스 플로우

## 개요
BlockPick 앱의 로그인 / 회원가입 프로세스 (비로그인 포함)

---

## 화면 목록

| 화면 ID | 화면명 | 설명 |
|---------|--------|------|
| SC-001 | Splash 화면 | 앱 시작 화면, 네트워크 오류 처리 |
| SC-002 | 권한설정 | 앱 접근 권한 안내 (최초 1회) |
| SC-003 | 온보딩 화면 | 서비스 소개 (3장 스와이프) |
| SC-004 | 로그인 | 이메일/SNS 로그인 |
| SC-005 | 회원가입 | 휴대폰 인증 + 이메일/비밀번호 설정 |
| SC-006 | 이메일 찾기 | 휴대폰 번호로 가입 이메일 찾기 |
| SC-007 | 비밀번호 찾기 | 이메일 인증 후 비밀번호 재설정 |

## SC-001: Splash 화면

### SC-001-01: 기본 스플래시
- 브랜드 로고 노출 (Blockpick)
- 이미지 형식: SVG, PNG, JPG file, JSON (Lottie)

### SC-001-02: 네트워크 오류
- 네트워크 오류 이미지 노출
- 제목: "연결이 잠시 끊겼어요."
- 설명: "인터넷 연결 상태를 확인하고 다시 시도해 주세요."
- "다시시도" 버튼 노출
- 네트워크 연결되면 해당 페이지 자동 종료

```
앱 실행 → 스플래시 화면 표시
              │
              ▼
        네트워크 상태 확인
              │
      ┌───────┴───────┐
      │               │
   [연결됨]        [연결 안됨]
      │               │
      ▼               ▼
   홈 화면       네트워크 오류 화면
                      │
                      ▼
               "다시시도" 버튼
                      │
                      ▼
              네트워크 재확인
```

## SC-002: 권한설정

**앱 최초 실행 시 1회 노출**

### 화면 구성
1. **텍스트**: "앱 접근 권한 안내"
2. **안내 문구**: "블록픽은 더 나은 서비스를 위해 아래와 같은 권한이 필요해요."

### 필수 접근 권한
- **기기 및 저장공간**: 서비스 최적화 및 오류 확인
  - ※ 개발팀 검토 필요

### 선택 접근 권한
| 권한 | 설명 |
|------|------|
| 알림 | 마케팅 알림, 배송 관련 알림 |
| 문자 | 본인 인증 및 당첨 문자 수신 |
| 카메라 | 프로필 사진, 상품 후기, QR코드 촬영 |

- 선택 접근 권한은 관련 기능 이용 시 동의가 필요하며, 미동의 시에도 해당 기능 외 서비스는 이용가능합니다.
- 해당 권한은 기능 이용 시, 팝업(모달) 창으로 접근 권한 요청함

### 버튼
- **앱 종료**: 선택 시 앱 종료
- **동의하고 계속**: 선택 시 온보딩 화면으로 이동

## SC-003: 온보딩 화면

**Swipe 제스처로 좌, 우로 화면 넘김 (3장 구성)**

온보딩 화면은 운영 협의에 따라 해당 프로세스가 아닌 앱 진입 후에 노출할 수도 있음.

### 컨셉 1: 블록픽 게임 플레이
- **제목**: "치열한 눈치싸움, 단 하나의 독점 블록"
- **설명**: "그리드 속 숨겨진 보물을 찾아보세요. 전략적으로 좌표를 선택하고 독점의 기쁨을 누리세요."

### 컨셉 2: 공정성과 투명성 강조
- **제목**: "조작 불가능한 100% 투명한 결과"
- **설명**: "모든 참여 내역이 블록체인에 암호화되서 보호되며, 어느 누구도 내가 참여한 게임의 좌표를 열어볼 수 없어요."

### 컨셉 3: 쇼핑몰 이용
- **제목**: "할인 혜택이 많은 쇼핑까지"
- **설명**: "다양한 상품을 쇼핑캐시로 할인받아 구입해보세요. 더 많은 제휴 상품으로 더 큰 혜택을 드립니다."

### 하단 요소
- **안내 문구**: "블록픽 일부 기능은 회원가입 및 로그인이 필요합니다."
- **로그인 하기 버튼**: 선택 시 로그인 화면으로 이동
- **앱 둘러보기 버튼**: 선택 시 홈 화면으로 이동

## SC-004: 로그인

### SC-004-01: 로그인 화면

#### 화면 구성
1. **이전 버튼**: 선택 시 이전 화면으로 이동
2. **App bar 텍스트**: "로그인 하기"
3. **이메일 입력 필드**
   - Placeholder: "이메일을 입력해 주세요."
   - 입력 중 유효성 검사: 이메일 형식 (@, . 포함) 확인
   - 오류:
     - 미입력: "이메일을 입력해 주세요."
     - 형식오류: "이메일 형식이 올바르지 않습니다."
4. **비밀번호 입력 필드**
   - Placeholder: "비밀번호를 입력해 주세요."
   - 입력 중 보안을 위해 *문자로 출력 → 보기 아이콘 선택 시 실제 표시
   - 오류:
     - 미입력: "비밀번호를 입력해주세요."
     - 불일치: "비밀번호를 다시 확인해 주세요 (#/5)." 문구 노출
5. **텍스트 버튼**
   - 회원가입: 선택 시 회원가입 화면으로 이동
   - 이메일 찾기: 선택 시 이메일 찾기 화면으로 이동
   - 비밀번호 찾기: 선택 시 비밀번호 찾기 화면으로 이동

### SC-004-02: 로그인 기능

#### 이메일 계정 로그인 버튼
- 이메일/비밀번호 입력 전에도 활성화
- 선택 시 네트워크 상태에 따라 로딩 애니메이션 표시
- 선택 시 홈 화면으로 이동

#### 간편로그인 계정 버튼
- 구글 계정으로 로그인
- 애플 계정으로 로그인
- 최초 로그인일 경우 회원가입 유도 Dialog 노출
- 협의에 따라 1~2개 추가 될 수 있음

**자동로그인은 서버에서 체크하며 UI에서 별도로 체크하지는 않음.**
**기본적으로 자동로그인이 된 상태이며, 로그아웃, 기기변경 할 경우 로그인 하기 화면을 보여줌.**

### 로그인 오류 Dialog

#### 비회원일 경우
```
┌─────────────────────────────────┐
│ Blockpick 회원 계정이 아니에요.    │
│ 다른 계정으로 로그인 하거나        │
│ 회원가입을 해주세요.              │
│                                 │
│     [취소]     [회원가입 하기]    │
└─────────────────────────────────┘
```

#### 비밀번호 5회 이상 실패 시
```
┌─────────────────────────────────┐
│ 비밀번호 5회 실패로 보안을 위해    │
│ 계정이 잠겼어요.                  │
│ 비밀버호 찾기를 이용해주세요.      │
│                                 │
│     [취소]     [비밀번호찾기]     │
└─────────────────────────────────┘
```

## SC-005: 회원가입

### SC-005-01: 회원가입 방법 선택

#### 화면 구성
1. **App bar 텍스트**: "회원가입"
2. **안내 문구**: "반가워요! Blockpick에서 게임을 시작해볼까요?"
3. **이메일 가입 버튼**: 선택 시 휴대폰 번호 인증 화면으로 이동
4. **구글 계정 가입 버튼**
   - 구글 Account 화면 출력 (Web view)
   - 필요한 정보 제공 동의 (이메일 계정, 프로필 사진)
   - 동의 완료 후 휴대폰 번호 인증 화면(SC-005-02)으로 이동
5. **애플 계정 가입 버튼**
   - 애플 Account 화면 출력 (Web view)
   - 필요한 정보 제공 동의 (이메일 계정, 프로필 사진)
   - 동의 완료 후 휴대폰 번호 인증 화면으로 이동

### SC-005-02: 휴대폰 번호 인증 (입력)

#### 화면 구성
1. **App bar 텍스트**: "휴대폰 번호 인증"
2. **안내 문구**: "회원가입을 위해 휴대폰 번호 인증이 필요해요."
3. **휴대폰 입력 필드**
   - 국가번호 선택: KOR(+82)
   - Placeholder: "숫자만 입력"
   - "-" 제외한 숫자만 입력 → 필드 선택시 숫자 키패드 노출
   - 입력 중 유효성 검사: 휴대폰 번호 자리수, 숫자만 입력 확인
   - 글로벌 서비스일 때, 앞에 국가번호 선택 옵션 추가 예정
   - 국가번호 양식: 영문 국가명 3자리 + 국가 번호
   - 오류:
     - 미입력: "휴대폰 번호를 입력해 주세요."
     - 형식오류: "숫자만 입력해 주세요."
4. **인증번호 전송 버튼**: 휴대폰 번호 자리수와 일치되면 활성화

### SC-005-03: 휴대폰 번호 인증 (인증코드 입력)

#### 화면 구성
1. **인증번호 입력 필드**
   - 인증번호 전송 버튼 선택 시 입력 필드 노출
   - Placeholder: "인증번호 6자리."
   - 숫자 6자리만 입력 가능
   - Android의 경우 SMS 권한 허용으로 자동 입력이 가능
   - 인증번호 전송 성공 시, 03:00 타이머 시작
2. **인증번호 재전송 버튼**
   - 비활성화된 버튼으로 "인증번호 재전송" 문구 출력
   - 인증번호 입력 필드에 입력되면 활성화
   - 재전송 버튼 선택 시, 타이머 초기화 및 인증 번호 재전송
   - 재전송 남발하는 이슈로 재전송 횟수 제한 (3회까지)
3. **이용 동의 선택**
   - 개인정보 수집 및 이용, 제3자 제공, 서비스 이용약관, 마케팅 수신 동의
   - 모두 동의 선택 시, 전체 항목이 선택됨
   - 동의 내용은 Web view로 새 창에서 출력됨
4. **인증 완료 버튼**
   - 플로팅 버튼으로 하단에 고정
   - 번호 인증, 개인정보 필수 동의 체크가 완료되면 활성화
   - 신규 회원이면 휴대폰 번호, 동의 내용을 임시 DB에 저장 후, 회원가입 완료될 때 회원 DB로 이전함
   - 선택 시 프로세스에 따라 다음 화면으로 이동:
     - 회원가입 → 회원가입 페이지
     - 이메일 찾기 → 이메일 찾기 페이지
     - 비밀번호 찾기 → 비밀번호 찾기 페이지
     - 회원 탈퇴 → 회원 탈퇴 페이지

### SC-005-04: 이메일/비밀번호 입력 (초기)

#### 화면 구성
1. **App bar 텍스트**: "회원가입"
2. **이메일 입력 필드**
   - 이메일 앞부분이 사용자 ID가 되며, 마이페이지에서 변경 가능
   - Placeholder: "이메일을 입력해 주세요."
   - 입력 중 유효성 검사: 이메일 형식 (@, . 포함) 확인
   - 오류:
     - 미입력: "이메일을 입력해 주세요."
     - 형식오류: "이메일 형식이 올바르지 않습니다."
3. **인증번호 전송 버튼**
   - 이메일 입력 전 비활성화 상태
   - 이메일 입력 후, 활성화 상태로 변경
   - 버튼 선택 시, 인증번호 입력 필드 노출
4. **비밀번호 입력 필드**
   - Placeholder: "문자,숫자,기호 조합 8자 이상"
   - 입력 중 보안을 위해 *문자로 출력 → 보기 아이콘 선택 시 실제 표시
   - 문자,숫자,기호 조합 8자 이상
   - 입력 중 유효성 검사: 비밀번호 생성 조건
   - 오류:
     - 미입력: "비밀번호를 입력해주세요."
     - 불일치: "문자,숫자,기호 조합 8자 이상으로 만들어주세요."
5. **비밀번호 확인 입력 필드**
   - Placeholder: "동일한 비밀번호를 입력해 주세요."
   - 입력 중 유효성 검사: 동일한 비밀번호 입력
   - 오류:
     - 미입력: "비밀번호를 입력해주세요."
     - 불일치: "동일한 비밀번호를 입력해 주세요."

#### 비밀번호 생성 규칙 안내
- 영문,숫자,특수문자 포함 8자 이상
- 동일하거나 연속되는 문자, 숫자 사용 금지
- 이메일, 휴대폰 번호 사용 금지

### SC-005-05: 이메일/비밀번호 입력 (완료)

#### 화면 구성
1. **인증번호 입력 필드**
   - 인증번호 전송 버튼 선택 시, 입력 필드 노출
   - Placeholder: "인증번호 6자리."
   - 숫자 6자리만 입력 가능
   - 인증번호 전송 성공 시, 03:00 타이머 시작
2. **인증번호 재전송 버튼**
   - 비활성화된 버튼으로 "인증번호 재전송" 문구 출력
   - 인증번호 입력 필드에 입력되면 활성화
   - 재전송 버튼 선택 시, 타이머 초기화 및 인증 번호 재전송
3. **가입 완료 버튼**
