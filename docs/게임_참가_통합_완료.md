# 게임 참가 플로우 통합 완료

**작성일**: 2025-11-04
**버전**: 1.0.0

---

## 🎯 개요

기존의 "2 blocks submitted!" 메시지가 표시되던 간단한 플로우를 **Toss 스타일 전체 화면 애니메이션**으로 교체했습니다.

이제 게임에서 블록을 선택하고 참가 버튼을 누르면:
1. ✨ 전체화면 로딩 오버레이 (그라데이션 + 회전 애니메이션)
2. 🔐 블록체인 지갑 생성/확인
3. 🔑 스마트 컨트랙트에서 암호화 키 요청
4. 🔒 좌표 AES-256 암호화
5. 📤 GraphQL Mutation으로 게임 참가
6. 🎉 성공/실패 결과 오버레이 (파티클 효과)

## 🎬 동작 플로우

### 사용자 관점

1. 게임 화면에서 블록 선택 (예: 2개)
2. 하단 바텀시트에서 "Select blocks (2/pick)" 버튼 클릭
3. 로그인 확인 (미로그인 시 로그인 다이얼로그)
4. **전체화면 로딩 오버레이** 표시
   - Blue → Purple 그라데이션
   - 회전하는 3단 원형 애니메이션
   - 🚀 로켓 아이콘
   - 5단계 진행 표시
5. 블록체인 트랜잭션 실행 (자동)
6. **결과 오버레이** 표시
   - ✅ 성공: 초록색 체크 아이콘 + 파티클 효과
   - ❌ 실패: 빨간색 X 아이콘 + 에러 메시지

### 기술적 플로우

```
사용자가 "Select blocks" 클릭
  ↓
SelectedBlocksSheet._handleJoinGame()
  ↓
fullGame에서 contractAddress, productId 추출
  ↓
GameJoinLoadingOverlay.show() ← 로딩 시작
  ↓
GameParticipationProvider.joinGame()
  ├─ 1. BlockchainWalletService: 지갑 생성/로드
  ├─ 2. SmartContractService: 암호화 키 요청 (Polygon Amoy)
  ├─ 3. CoordinateEncryptionService: AES-256 암호화
  ├─ 4. SHA-256: 지갑 주소 해시화 (익명성)
  └─ 5. GraphQL: joinGame Mutation 호출
  ↓
GameJoinLoadingOverlay.hide() ← 로딩 종료
  ↓
성공/실패 판단
  ↓
GameJoinResultOverlay.showSuccess() 또는 showError()
```

## 🔑 주요 데이터 흐름

### Contract Address
```dart
Game.onchainContractAddr → fullGame.onchainContractAddr
                          → GameParticipationProvider.joinGame()
                          → SmartContractService.requestEncryptionKey()
```

### Product ID
```dart
Game.gameProducts[0].id → fullGame.gameProducts.first.id
                        → GameParticipationProvider.joinGame()
                        → joinGame Mutation (selectedGameProductId)
```

### 좌표
```dart
selectedBlocks.first → (row, col)
                     → CoordinateEncryptionService.encryptCoordinate()
                     → coordCiphertext
                     → joinGame Mutation
```

## 🎨 애니메이션 효과

### 로딩 오버레이
- **배경**: Blue → Purple 그라데이션 (opacity 0.95)
- **외부 원**: 2초 360도 회전 (무한 반복)
- **중간 원**: 1.5초 역방향 회전 (무한 반복)
- **내부 원**: 고정
- **아이콘**: 로켓 🚀 (1초 스케일 1.0 → 1.1 왕복)
- **진행바**: Shimmer 효과

### 성공 오버레이
- **배경**: Green → Blue 그라데이션
- **아이콘**: ✅ Elastic 스케일 애니메이션 (0 → 1)
- **파티클**: 8방향 페이드아웃 + 스케일 (순차 실행)
- **흔들림**: 2Hz shake 효과

### 실패 오버레이
- **배경**: Red → Pink 그라데이션
- **아이콘**: ❌ X 아이콘
- **흔들림**: 4Hz shake 효과 (강함)

## 🧪 테스트 방법

### 방법 1: 실제 게임 화면에서 테스트

1. 앱 실행
2. 게임 화면 이동 (예: `/game/01a18547-64cc-4e9e-9816-3161f0278018`)
3. 그리드에서 블록 선택 (탭)
4. 하단 바텀시트에서 "Select blocks" 버튼 클릭
5. Toss 스타일 애니메이션 확인

### 방법 2: E2E 테스트 화면 (권장)

1. 앱 실행
2. `/test/game-join` 경로로 이동
3. 3가지 테스트 버튼 확인:
   - **테스트 1**: 기본 UI 버튼
   - **테스트 2**: 토스 스타일 애니메이션 ⭐ 권장
   - **테스트 3**: Provider 직접 호출
