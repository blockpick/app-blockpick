### 홈 주요 액션

- 배너 클릭 → 블록픽 상세
- 카드 클릭 → 블록픽 상세
- 검색 클릭 → 블록픽 검색
- 알림 클릭 → 알림함

# 15. 핵심 화면 연결 흐름

```
[홈]
  └→ [블록픽 상세]
        └→ [블록 선택]
              └→ [참여 결과]
                    ├→ [친구초대]
                    ├→ [광고 시청]
                    ├→ [미션 수행]
                    └→ [참여내역]

[블록픽]
  └→ [블록픽 상세]
        └→ [블록 선택]
              └→ [참여 결과]

[참여내역]
  └→ [참여 상세]
        ├→ [다시 참여하기]
        ├→ [친구초대]
        ├→ [광고 시청]
        └→ [미션 수행]

[친구초대]
  └→ [초대 실적 상세]

[마이]
  ├→ [알림함]
  ├→ [알림 설정]
  └→ [고객센터 / 정책]
```

# 16. 한 줄 정리

**유저 앱 와이어프레임은 `홈 → 블록픽 상세 → 블록 선택 → 참여 결과 → 재참여` 흐름을 중심으로 구성하고, 하단 탭은 `홈 / 블록픽 / 참여내역 / 친구초대 / 마이`로 운영하며, 알림은 상단 벨 아이콘과 마이 내부에서 처리한다.**
