# 블록픽 파트너 대시보드 IA

## 1차 MVP 기준

---

# 1. IA 설계 기준

## 1-1. 파트너 대시보드의 핵심 목적

파트너 대시보드는 아래 4가지를 가장 빠르게 할 수 있어야 한다.

1. **블록픽 생성**
2. **운영 중인 블록픽 관리**
3. **참여자 / 당첨자 / 리퍼럴 성과 확인**
4. **구독 / 브랜드 / 팀 설정 관리**

## 1-2. 핵심 설계 원칙

- 메뉴 구조는 **생성 → 운영 → 분석 → 설정** 흐름으로 간다.
- 파트너가 가장 자주 쓰는 기능은 상단이 아니라 **좌측 사이드바 상단**에 배치한다.
- 블록픽 단위 운영과 전체 계정 단위 운영을 구분한다.
- MVP에서는 너무 깊은 메뉴 구조보다 **2뎁스 중심**이 적합하다.

# 3. 파트너 대시보드 기본 레이아웃

## 3-1. 기본 구조

파트너 대시보드는 **웹 대시보드형 구조**를 기본으로 한다.

### 레이아웃 구성

- **좌측 사이드바**
    - 1차 메뉴 진입
- **상단 바**
    - 현재 워크스페이스/브랜드명
    - 검색
    - 알림
    - 도움말
    - 계정 메뉴
- **메인 콘텐츠 영역**
    - 리스트 / 상세 / 차트 / 설정 폼
- **우측 보조영역(선택)**
    - 팁, 최근 활동, 상태 요약

# 5. 메뉴별 목적 정의

---

## 5-1. 홈

### 목적

- 대시보드 전체 현황을 한눈에 보여주는 요약 화면
- 가장 중요한 KPI와 최근 운영 상태를 빠르게 확인

### 핵심 정보

- 총 방문 수
- 총 참여 수
- 무료 → 추가 참여 전환율
- 친구 초대 성과
- 광고 시청 수
- 진행 중 블록픽 수
- 최근 알림
- 빠른 실행 버튼

---

## 5-2. 블록픽

### 목적

- 블록픽 생성, 수정, 복제, 종료 등 **캠페인 단위 관리의 중심**

### 하위 메뉴 설명

### 전체 블록픽

- 생성한 전체 블록픽 리스트
- 상태/기간/성과를 함께 확인

### 새 블록픽 만들기

- 신규 블록픽 생성 Wizard 진입

### 진행중

- 현재 유저가 참여 가능한 블록픽만 조회

### 예약됨

- 발행 예정 상태의 블록픽 관리

### 종료됨

- 종료된 블록픽 및 결과 확인

### 임시저장

- 아직 발행하지 않은 초안 관리

---

## 5-3. 운영

### 목적

- 실제 참여자 운영, 당첨자 후처리, 리퍼럴/보상 운영을 담당하는 실무 메뉴

### 하위 메뉴 설명

### 참여자 관리

- 참여자 리스트
- 참여 횟수, 참여 경로, 상태 조회
- 검색/필터/다운로드

### 당첨자 관리

- 당첨자 리스트
- 지급 상태 관리
- 수령 정보 확인
- 후처리 메모

### 공유/리퍼럴 관리

- 공유 링크
- 초대 링크 구조
- 친구 초대 성과 확인
- 초대 보상 기준 관리

### 광고/미션 설정

- 광고 보상 참여 허용 여부
- 광고 횟수 제한
- 미션형 참여 조건 설정

---

## 5-4. 분석

### 목적

- 파트너가 돈 내고 계속 써야 할 이유를 보여주는 메뉴
- 구독 유지 및 상위 플랜 업셀의 핵심

### 하위 메뉴 설명

### 전체 성과

- 전체 계정 기준 KPI 요약

### 블록픽별 성과

- 각 블록픽 단위 성과 비교

### 친구 초대 성과

- 리퍼럴 링크 클릭/참여/보상 지급 성과

### 광고 성과

- 광고 시청 수, 완료율, 참여권 전환 성과

### 유입 채널 분석

- 링크, 캠페인, SNS 등 채널별 성과 분석

---

## 5-5. 브랜드

### 목적

- 파트너 브랜드 정체성을 블록픽 캠페인에 반영

### 하위 메뉴 설명

### 브랜드 기본정보

- 브랜드명
- 표시명
- 소개 문구
- 공식 URL

### 로고/컬러

- 로고 업로드
- 대표 색상 설정
- 썸네일 스타일 기초 설정

### 공유 문구

- 기본 공유 메시지
- 링크 공유 시 기본 문구
- SNS 공유용 문구

### 기본 유의사항

- 캠페인 공통 유의사항
- 경품/배송/CS 관련 기본 문구

---

## 5-6. 구독/결제

### 목적

- 현재 플랜, 사용량, 결제 상태, 업그레이드 관리를 담당

### 하위 메뉴 설명

### 현재 플랜

- 현재 사용 중인 요금제
- 포함 기능 요약

### 사용량

- 월 참여 수
- 생성 블록픽 수
- 동시 진행 수
- 팀 멤버 수

### 결제수단

- 카드 등록/변경
- 자동 결제 정보

### 청구 내역

- 월별 결제 이력
- 영수증/세금계산서 확인

### 플랜 변경

- 업그레이드 / 다운그레이드
- 추가 과금 옵션 선택

---

## 5-7. 팀

### 목적

- 파트너사 내부 실무자 협업 지원

### 하위 메뉴 설명

### 멤버 관리

- 대시보드 접근 멤버 목록
- 초대/제거

### 권한 관리

- 관리자
- 운영자
- 조회 전용 등 권한 구분

### 활동 로그

- 누가 어떤 블록픽을 수정했는지
- 주요 설정 변경 기록

---

## 5-8. 설정

### 목적

- 계정 운영의 기본값과 회사/CS/알림 관련 정보 관리

### 하위 메뉴 설명

### 사업자 정보

- 사업자명
- 사업자번호
- 국가
- 법인/개인사업자 정보

### CS 정보

- 고객 문의 이메일
- 운영 시간
- 기본 안내 문구

### 알림 설정

- 이메일 알림
- 운영 알림
- 성과 알림
- 결제 알림

### 계정 설정

- 비밀번호 변경
- 로그인 보안
- 계정 기본 설정

# 6. 블록픽 상세 운영 화면 IA

`블록픽` 메뉴 안에서 특정 블록픽을 클릭했을 때 들어가는 **블록픽 상세 운영 화면**은 별도 탭 구조가 필요해.

## 6-1. 블록픽 상세 내부 탭 구조

```
블록픽 상세
├── 개요
├── 설정
├── 참여자
├── 당첨자
├── 성과
├── 공유
└── 로그
```

---

## 6-2. 탭별 설명

### 개요

- 상태
- 기간
- 핵심 KPI
- 빠른 링크 복사
- 주요 경고/알림

### 설정

- 기본 정보
- 그리드 설정
- 참여 조건
- 보상 설정
- 공개 여부
- 발행/예약/종료

### 참여자

- 해당 블록픽 참여자 목록
- 참여 상태
- 추가 참여 상태

### 당첨자

- 당첨자 목록
- 지급 상태
- 수령 정보 확인

### 성과

- 방문/참여/전환/초대 성과
- 광고/미션 성과

### 공유

- 공유 링크
- 초대 링크
- 공유 문구
- 채널별 공유 상태

### 로그

- 수정 이력
- 상태 변경 이력
- 운영자 액션 기록

# 7. MVP 기준 우선순위 IA

MVP에서는 모든 메뉴를 한 번에 깊게 만들 필요는 없고,

우선순위를 나누는 게 좋다.

## 7-1. 1순위

- 홈
- 블록픽 > 전체 블록픽
- 블록픽 > 새 블록픽 만들기
- 운영 > 당첨자 관리
- 분석 > 전체 성과
- 구독/결제 > 현재 플랜 / 사용량 / 플랜 변경

## 7-2. 2순위

- 운영 > 참여자 관리
- 운영 > 공유/리퍼럴 관리
- 분석 > 블록픽별 성과
- 브랜드 > 로고/컬러
- 설정 > 사업자 정보 / CS 정보

## 7-3. 3순위

- 운영 > 광고/미션 설정
- 분석 > 광고 성과 / 유입 채널 분석
- 팀 > 권한 관리 / 활동 로그

---

# 8. MVP 기준 가장 중요한 사용자 흐름

## 8-1. 생성 흐름

홈 → 새 블록픽 만들기 → 설정 → 발행

## 8-2. 운영 흐름

홈 → 진행중 블록픽 확인 → 블록픽 상세 → 참여자/당첨자 확인

## 8-3. 성과 확인 흐름

홈 → 전체 성과 또는 블록픽별 성과 → 리퍼럴/전환 확인

## 8-4. 과금 흐름

홈 또는 구독/결제 → 사용량 확인 → 플랜 업그레이드

# 9. 파트너 대시보드 IA 한 줄 정의

**파트너 대시보드 IA는 `홈 / 블록픽 / 운영 / 분석 / 브랜드 / 구독·결제 / 팀 / 설정`의 구조를 기본으로 하며, 파트너가 블록픽을 생성하고 운영하고 성과를 확인하고 반복적으로 구독을 유지하도록 설계한다.**
