# 게임 참가 기능 구현 가이드

## 📋 개요

이 문서는 Blockpick 게임 참가 기능을 Flutter UI에 통합하는 방법을 설명합니다.

구현된 기능:
- ✅ 블록체인 지갑 자동 생성 및 관리
- ✅ **서버 가스비 대납 방식** (GraphQL `requestEncryptionKey`)
- ✅ 좌표 AES-256 암호화
- ✅ 지갑 주소 해시화 (익명성 강화)
- ✅ joinGame GraphQL Mutation 호출
- ✅ 사용자는 가스비 불필요 (MATIC 불필요)

## 🎨 새로운 UI 컴포넌트 (토스 스타일!)

### 생성된 위젯들

1. **`GameJoinLoadingOverlay`** - 전체화면 로딩 오버레이
   - 토스 앱처럼 멋진 gradient 배경
   - 회전하는 로켓 아이콘 애니메이션
   - 5단계 진행 표시
   - 실시간 진행률 바

2. **`GameJoinResultOverlay`** - 성공/실패 결과 화면
   - 성공 시: 초록색 그라데이션 + 체크 아이콘 + 파티클 효과
   - 실패 시: 빨간색 그라데이션 + X 아이콘 + 흔들림 애니메이션
   - Entry ID, TX Hash 복사 기능
   - 재시도 버튼

3. **`GameJoinButton`** - 게임 참가 버튼
   - 그라데이션 배경 + shimmer 효과
   - 호버/클릭 애니메이션
   - 자동 로딩 오버레이 표시

4. **`GameJoinFloatingButton`** - 플로팅 참가 버튼
   - 화면 하단 고정
   - 좌표 선택 시 자동으로 슬라이드 인
   - 선택 해제 시 자동으로 숨김

5. **`GameJoinInfoCard`** - 게임 참가 정보 카드
   - 선택한 좌표 표시
   - 참가 비용, 참가자 수 표시
   - 아이콘 + 색상 구분

**이게 전부입니다!** 🎉

4. 확인 버튼 누르면 onSuccess 콜백 실행

### 2. 수동 제어 (고급)

직접 오버레이를 제어하고 싶다면:

```dart
import '../features/game/widgets/game_join_loading_overlay.dart';
import '../features/game/widgets/game_join_result_overlay.dart';

Future<void> handleJoinGame() async {
  try {
    // 1. 로딩 오버레이 표시
    GameJoinLoadingOverlay.show(context);

    // 2. 게임 참가 로직
    final result = await ref
        .read(gameParticipationProvider.notifier)
        .joinGame(...);

    // 3. 로딩 숨김
    GameJoinLoadingOverlay.hide(context);

    await Future.delayed(const Duration(milliseconds: 300));

    // 4. 결과 표시
    if (result.success) {
      GameJoinResultOverlay.showSuccess(
        context,
        entryId: result.entryId,
        txHash: result.txHash,
        onConfirm: () {
          print('성공!');
        },
      );
    } else {
      GameJoinResultOverlay.showError(
        context,
        errorMessage: result.message,
        onRetry: () {
          handleJoinGame(); // 재시도
        },
      );
    }
  } catch (e) {
    GameJoinLoadingOverlay.hide(context);
    // 에러 처리
  }
}
```

### 3. 커스텀 버튼 + 애니메이션

기존 버튼에 애니메이션만 추가하고 싶다면:

```dart
import 'package:flutter/material.dart';
import 'package:flutter_riverpod/flutter_riverpod.dart';
import '../providers/game_participation_provider.dart';

class GameJoinButton extends ConsumerWidget {
  final String gameId;
  final String selectedGameProductId;
  final int selectedRow;
  final int selectedCol;
  final String contractAddress;

  const GameJoinButton({
    Key? key,
    required this.gameId,
    required this.selectedGameProductId,
    required this.selectedRow,
    required this.selectedCol,
    required this.contractAddress,
  }) : super(key: key);

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    // 참가 상태 감시
    final participationState = ref.watch(gameParticipationProvider);

    return ElevatedButton(
      onPressed: participationState.isLoading
          ? null
          : () async {
              try {
                // 게임 참가 실행
                final result = await ref
                    .read(gameParticipationProvider.notifier)
                    .joinGame(
                      gameId: gameId,
                      selectedGameProductId: selectedGameProductId,
                      row: selectedRow,
                      col: selectedCol,
                      contractAddress: contractAddress,
                    );

                if (result.success) {
                  // 성공 처리
                  ScaffoldMessenger.of(context).showSnackBar(
                    SnackBar(
                      content: Text('게임 참가 성공! Entry ID: ${result.entryId}'),
                      backgroundColor: Colors.green,
                    ),
                  );

                  // 게임 참가 완료 화면으로 이동
                  // Navigator.push(...);
                } else {
                  // 실패 처리
                  ScaffoldMessenger.of(context).showSnackBar(
                    SnackBar(
                      content: Text('게임 참가 실패: ${result.message}'),
                      backgroundColor: Colors.red,
                    ),
                  );
                }
              } catch (e) {
                // 에러 처리
                ScaffoldMessenger.of(context).showSnackBar(
                  SnackBar(
                    content: Text('에러 발생: $e'),
                    backgroundColor: Colors.red,
                  ),
                );
              }
            },
      child: participationState.isLoading
          ? const CircularProgressIndicator()
          : const Text('게임 참가하기'),
    );
  }
}
```

## 📊 프로세스 흐름도

```
[사용자] 좌표 선택
    ↓
[앱] joinGame() 호출
    ↓
[1] 블록체인 지갑 확인/생성
    ↓
[2] 스마트 컨트랙트에 암호화 키 요청
    ├─ TX 전송
    ├─ TX 확인 대기
    └─ 이벤트에서 키 추출
    ↓
[3] 좌표 암호화 (AES-256)
    ↓
[4] 지갑 주소 해시화 (SHA-256)
    ↓
[5] joinGame Mutation 호출
    ├─ gameId
    ├─ selectedGameProductId
    ├─ coordCiphertext (암호화된 좌표)
    ├─ signerWallet (해시된 지갑)
    └─ contractAddress
    ↓
[백엔드] 검증 및 저장
    ├─ 중복 체크
    ├─ 게임 상태 확인
    └─ 참가 기록 저장
    ↓
[응답] JoinGameResponse
    ├─ success
    ├─ entryId
    └─ status
    ↓
[UI] 결과 표시
```

## ❓ FAQ

### Q1. 지갑이 삭제되면 이전 참가 기록은 어떻게 되나요?

A: 백엔드에는 해시된 지갑 주소만 저장되므로, 지갑을 삭제하면 이전 참가 기록을 연결할 수 없습니다. 사용자가 지갑을 백업하지 않으면 복구할 수 없습니다.

### Q2. 한 게임에 여러 번 참가할 수 있나요?

A: 게임 설정에 따라 다릅니다. `maxEntriesPerUser` 필드를 확인하세요.

### Q3. 트랜잭션이 실패하면 어떻게 되나요?

A: 스마트 컨트랙트 트랜잭션이 실패하면 전체 프로세스가 중단되고 에러가 반환됩니다. 사용자에게 재시도를 안내하세요.

### Q4. 백엔드에서 좌표를 복호화할 수 있나요?

A: **아니요**. 암호화 키는 스마트 컨트랙트에서 생성되며, 사용자만 가지고 있습니다. 백엔드는 암호화된 좌표만 저장합니다.

### Q5. 메인넷 배포 시 무엇을 변경해야 하나요?

A: `smart_contract_service.dart`에서:
- RPC URL을 메인넷으로 변경
- Chain ID를 메인넷으로 변경 (Polygon: 137)
- 가스비 처리 로직 추가
- 컨트랙트 주소를 메인넷 주소로 변경
