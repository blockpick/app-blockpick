## 1. 비전 / 1차 MVP 목표

### 1-1. 서비스 정의
**파트너사가 직접 그리드형 이벤트 판을 생성·운영하고, 유저는 무료 1회 참여 + 친구초대/광고/미션/포인트로 추가 참여하는 블록체인 기반 참여형 리퍼럴 SaaS 플랫폼.**

### 1-2. 1차 MVP 성공 기준
- 파트너 1+가 블록픽 캠페인을 직접 생성·종료까지 운영 가능
- 유저가 5탭 IA로 탐색·참여·재참여·당첨확인까지 완주 가능
- 포인트 적립(광고/미션/출석/미니게임/오퍼월) → 포인트 차감(블록픽 참여) 흐름 정상 작동
- Admin이 파트너 승인·블록픽 검수·신고/제재까지 처리 가능
- 결제(파트너 구독), 푸시, 광고, 공유 외부 통합 검증 완료
- 블록체인(Ronin Mainnet) 트랜잭션 안정 운영

### 1-3. 1차 MVP 제외 (Phase 2)
- NFT 보상 / 크로스체인 / 토큰 이코노미
- 다국어 풀 지원 (한국어/영어 우선)
- 고급 분석 (코호트, 퍼널) — 기본 KPI만
- 멀티 리전
