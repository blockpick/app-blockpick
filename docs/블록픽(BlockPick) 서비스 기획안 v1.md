### MVP 기준 블록체인 기반 서비스 기획

# 2. 서비스 정의

## 2-1. 한 줄 정의

**블록픽은 파트너사가 직접 그리드형 이벤트 판을 생성하고, 유저는 무료 참여와 친구 초대/광고 시청/미션 수행을 통해 추가 기회를 얻는 블록체인 기반 참여형 리퍼럴 SaaS 플랫폼이다.**

## 2-2. 서비스 핵심 개념

- 하나의 **블록픽 판**은 하나의 **프로모션 캠페인**이다.
- 파트너사는 직접 판을 만들고 운영한다.
- 유저는 각 판마다 기본 1회 무료로 참여할 수 있다.
- 유저는 친구 초대, 광고 시청, 미션 수행을 통해 추가 참여 기회를 획득한다.
- 블록픽은 단순 이벤트 툴이 아니라, **유입·확산·전환을 동시에 만드는 블록체인 기반 SaaS 도구**다.

# 3. 서비스 방향 재정의

## 3-1. 유지하는 요소

- 그리드 기반 블록 선택 UX
- 직관적이고 가벼운 참여 방식
- 친구와 공유하고 재참여를 유도하는 구조
- 쿠폰/경품/혜택과 결합 가능한 이벤트 형태
- 블록체인 기반의 신뢰 구조

## 3-2. 새롭게 정의하는 요소

- 블록픽은 자체 게임 서비스가 아니라 **파트너 운영형 프로모션 SaaS**
- 파트너사는 구독형 요금제를 통해 블록픽을 생성·운영
- 경품/배송/CS/법적 책임은 파트너사 책임
- 유저의 추가 참여는 행동 기반으로 획득
- 플랫폼은 파트너에게 **운영도구, 리퍼럴 추적, 데이터 분석, 관리 기능**을 제공

# 4. 서비스 목표

## 4-1. 파트너 관점 목표

- 이벤트 운영을 쉽게 만들기
- 친구 초대 기반 확산 유도
- 회원가입/앱설치/방문/구매 등 행동 전환 유도
- 데이터 기반으로 이벤트 성과를 확인 가능하게 만들기
- 반복 운영 가능한 SaaS 도구로 정착시키기

## 4-2. 유저 관점 목표

- 누구나 쉽게 무료로 참여 가능
- 참여 자체가 재미있고 가벼워야 함
- 행동 수행을 통해 추가 기회를 얻는 구조 제공
- 친구와 함께 참여하고 공유하게 만들기

## 4-3. 플랫폼 관점 목표

- 블록픽을 구독형 SaaS로 정착
- 파트너 반복 운영 수요 확보
- 광고/리퍼럴/미션 기반 BM 확장
- 블록체인 기반 서비스로서 신뢰성과 차별성 유지

# 6. 블록픽의 서비스 본질

## 6-1. 블록픽 판 = 하나의 프로모션 캠페인

예시:

- 쇼핑몰 할인쿠폰 블록픽
- 앱 설치 유도형 이벤트 블록픽
- 브랜드 런칭 기념 경품 블록픽
- 오프라인 매장 방문 유도형 QR 이벤트 블록픽

즉, 블록픽 판은 단순한 게임판이 아니라

**브랜드가 운영하는 리퍼럴/참여형 프로모션 단위**다.

## 6-2. 블록체인 기반 서비스로서의 의미

블록픽은 SaaS 운영 기능 자체는 오프체인 백오피스로 제공하되,

서비스의 기본 방향과 신뢰 구조는 **블록체인 기반**으로 유지한다.

즉,

- 파트너 관리
- 구독/결제
- 판 생성/운영
- 친구 초대/광고/미션
- 통계/대시보드

와 같은 기능은 SaaS 영역에서 운영되며,

블록픽 서비스 전체는

**블록체인을 기반으로 한 신뢰 가능한 프로모션 서비스**라는 포지션을 유지한다.

# 8. 파트너 SaaS 구독 구조

# 10. 유저 참여 구조

## 10-1. 기본 참여 규칙

## 10-2. 추가 참여 획득 방식

- 친구 초대 성공
- 광고 시청 완료

### 확장형

- 회원가입 완료
- 앱 설치 완료
- 카카오채널 추가
- 뉴스레터 구독
- 특정 페이지 방문
- 장바구니 담기
- 오프라인 QR 인증

# 11. 유저 흐름

## 11-1. 기본 참여 흐름

1. 유저가 블록픽 판 진입
2. 이벤트/혜택/참여 조건 확인
3. 무료 1회 참여
4. 블록 선택
5. 결과 확인
6. 추가 참여가 필요하면 행동 수행
7. 추가 참여권 획득 후 재참여

## 11-2. 친구 초대 흐름

1. 유저가 개인 초대 링크 발급
2. 친구가 링크를 통해 유입
3. 친구가 최소 조건 충족
4. 기존 유저에게 추가 참여권 지급

### 권장 최소 조건

- 친구 첫 참여 완료
- 친구 가입 완료
- 친구 인증 완료

## 11-3. 광고 시청 흐름

1. 유저가 광고 시청 선택
2. 보상형 광고 완료
3. 추가 참여권 지급

### 권장 정책

- 판당 광고 시청 제한
- 일일 광고 시청 제한
- 반복 시청 기반 어뷰징 방지

# 12. 보상 구조 제안

## 12-1. 기본 보상

- 구독 신청
- 채널 추가
- 상품 페이지 방문
- 장바구니 담기
- 오프라인 방문 인증

# 13. 결과 처리 방향

MVP 기준 블록픽은 **블록체인 기반 서비스 방향을 유지**하되,

유저 참여 경험과 파트너 운영 흐름이 자연스럽게 이어지는 구조를 우선 설계한다.

즉, 본 기획의 핵심은 다음이다.

- 유저가 쉽게 참여할 수 있어야 함
- 추가 참여 유도가 자연스러워야 함
- 파트너가 성과를 관리할 수 있어야 함
- 서비스는 블록체인 기반이라는 정체성을 유지해야 함

결과 처리 방식에 대한 세부 구현은

운영 정책, 기술 구조, 향후 고도화 방향에 따라 단계적으로 정리할 수 있다.

# 18. 최종 정리

블록픽의 MVP는

**블록체인 기반 서비스 방향을 유지하면서, 파트너가 직접 운영하는 리퍼럴 SaaS형 참여 프로모션 플랫폼**으로 정리할 수 있다.

핵심은 다음이다.

- 블록픽 판 = 파트너 프로모션 캠페인
- 유저는 무료 1회 + 행동 기반 추가 참여
- 파트너는 구독형으로 운영
- 경품/배송/CS 책임은 파트너
- 플랫폼은 리퍼럴, 광고, 미션, 분석, 운영 기능 제공
- 서비스 정체성은 블록체인 기반으로 유지
