## 1.1 메인 홈 (게임 탐색)

### 화면 목적
사용자가 다양한 타입의 럭키드로우 게임을 탐색하고 참여할 게임을 선택하는 첫 번째 진입점입니다.

### 주요 UI 구성

#### 상단 탭바 (4개)
- **DAILY**: 매일 진행되는 일일 게임
- **SELECT**: 선택형 게임 (사용자가 블록을 선택)
- **VIBE**: 테마/분위기 기반 게임
- **OPTIMAL**: 최적가 입찰 게임

#### 하단 네비게이션 (6개)
- HOME: 홈 피드
- My Pick: 내 참여 내역
- PICK: 게임 목록 (현재 화면)
- Winners: 당첨자 발표
- MALL: 쇼핑몰
- MY: 마이페이지

### 사용자 시나리오

#### 1. 앱 최초 실행
**사용자 행동**: 앱을 켠다
**화면 반응**:
- 기본적으로 PICK 탭이 선택되어 있음
- DAILY 탭이 활성화 상태 (파란색 인디케이터)
- DAILY 타입 게임 목록이 자동으로 로드됨

**비즈니스 의도**: 사용자에게 가장 접근하기 쉬운 "일일 게임"을 먼저 노출하여 참여율을 높임

#### 2. SELECT 탭 선택
**사용자 행동**: SELECT 탭을 터치
**화면 반응**:
- SELECT 탭이 파란색으로 활성화
- 하단 인디케이터가 SELECT로 이동 (애니메이션)
- SELECT 타입 게임 목록이 로드됨 (좌/우 슬라이드 전환)

**비즈니스 의도**: 사용자가 직접 블록을 선택하는 게임 타입을 제공하여 참여 재미 증대

#### 3. OPTIMAL 탭 선택
**사용자 행동**: OPTIMAL 탭을 터치
**화면 반응**:
- 최적가 게임 목록이 로드됨
- 다른 탭과 다른 가로 카드 레이아웃으로 표시
- 입찰 가능한 가격 범위가 강조됨

**비즈니스 의도**: 사용자가 원하는 가격대를 입력하는 "입찰형" 게임 제공

## 1.2 게임 목록

### 화면 목적
선택한 게임 타입(DAILY/SELECT/VIBE)의 게임들을 필터링/정렬하여 보여주고, 사용자가 참여할 게임을 선택하도록 유도합니다.

### 주요 UI 구성

#### 상단 배너
- Purple → Blue 그라데이션 배경
- 슬로건: "PICK YOUR PRIZE, MAKE IT YOURS"
- 시각적 임팩트를 주어 브랜드 아이덴티티 강화

#### 필터 바
- **카테고리 필터** (5개): ALL / Digital / Fashion / Gift / Food
- **정렬 옵션** (4개):
  - Most Popular (인기순)
  - Newest (최신순)
  - Ending Soon (마감임박순)
  - Price Low to High (저가순)
- **게임 개수**: 현재 필터링된 게임 수 표시 (예: "12 games")

#### 게임 카드 그리드
- 2열 그리드 레이아웃
- 각 카드에 다음 정보 표시:
  - **상품 이미지** (16:9 비율)
  - **게임 상태 배지**: Active(녹색) / Drawing(보라색) / Ended(회색)
  - **게임 타입 배지**: Daily(핑크) / Select(보라) / Vibe(파랑)
  - **게임 제목**
  - **참가자 수** (👥 아이콘)
  - **총 블록 수** (📊 아이콘, K/M 포맷)
  - **필요 Pick 수** (🎯 아이콘)
  - **당첨자 수** (🏆 아이콘)
  - **가격**: 원가 (취소선) + 현재가 (파란색 강조)
  - **남은 시간** (⏰ 아이콘, 빨간색)

### 사용자 시나리오

#### 1. 게임 목록 최초 진입
**사용자 행동**: DAILY 탭을 선택
**화면 반응**:
- 로딩 인디케이터 표시 (파란색 원형)
- 서버에서 게임 데이터를 가져옴
- 게임 카드 그리드를 표시
- 필터 바에 "12 games" 표시

**비즈니스 의도**: 사용자에게 현재 참여 가능한 게임의 전체 현황을 빠르게 파악시킴

#### 2. Digital 카테고리 필터 선택
**사용자 행동**: Digital 필터 칩을 터치
**화면 반응**:
- Digital 칩이 파란색으로 변경 (선택 상태)
- ALL 칩이 흰색으로 변경 (선택 해제)
- Digital 카테고리 게임만 필터링되어 표시
- 게임 개수가 "5 games"로 업데이트

**비즈니스 의도**: 사용자가 관심 있는 상품 카테고리를 빠르게 찾도록 지원

#### 3. "Ending Soon" 정렬 선택
**사용자 행동**: 정렬 드롭다운을 터치 → "Ending Soon" 선택
**화면 반응**:
- 드롭다운 라벨이 "Ending Soon"으로 변경
- 게임 목록이 마감 임박 순으로 재정렬
- 애니메이션과 함께 카드 순서가 변경됨

**비즈니스 의도**: 마감이 임박한 게임을 우선 노출하여 참여 전환율을 높임 (긴급성 활용)

#### 4. 게임 카드 클릭
**사용자 행동**: 관심 있는 게임 카드를 터치
**화면 반응**:
- 게임 플레이 화면(GameScreen)으로 이동
- 터치 피드백 애니메이션 (스케일 효과)

**비즈니스 의도**: 사용자를 게임 참여 단계로 유도

#### 5. 빈 결과 상태
**사용자 상황**: Fashion 카테고리를 선택했는데 게임이 없음
**화면 반응**:
- 중앙에 회색 📥 아이콘 표시
- "No games found" 메시지
- "Try changing your filters" 안내 메시지

**비즈니스 의도**: 사용자가 다른 필터를 시도하도록 유도하여 이탈 방지

#### 6. 에러 발생
**사용자 상황**: 네트워크 오류로 게임 로드 실패
**화면 반응**:
- 빨간색 ⚠️ 아이콘 표시
- "Error loading games" 메시지
- 에러 상세 내용 표시
- 파란색 "Retry" 버튼 제공

**사용자 액션**: Retry 버튼 터치
**화면 반응**: 게임 데이터를 다시 요청하고 로딩 인디케이터 표시

**비즈니스 의도**: 에러 상황에서도 사용자가 쉽게 재시도할 수 있도록 지원

## 1.3 게임 플레이 화면

### 화면 목적
사용자가 대형 그리드에서 원하는 블록을 선택하여 게임에 참여하는 핵심 상호작용 화면입니다.
**BlockPick의 가장 차별화된 UX**가 적용된 화면입니다.

### 주요 UI 구성

#### 1. Pick HUD (좌측 상단)
- 현재 선택된 블록 수 / 최대 선택 가능 수 표시
- 예: "3/5 picks"
- 실시간 업데이트

#### 2. 미니맵 (우측 상단)
- 전체 그리드의 축소판 표시
- 현재 보고 있는 뷰포트 위치를 흰색 박스로 표시
- 미니맵을 터치하면 해당 위치로 이동 (애니메이션)

#### 3. 게임 그리드 (중앙)
- 예: 1000x1000 크기의 대형 그리드
- 각 셀은 블록을 나타냄
- 사용자가 선택한 블록은 파란색 테두리로 강조
- 줌/팬(확대/이동) 제스처 지원

#### 4. 줌 컨트롤 (우측 하단)
- **+ 버튼**: 확대
- **- 버튼**: 축소
- 버튼 스타일: 흰색 원형, 그림자 효과

#### 5. 선택된 블록 바텀시트 (하단)
- 블록을 1개 이상 선택하면 자동으로 나타남
- 선택된 블록 목록을 카드 형태로 표시
- "CLEAR" 버튼: 모든 선택 취소
- "Select blocks (3/5 picks)" 버튼: 게임 참가 제출

#### 6. 섹션 오버레이
- 그리드를 3x3 구역으로 나누어 라벨 표시 (예: "A1", "B2", "C3")
- 사용자가 현재 어느 구역을 보고 있는지 직관적으로 표시

### 차별화된 UX 요소

#### LOD (Level of Detail) 시스템
- **확대 시 (고줌)**: 개별 셀 경계선, 셀 번호 표시 → 정확한 선택 가능
- **중간 줌**: 경계선만 표시
- **축소 시 (저줌)**: 경계선 숨김, 성능 최적화 → 전체 조망 가능

**비즈니스 의도**: 대형 그리드(수백만 블록)에서도 부드러운 성능 제공

#### 마커 시스템 (계층적 정보 표시)
- **레벨 1 (고줌)**: 개별 블록 마커 (작은 점)
- **레벨 2 (중줌)**: 클러스터 마커 (여러 블록을 그룹화, 숫자 표시)
- **레벨 3 (저줌)**: 섹션 마커 (큰 영역 그룹화)

**비즈니스 의도**: 사용자가 줌 레벨에 관계없이 중요한 정보를 놓치지 않도록 지원

### 사용자 시나리오

#### 1. 게임 화면 최초 진입
**사용자 행동**: 게임 카드를 터치하여 게임 화면에 진입
**화면 반응**:
1. 로딩 인디케이터 표시
2. 서버에서 게임 데이터 로드 (그리드 크기, 게임 정보 등)
3. 그리드 중앙을 화면 중앙에 배치
4. 초기 줌 레벨을 "선택하기 좋은 레벨"로 설정
5. 미니맵 표시
6. Pick HUD에 "0/5 picks" 표시
7. 줌 컨트롤 버튼 표시

**비즈니스 의도**: 사용자가 처음 진입 시 게임을 이해하고 바로 참여할 수 있도록 최적의 뷰로 시작

#### 2. 블록 선택
**사용자 행동**: 그리드의 특정 셀을 터치
**화면 반응**:
1. 터치한 블록에 파란색 테두리 표시
2. Pick HUD가 "1/5 picks"로 업데이트
3. 하단에 바텀시트가 슬라이드 업 (40% 높이)
4. 바텀시트에 선택된 블록 정보 표시:
   - 블록 좌표 (예: "Row 123, Col 456")
   - 삭제 버튼 (X)

**비즈니스 의도**: 사용자가 선택한 블록을 즉시 확인하고 관리할 수 있도록 지원

#### 3. 추가 블록 선택 (최대 5개)
**사용자 행동**: 다른 셀을 연속으로 터치 (2개, 3개, 4개, 5개)
**화면 반응**:
- 각 블록에 파란색 테두리 추가
- Pick HUD가 "2/5", "3/5", "4/5", "5/5"로 업데이트
- 바텀시트에 선택된 블록 목록이 추가됨 (스크롤 가능)

#### 4. 최대 선택 수 초과 시도
**사용자 행동**: 이미 5개를 선택한 상태에서 6번째 블록을 터치
**화면 반응**:
- 선택이 거부됨
- 빨간색 스낵바 표시: "최대 5개까지 선택 가능합니다"

**비즈니스 의도**: 게임 규칙을 명확히 전달하고 사용자 실수 방지

#### 5. 블록 선택 해제
**사용자 행동**: 이미 선택한 블록을 다시 터치 (또는 바텀시트에서 X 버튼 클릭)
**화면 반응**:
- 블록의 파란색 테두리 제거
- Pick HUD가 "4/5"로 업데이트
- 바텀시트에서 해당 블록 제거

#### 6. 모든 선택 취소
**사용자 행동**: 바텀시트의 "CLEAR" 버튼 터치
**화면 반응**:
- 모든 블록의 파란색 테두리 제거
- Pick HUD가 "0/5"로 리셋
- 바텀시트가 사라짐 (슬라이드 다운)

**비즈니스 의도**: 사용자가 선택을 처음부터 다시 시작할 수 있도록 지원

#### 7. 줌 인 (확대)
**사용자 행동**: 우측 하단 "+" 버튼 터치
**화면 반응**:
- 그리드가 확대됨 (뷰포트 중심 기준)
- 개별 셀 경계선이 표시됨
- 셀 번호가 표시됨 (LOD 시스템)
- 미니맵의 뷰포트 박스가 축소됨 (확대 중임을 나타냄)

**비즈니스 의도**: 사용자가 정확한 블록을 선택할 수 있도록 세밀한 뷰 제공

#### 8. 최대 줌 레벨에서 줌 인 시도
**사용자 행동**: 최대 확대 상태에서 "+" 버튼 터치
**화면 반응**:
- 줌 레벨 변경 없음
- 스낵바 표시: "최대 확대입니다"

#### 9. 줌 아웃 (축소)
**사용자 행동**: 우측 하단 "-" 버튼 터치
**화면 반응**:
- 그리드가 축소됨
- 셀 경계선이 사라짐 (LOD 시스템)
- 더 넓은 영역을 볼 수 있음
- 미니맵의 뷰포트 박스가 확대됨

**비즈니스 의도**: 사용자가 전체 그리드를 조망하며 전략적으로 위치를 선택할 수 있도록 지원

#### 10. 그리드 드래그 (이동)
**사용자 행동**: 그리드 위에서 손가락으로 드래그
**화면 반응**:
- 그리드가 실시간으로 이동
- 섹션 라벨이 실시간으로 업데이트 (예: "A1" → "B2")
- 미니맵의 뷰포트 박스가 이동

**비즈니스 의도**: 직관적인 네비게이션으로 대형 그리드 탐색 경험 개선

#### 11. 미니맵 터치 (빠른 이동)
**사용자 행동**: 미니맵의 특정 위치를 터치
**화면 반응**:
- 터치한 위치로 그리드가 부드럽게 이동 (애니메이션)
- 미니맵의 뷰포트 박스가 해당 위치로 이동

**비즈니스 의도**: 사용자가 그리드의 먼 위치로 빠르게 이동할 수 있도록 지원 (UX 효율성)

#### 12. 바텀시트에서 블록 카드 터치
**사용자 행동**: 바텀시트의 선택된 블록 카드를 터치
**화면 반응**:
- 해당 블록 위치로 그리드가 이동 (애니메이션)
- 해당 블록이 화면 중앙에 오도록 줌 레벨 조정
- 블록이 포커스 상태로 강조됨 (테두리 깜빡임)

**비즈니스 의도**: 사용자가 선택한 블록의 위치를 쉽게 재확인할 수 있도록 지원

## 1.4 게임 참가 프로세스

### 화면 목적
사용자가 블록을 선택한 후 "게임 참가" 버튼을 눌렀을 때 실행되는 **블록체인 기반 참가 프로세스**입니다.
**Toss 스타일의 전체화면 애니메이션**으로 구현되어 프리미엄 UX를 제공합니다.

### 프로세스 단계

#### 1단계: 로그인 확인
**사용자 행동**: 바텀시트의 "Select blocks (3/5 picks)" 버튼 터치
**화면 반응**:
- 로그인 상태 확인
- 비로그인 시: 로그인 다이얼로그 표시

**비즈니스 의도**: 게임 참가 전 회원 확인

#### 2단계: 로딩 오버레이 표시
**화면 반응**:
- 전체화면 오버레이가 페이드 인 (0.95 투명도)
- Blue → Purple 그라데이션 배경
- 중앙에 회전하는 3단 원형 애니메이션
  - 외부 원: 2초 360도 회전
  - 중간 원: 1.5초 역방향 회전
  - 내부 원: 고정
- 중앙에 🚀 로켓 아이콘 (스케일 애니메이션)
- "Processing your entry..." 메시지
- 5단계 진행 표시:
  1. "Creating blockchain wallet..."
  2. "Requesting encryption key..."
  3. "Encrypting coordinates..."
  4. "Hashing wallet address..."
  5. "Submitting to blockchain..."

**비즈니스 의도**: 복잡한 블록체인 프로세스를 시각적으로 표현하여 사용자 신뢰 구축

#### 3단계: 블록체인 처리 (백엔드)
1. **지갑 생성/로드**: 사용자 전용 블록체인 지갑 확인/생성
2. **암호화 키 요청**: Polygon Amoy Testnet 스마트 컨트랙트에서 암호화 키 요청
3. **좌표 암호화**: AES-256으로 선택한 블록 좌표 암호화
4. **주소 해시화**: SHA-256으로 지갑 주소 해시화 (익명성 보장)
5. **GraphQL Mutation**: joinGame API 호출

**비즈니스 의도**:
- 블록체인 기술로 투명성과 공정성 보장
- 암호화로 사용자 선택 보호 (다른 사용자가 볼 수 없음)
- 해시화로 익명성 보장

#### 4단계: 성공 오버레이
**화면 반응** (성공 시):
- 로딩 오버레이가 페이드 아웃
- Green → Blue 그라데이션 배경
- 중앙에 ✅ 체크 아이콘 (Elastic 스케일 애니메이션)
- 8방향 파티클 효과 (페이드아웃 + 스케일)
- 2Hz 흔들림 효과
- "Entry Successful!" 메시지
- 트랜잭션 정보 표시:
  - Entry ID
  - Status: PENDING
  - TX Hash (블록체인 트랜잭션)
- "Confirm" 버튼

**사용자 행동**: Confirm 버튼 터치
**화면 반응**:
- 오버레이가 사라짐
- 선택된 블록 초기화 (바텀시트 닫힘)
- 게임 화면으로 복귀

**비즈니스 의도**: 성공 경험을 강화하여 다음 게임 참여 유도

#### 5단계: 실패 오버레이
**화면 반응** (실패 시):
- 로딩 오버레이가 페이드 아웃
- Red → Pink 그라데이션 배경
- 중앙에 ❌ X 아이콘
- 4Hz 흔들림 효과 (강함)
- "Entry Failed" 메시지
- 에러 메시지 표시
- 2개 버튼:
  - "Retry": 다시 시도
  - "Cancel": 취소

**사용자 행동**: Retry 버튼 터치
**화면 반응**: 2단계부터 다시 시작

**비즈니스 의도**: 에러 상황에서도 사용자가 쉽게 재시도할 수 있도록 지원

## 3.1 My 페이지 (지갑 관리)

### 화면 목적
사용자의 캐시(cash) 잔액을 확인하고, 충전/환불/내역 조회를 할 수 있는 금융 관리 화면입니다.

### 주요 UI 구성

#### 상단: Total Cash 카드
- Blue → Purple 그라데이션 배경
- 큰 폰트로 총 캐시 표시 (예: "₩ 50,000")
- 작은 폰트로 "Total Cash" 라벨

#### 중간: 액션 버튼 (3개)
- **충전** (Charge): 파란색 아이콘, "Cash를 충전합니다"
- **환불** (Refund): 주황색 아이콘, "Cash를 환불받습니다"
- **내역** (History): 회색 아이콘, "거래 내역을 확인합니다"

#### 캐시 배분 섹션
- **Event Cash**: 이벤트로 받은 무료 캐시
  - 금액 표시 (예: "₩ 10,000")
  - 핑크색 카드
- **Shopping Cash**: 충전한 캐시
  - 금액 표시 (예: "₩ 40,000")
  - 파란색 카드

#### 하단: 거래 내역
- 최근 거래 3개 표시
- 각 항목:
  - 거래 유형 (Charge / Refund / Used)
  - 금액 (+ 또는 -)
  - 날짜/시간
- "View All" 버튼

### 사용자 시나리오

#### 1. My 페이지 진입
**사용자 행동**: 하단 네비게이션 "MY" 터치
**화면 반응**:
1. 로그인 확인
2. 비로그인 시: 로그인 다이얼로그 표시
3. 로그인 시: My 페이지 표시
4. 서버에서 캐시 잔액 로드
5. 거래 내역 최근 3개 로드

#### 2. 충전 버튼 클릭
**사용자 행동**: "충전" 버튼 터치
**화면 반응**:
1. 충전 금액 선택 바텀시트 표시:
   - 1만원, 3만원, 5만원, 10만원, 직접 입력
2. 사용자가 금액 선택
3. 결제 수단 선택 (카드/계좌이체/토스페이 등)
4. 결제 성공 시: 잔액 업데이트
5. 초록색 스낵바: "₩ 10,000 charged successfully"

**비즈니스 의도**: 사용자가 쉽게 캐시를 충전하여 게임에 참여하도록 유도

#### 3. 환불 버튼 클릭
**사용자 행동**: "환불" 버튼 터치
**화면 반응**:
1. 환불 가능 금액 확인 (Shopping Cash만 환불 가능)
2. 환불 금액 입력 다이얼로그 표시
3. 환불 계좌 정보 입력
4. 환불 신청 확인 다이얼로그
5. 사용자 확인 후 환불 처리
6. 초록색 스낵바: "Refund requested"

**비즈니스 의도**: 사용자가 안심하고 충전할 수 있도록 환불 정책 제공

#### 4. 거래 내역 보기
**사용자 행동**: "내역" 버튼 터치 (또는 "View All" 터치)
**화면 반응**:
- 거래 내역 전체 페이지로 이동
- 필터링 옵션: 전체 / 충전 / 환불 / 사용
- 날짜 범위 필터

## 3.2 My Pick (참여 내역)

### 화면 목적
사용자가 참여한 게임 목록을 확인하고, 각 게임의 진행 상황과 결과를 조회할 수 있습니다.

### 주요 UI 구성

#### 상단 탭바 (4개)
- **ALL**: 전체 참여 게임
- **DAILY**: DAILY 타입 게임만

- **VIBE**: VIBE 타입 게임만

#### 게임 카드 리스트

  - 게임 썸네일 이미지

### 사용자 시나리오

#### 2. DAILY 탭 선택
**사용자 행동**: "DAILY" 탭 터치
**화면 반응**:

#### 3. 게임 카드 클릭

**화면 반응**:
1. 모달 바텀시트 표시 (70% 높이)
2. 게임 상세 정보:
   - 게임 썸네일
   - 게임 제목, 설명
   - 참여 상태 (Active / Drawing / Won / Lost)
   - 내가 선택한 블록 좌표 (예: "Row 123, Col 456")
   - 총 참가자 수
   - 당첨자 수

#### 4. 당첨된 게임

**화면 반응**:

- 상품 정보 표시
- 배송/사용 안내

**비즈니스 의도**: 당첨 경험을 강화하여 재참여 유도

#### 5. 빈 상태
**사용자 상황**: 참여한 게임이 없음
**화면 반응**:
- 중앙에 회색 📭 아이콘
- "You haven't joined any games yet"
- "Browse games and pick your prize!" 버튼

**사용자 행동**: 버튼 터치
**화면 반응**: 홈 화면(PICK 탭)으로 이동

**비즈니스 의도**: 사용자가 게임에 참여하도록 유도
